## L'essentiel du chapitre

:::formule L'équation bilan
$$
\text{C}_6\text{H}_{12}\text{O}_6 + 6\,\text{O}_2 \longrightarrow 6\,\text{CO}_2 + 6\,\text{H}_2\text{O} + \text{énergie}
$$
- **Réactifs** : glucose + oxygène.
- **Produits** : dioxyde de carbone + eau + énergie.
- Équilibrage : $6$ carbones → $6$ $\text{CO}_2$ ; $12$ hydrogènes → $6$ $\text{H}_2\text{O}$ ; $18$ oxygènes des deux côtés.
:::

:::formule Définition
La **respiration cellulaire** est l'ensemble des réactions qui dégradent le glucose **en présence d'oxygène** dans le cytoplasme et les **mitochondries**, pour libérer de l'énergie.
:::

:::formule Deux respirations à ne pas confondre
- **Respiration pulmonaire** : l'air entre et sort (ventilation), échanges dans les alvéoles.
- **Respiration cellulaire** : dans les cellules, glucose + $\text{O}_2$ → $\text{CO}_2$ + $\text{H}_2\text{O}$ + énergie.
:::

:::formule L'ATP, monnaie énergétique
$$
\text{ADP} + \text{énergie} \to \text{ATP} \qquad \text{puis} \qquad \text{ATP} \to \text{ADP} + \text{énergie}
$$
L'**ATP** stocke l'énergie libérée et la restitue au moment où la cellule en a besoin (contraction musculaire, synthèses, etc.).
:::

:::formule Bilan énergétique
- $1$ mole de glucose ($180$ g) ≈ $2\,870$ kJ.
- ≈ **$38$ moles d'ATP** produites par mole de glucose.
- L'énergie est libérée **progressivement**, pas d'un coup.
:::

## Méthode express

1. Écrire l'équation : glucose + $\text{O}_2$ à gauche ; $\text{CO}_2$ + $\text{H}_2\text{O}$ + énergie à droite.
2. Équilibrer : $6$ $\text{CO}_2$, $6$ $\text{H}_2\text{O}$, $6$ $\text{O}_2$.
3. Nommer le lieu : cytoplasme et **mitochondries**.
4. Expliquer le devenir de l'énergie : captée par l'**ATP**, utilisée pour le travail musculaire, la chaleur, la croissance.
5. Si la question porte sur l'effort : sans $\text{O}_2$ suffisant → fermentation → acide lactate.

:::erreur Les erreurs qui coûtent des points
1. Inverser réactifs et produits : l'$\text{O}_2$ est **consommé**, le $\text{CO}_2$ est **produit**.
2. Oublier les coefficients $6$/$6$/$6$ : l'équation doit être équilibrée.
3. Confondre respiration **pulmonaire** et respiration **cellulaire**.
4. Écrire que l'ATP est un déchet : c'est la molécule de l'énergie.
5. Dire que l'énergie est libérée en une seule fois.
:::

## Vocabulaire

- **Respiration cellulaire** : dégradation du glucose avec $\text{O}_2$, dans les cellules.
- **Mitochondrie** : organite où se déroule la respiration cellulaire.
- **ATP** (adénosine triphosphate) : molécule qui stocke l'énergie.
- **ADP** (adénosine diphosphate) : forme appauvrie de l'ATP.
- **Énergie libre** : énergie directement utilisable par la cellule.
- **Fermentation** : dégradation du glucose **sans oxygène** (moins d'ATP, acide lactate).
- **Acide lactate** : déchet de l'effort musculaire sans oxygène suffisant.
- **Équation bilan** : équation chimique équilibrée du bilan d'une transformation.
