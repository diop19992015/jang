## Question

Dans quel organe se font les échanges gazeux entre l'air et le sang ?

- [ ] La trachée
- [ ] Les bronches
- [x] Les alvéoles pulmonaires
- [ ] Le larynx

> Les **alvéoles** sont de minuscules sacs entourés de capillaires sanguins : l'oxygène y diffuse vers le sang et le dioxyde de carbone en sort. La trachée et les bronches ne font que **conduire** l'air.

## Question

Que fait le diaphragme pendant l'inspiration ?

- [x] Il se contracte et s'abaisse
- [ ] Il se relâche et se redresse
- [ ] Il ne bouge pas
- [ ] Il bloque l'entrée de l'air

> À l'inspiration, le diaphragme **s'abaisse** et la cage thoracique s'élargit : le volume augmente, la pression baisse et l'air entre. À l'expiration, tout s'inverse.

## Question

Quel est le trajet correct de l'air ?

- [x] Cavité nasale → pharynx → larynx → trachée → bronches → bronchioles → alvéoles
- [ ] Alvéoles → trachée → cavité nasale → bronches → poumons
- [ ] Cavité nasale → poumons → trachée → alvéoles → bouche
- [ ] Bouche → larynx → cœur → bronches → alvéoles

> On retient l'ordre de haut en bas : l'air entre par la **cavité nasale**, descend par le **larynx** et la **trachée**, se divise dans les **bronches** puis les **bronchioles**, et arrive aux **alvéoles** où se font les échanges.

## Question

Comment l'oxygène est-il transporté dans le sang ?

- [x] Par l'hémoglobine des globules rouges, sous forme d'oxyhémoglobine
- [ ] Directement dissous dans le plasma uniquement
- [ ] Par les globules blancs
- [ ] Sous forme de dioxyde de carbone

> L'**hémoglobine** se charge en oxygène dans les poumons en formant l'**oxyhémoglobine** ($\text{HbO}_2$), puis le libère dans les tissus. Une petite partie de l'oxygène reste dissoute dans le plasma.
