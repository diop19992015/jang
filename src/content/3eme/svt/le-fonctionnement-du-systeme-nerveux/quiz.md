## Question

Quel est le trajet correct de l'arc réflexe ?

- [ ] Récepteur → nerf moteur → moelle → nerf sensitif → effecteur
- [x] Récepteur → nerf sensitif → moelle épinière → nerf moteur → effecteur
- [ ] Effecteur → nerf sensitif → cerveau → nerf moteur → récepteur
- [ ] Récepteur → cortex sensitif → cortex motrice → effecteur

> L'arc réflexe suit toujours le même sens : le récepteur capte le stimulus, le nerf **sensitif** apporte le message à la moelle, le nerf **moteur** repart avec l'ordre vers l'effecteur. Le cerveau n'en fait pas partie.

## Question

Dans un neurone, quelle partie conduit le message vers un autre neurone ?

- [ ] Les dendrites
- [ ] Le corps cellulaire
- [x] L'axone et ses terminaisons nerveuses
- [ ] Le liquide céphalo-rachidien

> Les dendrites **réçoivent** le message, le corps cellulaire l'intègre, puis l'axone le conduit jusqu'aux terminaisons nerveuses, qui le transmettent à la synapse.

## Question

Un réflexe est-il un comportement acquis ou inné ?

- [ ] Acquis, car il faut s'entraîner pour le déclencher
- [ ] Acquis, car il dépend du milieu
- [x] Inné, car il est présent dès la naissance et ne s'apprend pas
- [ ] Inné, mais seulement chez certaines personnes

> Le réflexe est un comportement **inné** : il est automatique, identique chez tous les individus et ne nécessite aucun apprentissage. Les comportements acquis (écrire, faire du vélo) s'apprennent par l'expérience.

## Question

Quelle est le rôle principal du cortex moteur ?

- [ ] Interpréter les sensations de chaud et de froid
- [ ] Assurer l'équilibre du corps
- [x] Commander volontairement les muscles
- [ ] Contrôler la respiration

> L'aire **motrice** du cortex envoie les ordres de mouvement volontaires aux muscles ; l'aire **sensitive** reçoit les sensations, le cervelet assure l'équilibre et le bulbe rachidien contrôle la respiration.
