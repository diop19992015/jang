## L'essentiel du chapitre

:::formule Inné ou volontaire ?
- **Inné** : présent dès la naissance, automatique, sans apprentissage (retirer la main du feu).
- **Volontaire (acquis)** : appris par l'expérience et la décision (écrire, faire du vélo).
:::

:::formule Le neurone
$$
\text{dendrites} \to \text{corps cellulaire} \to \text{axone} \to \text{terminaisons nerveuses}
$$
- **Dendrites** : réçoivent le message.
- **Axone** : le conduit (gaine de myéline = isolation, vitesse).
- Trois types : **sensitif** (récepteur → centre), **moteur** (centre → effecteur), **interneurone** (synapses).
:::

:::formule Le message nerveux
Onde électrochimique, circulation **en un seul sens** ; transmission d'un neurone à l'autre par la **synapse**, grâce à un **neurotransmetteur**.
:::

:::formule L'arc réflexe
$$
\text{récepteur} \to \text{nerf sensitif} \to \text{moelle épinière} \to \text{nerf moteur} \to \text{effecteur}
$$
Réponse **innée, involontaire, automatique et rapide** : le cerveau n'intervient qu'après, pour ressentir la douleur.
:::

:::formule Système nerveux central
| Organe | Rôle |
| --- | --- |
| Cerveau | Pensée, volonté, sens, langage |
| Cervelet | Équilibre, coordination des mouvements |
| Bulbe rachidien | Respiration, cœur (fonctions vitales) |
| Moelle épinière | Conduction des messages, réflexes |
:::

:::formule Les aires du cortex
- **Aire sensitive** : réception des sensations.
- **Aire motrice** : commande volontaire des muscles.
- **Aires de association** : mémoire, langage, raisonnement.
:::

## Méthode express

1. Classer un comportement : est-il présent **dès la naissance** ? → inné. Sinon → acquis.
2. Décrire le trajet d'un message : récepteur → neurone sensitif → centre nerveux → neurone moteur → effecteur.
3. Compléter un schéma d'arc réflexe : toujours les **5 éléments**, dans l'ordre, avec le bon sens de flèche.
4. Localiser une information sur le cortex : entrée par l'aire **sensitive**, sortie par l'aire **motrice**.
5. Rédiger l'hygiène du système nerveux : sommeil, alimentation, activité physique, pas d'alcool/tabac/drogues.

:::erreur Les erreurs qui coûtent des points
1. Dire que le message nerveux fait « un aller-retour » : il est **sensitif dans un sens, moteur dans l'autre**, ce sont deux nerfs différents.
2. Placer le cerveau dans l'arc réflexe.
3. Écrire que le réflexe est acquis ou conscient : il est **inné et inconscient**.
4. Confondre **sensitif** (information) et **moteur** (ordre).
5. Oublier la **synapse** dans le trajet du message entre deux neurones.
:::

## Vocabulaire

- **Neurone** : cellule nerveuse qui transmet l'information.
- **Influx nerveux (message nerveux)** : impulsion électrochimique qui parcourt le neurone.
- **Synapse** : zone de contact entre deux neurones (neurotransmetteur).
- **Arc réflexe** : trajet minimal d'une réponse automatique.
- **Récepteur** : organe qui capte le stimulus (peau, œil…).
- **Effecteur** : muscle ou glande qui exécute la réponse.
- **Encéphale** : cerveau + cervelet + bulbe rachidien (dans la boîte crânienne).
- **Cortex** : surface plissée du cerveau, siège des aires fonctionnelles.
- **Latéralisation** : spécialisation d'un hémisphère (langage à gauche chez le droitier).
