## L’essentiel du chapitre

:::formule Définitions clés
- **Système immunitaire** : ensemble des organes, cellules et molécules qui défendent l’organisme contre les éléments étrangers.
- **Organe lymphoïde** : organe qui produit ou accueille les cellules de défense.
- **Phagocyte** : globule blanc qui avale et digère les microbes (défense non spécifique).
- **Lymphocyte** : cellule de l’immunité **spécifique** (T et B), seule capable de créer une **mémoire**.
:::

:::formule Les organes primaires (production et maturation)
$$
\text{moelle osseuse} \to \text{lymphocytes B} \qquad \text{thymus} \to \text{lymphocytes T}
$$

Tous les leucocytes naissent dans la **moelle osseuse** ; seuls les lymphocytes T vont mûrir dans le **thymus**.
:::

:::formule Les organes secondaires (rencontre avec l’antigène)
Ganglions lymphatiques · Rate · Amygdales · Plaques de Peyer (intestin) · Appendice · Muqueuses
:::

## Le tableau à connaître par cœur

| | Phagocytes | Lymphocytes T | Lymphocytes B |
| --- | --- | --- | --- |
| Spécificité | non spécifique | spécifique | spécifique |
| Maturation | moelle osseuse | **thymus** | **moelle osseuse** |
| Rôle | phagocytent les microbes | immunité **cellulaire** : tuent les cellules infectées, coordonnent | immunité **humorale** : deviennent plasmocytes → **anticorps** |
| Mémoire | non | oui | oui |
| Exemple | macrophage, polynucléaire neutrophile | T auxiliaire (CD4), T cytotoxique (CD8) | plasmocyte, lymphocyte B mémoire |

## Méthode express

1. Sur un schéma, distinguer les organes **primaires** (moelle osseuse, thymus) des organes **secondaires** (ganglions, rate, amygdales).
2. Repérer le lieu de maturation : **B comme moelle osseuse**, **T comme thymus**.
3. Dire que les **phagocytes** sont la défense innée : ils dévorent tout intrus, sans mémoire.
4. Dire que les **lymphocytes** sont la défense spécifique : un lymphocyte = un antigène.
5. Expliquer le rôle du macrophage qui **présente l’antigène** : il fait le lien entre les deux lignes de défense.
6. Terminer par la **mémoire immunitaire** (vaccination) et, si on le demande, l’action du **VIH** sur les CD4.

:::erreur Les erreurs qui coûtent des points
1. Inverser les lieux de maturation : lymphocyte **B** = moelle osseuse, lymphocyte **T** = thymus.
2. Dire que les phagocytes ont une mémoire immunitaire : seule l’immunité spécifique en a une.
3. Confondre organe (ganglion, rate) et cellule (lymphocyte, phagocyte).
4. Écrire que les anticorps sont produits par les lymphocytes T : ce sont les **lymphocytes B** (plasmocytes).
5. Croire que le VIH attaque les anticorps : il détruit les lymphocytes **T auxiliaires CD4**.
:::

## Vocabulaire

- **Moelle osseuse** : tissu des os où naissent les cellules sanguines ; maturation des lymphocytes B.
- **Thymus** : organe derrière le sternum où mûrissent les lymphocytes T.
- **Ganglion lymphatique** : filtre de la lymphe, gonfle lors des infections.
- **Rate** : organe de filtrage du sang, à gauche de l’abdomen.
- **Amygdales** : tissu lymphoïde de la gorge.
- **Phagocytose** : ingestion d’un microbe par un phagocyte.
- **Antigène présenté** : rôle du macrophage (cellule présentatrice d’antigène).
- **Immunité cellulaire** : défense menée par les lymphocytes T.
- **Immunité humorale** : défense menée par les anticorps (lymphocytes B).
- **CD4** : récepteur des lymphocytes T auxiliaires, cible du VIH.
- **VIH / sida** : virus qui détruit les CD4 ; sida = stade tardif de l’infection.
