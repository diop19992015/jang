## Question

Dans quel organe mûrissent les lymphocytes T ?

- [ ] La moelle osseuse
- [x] Le thymus
- [ ] La rate
- [ ] Les amygdales

> Les lymphocytes T naissent dans la moelle osseuse puis migrent vers le **thymus**, où ils mûrissent : c’est d’ailleurs le T de leur nom. Les lymphocytes B mûrissent, eux, dans la moelle osseuse.

## Question

Quel est le rôle principal des phagocytes ?

- [ ] Produire les anticorps
- [x] Avaler et digérer les microbes et les débris
- [ ] Stocker la mémoire immunitaire
- [ ] Fabriquer les globules rouges

> Les phagocytes (macrophages, polynucléaires neutrophiles) phagocytent tout corps étranger : c’est une défense **innée**, non spécifique, qui ne crée pas de mémoire.

## Question

Quelle différence entre lymphocytes T et lymphocytes B ?

- [ ] Les T produisent les anticorps, les B tuent les cellules infectées
- [x] Les T assurent l’immunité cellulaire, les B deviennent plasmocytes et sécrètent les anticorps
- [ ] Les T mûrissent dans la rate, les B dans le thymus
- [ ] Les T ne reconnaissent aucun antigène

> Les lymphocytes T (maturation thymique) dirigent la réponse et détruisent les cellules infectées : immunité cellulaire. Les lymphocytes B (maturation moelle osseuse) se transforment en plasmocytes qui sécrètent les anticorps : immunité humorale.

## Question

Pourquoi les ganglions gonflent-ils lors d’une infection ?

- [ ] Parce qu’ils fabriquent des virus
- [x] Parce qu’ils filtrent la lymphe chargée de microbes et de cellules en multiplication
- [ ] Parce qu’ils produisent trop de globules rouges
- [ ] Parce qu’ils sécrètent du mucus

> Les ganglions lymphatiques filtrent la lymphe : y affluent les microbes, les cellules mortes et les leucocytes qui se multiplient pour combattre l’infection. Leur gonflement (adénopathie) signale donc une réaction immunitaire locale.
