## La formation des mots

| Procédé | Principe | Exemple |
| --- | --- | --- |
| Dérivation | radical + préfixe ou suffixe | *rebâtir*, *lecture* |
| Composition | deux mots réunis | *chasse-mouches*, *gratte-ciel* |
| Mot-valise | deux mots fondus en un | *courriel* (courrier + électronique) |
| Troncature | on garde le début du mot | *info*, *labo*, *vélo* |
| Conversion | le mot change de catégorie | *sourire* (verbe → nom) |
| Emprunt | mot pris à une autre langue | *basket*, *week-end*, *teranga* |

:::formule Préfixes fréquents
| Préfixe | Sens | Exemple |
| --- | --- | --- |
| *in-, im-, il-, ir-* | négation | *injuste*, *impossible* |
| *dés-, dé-* | opposé, privation | *désobéir*, *déplacer* |
| *re-* | répétition | *relire*, *rebâtir* |
| *anti-* | contre | *antidote* |
| *mal-, mé-* | mal | *malentendu*, *mépriser* |
| *pré-, pro-, sur-, sous-* | avant, au-dessus, au-dessous | *prévoir*, *sous-marin* |
| *trans-* | au-delà | *transport* |
| *a-, an-* | absence | *anonyme* |
:::

:::formule Suffixes fréquents
| Suffixe | Fonction | Exemple |
| --- | --- | --- |
| *-eur, -euse* | nom de personne ou de chose | *marcheur*, *tricheuse* |
| *-tion, -sion, -ment* | nom d’action | *lecture*, *décision*, *mouvement* |
| *-able, -ible* | adjectif de possibilité | *lisible*, *flexible* |
| *-iste* | nom de métier ou d’adepte | *artiste*, *journaliste* |
| *-ien, -enne* | adjectif d’appartenance | *africain*, *européenne* |
| *-esse, -ette* | féminin ou diminutif | *princesse*, *maisonnette* |
| *-age, -ure* | nom d’action ou de résultat | *voyage*, *peinture* |
| *-ance, -ence* | nom d’état ou de qualité | *naissance*, *espérance* |
:::

## Les relations entre mots

| Relation | Définition | Exemple |
| --- | --- | --- |
| Synonymes | même sens | *joyeux / gai* |
| Antonymes | sens opposés | *monter / descendre* |
| Paronymes | proches par le son, différents par le sens | *complément / compliment*, *allusion / illusion* |
| Homonymes | même mot, plusieurs sens | *un livre* (roman) / *un livre* (unité) |
| Famille de mots | même radical | *écrire, écrivain, écrit, écriture* |

## Les figures de style

:::formule Figures de sens
| Figure | Définition | Exemple |
| --- | --- | --- |
| Comparaison | rapprochement avec *comme, tel, ainsi que* | *le vent hurle **comme** une bête* |
| Métaphore | comparaison sans comparatif | *ton sourire **est un soleil*** |
| Personnification | qualités humaines à une chose | *la pluie **tambourine*** |
| Hyperbole | exagération | *attendre **une éternité*** |
| Litote | dire moins pour suggérer | *ce n’est pas mal* (= bien) |
| Antithèse | idées opposées | *ouvrir l’esprit / le fermer* |
| Allégorie | idée abstraite incarnée | *la Liberté au flambeau* |
| Euphémisme | adoucir | *il a quitté ce monde* |
| Ironie | dire le contraire | *bravo, tout est gâché !* |
:::

:::formule Figures de forme
| Figure | Définition | Exemple |
| --- | --- | --- |
| Anaphore | répétition en début de phrase | *nous voulons **des livres**, nous voulons **des bancs*** |
| Gradation | idées en croissant ou décroissant | *mentir, trahir, voler* |
| Énumération | liste d’éléments | *fonds, murs, toit : tout casse* |
| Allitération | même son consonne | *le **s**ilence **s**’étend* |
| Assonance | même son voyelle | *le jour tombe, l’eau coule* |
| Répétition | un mot revient | *le travail, toujours le travail* |
:::

:::remarque Comparaison ou métaphore ?
Le test est simple : si la comparaison est exprimée par un **comparatif** (*comme, tel, ainsi que, en guise de*), c’est une **comparaison** ; si le rapprochement se fait **sans aucun mot comparatif**, c’est une **métaphore**. Dans les deux cas, précise toujours **l’effet** : frapper l’esprit, rendre l’idée plus sensible, créer une ambiance.
:::

## Les niveaux de langue et les registres

:::formule Les trois niveaux
| Niveau | Situation | Exemple |
| --- | --- | --- |
| Familier (et argot) | conversation détendue | *il a filé*, *la bagnole* |
| Courant (standard) | usage quotidien, écrit courant | *il est parti*, *la voiture* |
| Soutenu (littéraire) | écrit soigné, discours | *il a pris congé*, *l’automobile* |
:::

| Registre | Tonalité | Exemple d’effet |
| --- | --- | --- |
| Pathétique | émotion, douleur | attendrir le lecteur |
| Lyrique | introspection, sentiment | faire vibrer le cœur |
| Satirique | moquerie, critique | dénoncer par le rire |
| Humoristique | comique | faire sourire |
| Épique | héroïsme | grandir les personnages |
| Tragique | fatalité, douleur | émouvoir profondément |

:::remarque Niveau et registre ne se confondent pas
Le **niveau** se juge au mot (familier, courant, soutenu) ; le **registre** se juge au ton de tout le texte (pathétique, lyrique, satirique…). Un extrait soutenu peut être pathétique, et une conversation familière peut être humoristique. Au BFEM, précise toujours lequel tu nommes et pourquoi.
:::

## Méthode de rappel

1. Mot → radical + affixes → procédé → sens.
2. Expression → figure (sens ou forme) → effet.
3. Texte → mots du même domaine → champ lexical.
4. Discours → mots → niveau ; tonalité → registre.
