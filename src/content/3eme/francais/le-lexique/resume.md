## L’essentiel du chapitre

:::formule La formation des mots
- **Radical** : sens de base (*port* dans *porter, portail, rapport*).
- **Préfixe** devant : *in-, im-, dé-, re-, anti-, mal-, pré-, sur-, sous-, trans-*.
- **Suffixe** derrière : *-eur, -tion, -ment, -able, -iste, -ien, -esse, -age, -ance*.
- Autres procédés : composition (*chasse-mouches*), mot-valise (*courriel*), troncature (*info*), conversion (*sourire*), emprunt (*basket*, *teranga*).
:::

:::formule Sens propre, sens figuré, champ lexical
- **Sens propre** : sens littéral du dictionnaire. **Sens figuré** : sens imagé, par analogie.
- **Champ lexical** : ensemble des mots d’un même domaine (*pluie, nuage, orage, ruisseau* → champ lexical des pluies).
:::

:::formule Figures de sens à connaître
| Figure | Repère |
| --- | --- |
| Comparaison | mot comparatif : *comme, tel, ainsi que* |
| Métaphore | comparaison **sans** comparatif |
| Personnification | une chose reçoit des qualités humaines |
| Hyperbole | exagération volontaire |
| Litote | dire moins (souvent par négation) |
| Antithèse | deux idées opposées |
| Euphémisme | adoucir une idée |
| Ironie | dire le contraire de ce qu’on pense |
:::

:::formule Figures de forme à connaître
| Figure | Repère |
| --- | --- |
| Anaphore | répétition en **début** de phrase |
| Gradation | idées en croissant ou décroissant |
| Énumération | liste d’éléments |
| Allitération | répétition de **consonnes** |
| Assonance | répétition de **voyelles** |
:::

:::formule Niveaux de langue
| Niveau | Exemple avec *partir* |
| --- | --- |
| Familier | *il a filé* |
| Courant | *il est parti* |
| Soutenu | *il a pris congé* |
:::

## Méthode express

1. **Former un mot** : isoler le radical → repérer préfixe/suffixe → nommer le procédé → expliquer le sens.
2. **Sens d’un mot** : essayer le sens littéral ; s’il est impossible, on est au **figuré**.
3. **Champ lexical** : repérer le sujet dominant → souligner tous les mots du domaine → le nommer en un mot.
4. **Figure de style** : expression frappante → comparatif ? → comparaison. Sinon : opposé → antithèse ; exagéré → hyperbole ; personne à une chose → personnification ; répétition → anaphore/gradation. **Toujours citer l’effet**.
5. **Niveau et registre** : les mots parlent du **niveau** (familier/courant/soutenu) ; la tonalité parle du **registre** (pathétique, lyrique, satirique, humoristique…).

:::erreur Les erreurs qui coûtent des points
1. Dire « métaphore » alors que *comme* est présent : c’est une **comparaison**.
2. Donner la figure **sans son effet** (« effet : rendre l’idée plus forte, plus sensible ou plus émouvante »).
3. Confondre **paronymes** (*compliment / complément*, mots différents) et **homonymes** (*un livre / un livre*, un seul mot, plusieurs sens).
4. Affirmer « c’est du langage familier, donc c’est une faute » : le familier est un **niveau** adapté à la conversation, pas une faute.
5. Oublier le **radical** quand on analyse un mot : *inattendu* → radical *attendu*, pas *attendre*.
:::

## Vocabulaire

- **Lexique** : ensemble des mots d’une langue, d’un texte, d’un auteur.
- **Radical (racine)** : partie du mot portant le sens principal.
- **Préfixe / suffixe** : affixe placé avant / après le radical.
- **Champ lexical** : mots appartenant au même domaine de sens.
- **Sens propre / sens figuré** : sens littéral / sens imagé par analogie.
- **Synonymes / antonymes** : mots de même sens / de sens opposés.
- **Paronymes** : mots proches par le son, différents par le sens.
- **Homonymes** : même mot, plusieurs sens différents.
- **Figure de style** : emploi singulier des mots pour frapper l’esprit.
- **Niveau de langue** : degré de formalité du vocabulaire (familier, courant, soutenu).
- **Registre** : tonalité d’un texte (pathétique, lyrique, satirique, humoristique, épique, tragique).
