:::remarque À quoi ça sert au BFEM ?
Au BFEM, le lexique revient chaque année : on te demande de repérer un champ lexical, d’identifier une figure de style et son effet, de dire le niveau de langue d’un extrait ou d’expliquer un mot par son radical et ses affixes. Ces questions sont rapides et ne demandent pas de rédaction longue : ce sont des points faciles à gagner si tu connais les définitions par cœur.
:::

## Le lexique, qu’est-ce que c’est ?

Le **lexique** est l’ensemble des mots d’une langue, mais aussi d’un texte, d’un auteur ou d’un domaine donné. La **grammaire** organise les phrases (accords, conjugaison, syntaxe) ; le **lexique** fournit les mots que l’on met dans ces phrases.

:::exemple Deux mots, deux champs lexicaux
« Le harmattan assèche les lèvres, le sol craquelle, les puits se vident. » → lexique de la **sécheresse**.
« L’hivernage inonde les rues, les canaux débordent, les nattes s’envolent. » → lexique des **pluies**.
:::

:::erreur Attention
Un mot ne s’apprend pas seul : on l’apprend avec sa **famille** (*écrire → écrivain, écrit, écriture, réécrire*) et avec les mots du **même domaine**. Au BFEM, on te demandera presque toujours les deux.
:::

## La formation des mots

Les mots se forment à partir d’un **radical** (ou racine), qui porte le sens de base, auquel on ajoute des **affixes** (préfixes devant, suffixes derrière).

:::definition Trois termes à ne jamais confondre
- **Radical** : partie du mot qui porte le sens principal (*port* dans *porter, portail, rapport*).
- **Préfixe** : élément placé **avant** le radical (*re-, in-, dé-*).
- **Suffixe** : élément placé **après** le radical (*-eur, -tion, -able*).
:::

### La dérivation

C’est le procédé le plus fréquent : on forme un mot nouveau en ajoutant un préfixe ou un suffixe.

:::formule Les préfixes les plus utiles
| Préfixe | Sens | Exemple |
| --- | --- | --- |
| *in-, im-, il-, ir-* | négation | *injuste*, *impossible* |
| *dés-, dé-* | opposé, privation | *désobéir*, *déplacer* |
| *re-* | répétition | *relire*, *rebâtir* |
| *anti-* | contre | *antidote*, *anti-moustique* |
| *mal-, mé-* | mal | *malentendu*, *mépriser* |
| *pré-, pro-, sur-, sous-* | avant, devant, au-dessus, au-dessous | *prévoir*, *surmener*, *sous-marin* |
| *trans-* | au-delà | *transport*, *traverser* |
| *a-, an-* | privation, absence | *atypique*, *anonyme* |
:::

:::formule Les suffixes les plus utiles
| Suffixe | Fonction | Exemple |
| --- | --- | --- |
| *-eur, -euse, -eur* | nom de personne ou de chose | *marcheur*, *tricheuse* |
| *-tion, -sion, -ment* | nom d’action | *lecture*, *décision*, *mouvement* |
| *-able, -ible* | adjectif de possibilité | *lisible*, *flexible* |
| *-iste* | nom de métier ou d’adepte | *artiste*, *journaliste* |
| *-ien, -enne* | adjectif d’appartenance | *africain*, *européenne* |
| *-esse, -ette* | nom ou adjectif féminin | *princesse*, *maisonnette* |
| *-age, -ure* | nom d’action ou de résultat | *voyage*, *peinture* |
| *-ance, -ence* | nom d’état ou de qualité | *naissance*, *espérance* |
:::

### La composition et les autres procédés

:::formule Les procédés de formation des mots
| Procédé | Principe | Exemple |
| --- | --- | --- |
| Dérivation | radical + préfixe ou suffixe | *rebâtir*, *lecture* |
| Composition | deux mots indépendants réunis | *chasse-mouches*, *gratte-ciel*, *porte-monnaie* |
| Mot-valise | fonction de deux mots en un seul | *courriel* (courrier + électronique), *clavardage* (clavier + bavardage) |
| Troncature | on garde le début du mot | *info* (information), *labo* (laboratoire), *vélo* (vélocipède) |
| Conversion | le mot change de catégorie | *sourire* (verbe → nom), *un après-midi* |
| Emprunt | on prend un mot à une autre langue | *basket*, *week-end* (anglais), *teranga*, *sabar* (wolof) |
:::

:::methode Analyser un mot en quatre étapes
1. Isole le **radical** (le sens de base).
2. Repère le **préfixe** et/ou le **suffixe**.
3. Nomme le **procédé** (dérivation, composition, troncature…).
4. Explique le **sens du mot** avec tes propres mots.
:::

:::exemple Analyse complète
« Cet élève est **indiscipliné**. »

1. Radical : *discipline*.
2. Préfixe : *in-* (négation) + suffixe : *-é* (adjectif).
3. Procédé : dérivation.
4. Sens : « qui n’a pas de discipline ».
:::

:::piege Les pièges classiques
- *inattendu* : le radical est *attendu*, pas *attendre* ; le préfixe *in-* marque la négation.
- *rebâtir* : *re-* signifie « de nouveau », mais *retirer* ne signifie pas « tirer de nouveau » : le sens des affixes doit être vérifié dans le dictionnaire.
- Un mot en *-age* n’est pas forcément un nom d’action : *plage* vient de *plaie*.
:::

## Le sens des mots et le champ lexical

### Sens propre et sens figuré

:::definition Sens propre et sens figuré
- **Sens propre** : le sens littéral, premier, celui du dictionnaire.
- **Sens figuré** : le sens dérivé, imagé, employé par analogie.
:::

:::exemple Le mot à deux sens
« Il pleut. » → sens propre : de l’eau tombe du ciel.
« Les insultes pleuvaient sur le maître. » → sens figuré : les insultes arrivaient en grande quantité.
:::

:::remarque Comment reconnaître le sens figuré ?
Pose la question : le sens littéral a-t-il un sens ici ? Si « les insultes pleuvaient » est impossible physiquement, le mot est employé au sens figuré.
:::

### Le champ lexical

:::definition Champ lexical
Le champ lexical est l’ensemble des mots appartenant au **même domaine** ou à la même idée, qui permettent de créer une ambiance dans un texte.
:::

:::exemple Un champ lexical local
Texte : « La **saison** arrive, les **nuages** noircissent, la **pluie** fouette la tôle, les **ruisseaux** grossissent, les **écoliers** courent sous la **teranga** des voisins. »
→ Champ lexical des **pluies** (ou de l’hivernage) : *saison, nuages, pluie, ruisseaux*.
:::

:::methode Trouver un champ lexical
1. Repère le sujet ou l’ambiance dominante du texte.
2. Souligne tous les mots qui tournent autour de cette idée.
3. Donne le domaine en un mot (l’amour, la mort, la nature, la pauvreté, la joie…).
:::

### Les relations entre mots

:::formule Les relations à connaître
| Relation | Définition | Exemple |
| --- | --- | --- |
| Synonymes | mêmes sens, nuances différentes | *grand / élevé*, *joyeux / gai* |
| Antonymes | sens opposés | *monter / descendre*, *riche / pauvre* |
| Paronymes | proches par le son, différents par le sens | *complément / compliment*, *allusion / illusion* |
| Homonymes | même mot, même son, sens totalement différents | *un livre* (roman) / *un livre* (unité) ; *un voile* / *une voile* |
| Famille de mots | même radical | *écrire, écrivain, écrit, écriture* |
:::

:::piege Paronymes et homonymes : la distinction qui rapporte des points
**Paronymes** : deux mots *différents* qui se ressemblent (*compliment* ≠ *complément*).
**Homonymes** : un *seul* et même mot qui a plusieurs sens (*je lis un **livre*** / *un **livre** de riz*).
Le test : si les mots peuvent avoir une famille commune, ce sont des paronymes ; si ce sont exactement les mêmes lettres, ce sont des homonymes.
:::

## Les figures de style

:::definition Figure de style
Une figure de style est une manière **singulière** d’employer les mots pour rendre une idée plus frappante, plus belle ou plus forte.
:::

On distingue deux grandes familles : les **figures de sens** (elles changent l’idée exprimée) et les **figures de forme** (elles organisent les mots).

:::formule Les figures de sens
| Figure | Définition | Exemple |
| --- | --- | --- |
| Comparaison | rapprochement exprimé par *comme, tel, ainsi que* | *Le vent gémissait **comme** une bête blessée.* |
| Métaphore | comparaison **sans** mot comparatif | *Ton **sourire est un soleil** de mars.* |
| Personnification | on donne des qualités humaines à une chose | *La **pluie tambourine** sur la tôle.* |
| Hyperbole | exagération volontaire | *J’attendais **depuis une éternité**.* |
| Litote | on dit **moins** pour suggérer davantage (souvent par négation) | *Ce n’est pas **mal** ce garçon* (= c’est bien). |
| Antithèse | rapprochement de deux idées **opposées** | *L’école **ouvre** l’esprit, la routine le **ferme**.* |
| Allégorie | une idée abstraite rendue par un personnage ou une scène | *La Liberté tenant son flambeau.* |
| Euphémisme | on **adoucit** une idée désagréable | *Il a **quitté** ce monde* (= il est mort). |
| Ironie | on dit le **contraire** de ce qu’on pense | *Bravo, tu as tout gâché !* |
:::

:::formule Les figures de forme
| Figure | Définition | Exemple |
| --- | --- | --- |
| Anaphore | répétition au **début** de phrases ou de vers | *Nous voulons **des livres**, nous voulons **des bancs**, nous voulons **des maîtres**.* |
| Gradation | idées classées en **croissant** ou en **décroissant** | *Il a menti, trahi, volé.* |
| Énumération | liste de mots ou d’idées | *Fonds, murs, toit : tout est à réparer.* |
| Allitération | répétition d’un **même son consonne** | *Le **s**ilence **s**’étend sur le sahel.* |
| Assonance | répétition d’un **même son voyelle** | *Le jour tombe, l’eau coule, l’ombre monte.* |
| Répétition | un mot revient dans la même phrase | *Le travail, toujours le travail.* |
:::

:::methode Reconnaître une figure de style
1. Souligne l’expression étrange ou frappante.
2. Y a-t-il un comparatif (*comme, tel*) ? → **comparaison**.
3. Sinon, deux idées opposées ? → **antithèse** ; une exagération ? → **hyperbole** ; une négation qui atténue ? → **litote** ; une chose traitée en personne ? → **personnification**.
4. Les mots sont-ils répétés ? → **anaphore** (en début), **gradation** (dans l’ordre), **allitération/assonance** (sons).
5. Termine toujours par **l’effet** produit : frapper, convaincre, émouvoir, faire sourire.
:::

:::erreur Les erreurs qui coûtent des points
1. Dire « métaphore » alors que le mot comparatif *comme* est présent : c’est une **comparaison**.
2. Citer la figure **sans son effet** : le correcteur attend « effet : rendre l’idée plus forte/plus sensible ».
3. Confondre **personnification** (une chose devient une personne) et **métaphore** (une chose est *comparée* à une autre).
4. Prendre un simple adjectif pour une figure de style : tout emploi d’adjectif n’est pas une figure.
:::

## Niveaux de langue et registres

:::definition Niveau de langue
Le niveau de langue est le degré de formalité du vocabulaire employé selon la situation de communication : conversation familiale, écrit soigné, texte littéraire…
:::

:::formule Les trois niveaux de langue
| Niveau | Situation | Exemple |
| --- | --- | --- |
| **Familier** (et argot) | entre amis, conversation détendue | *Il a **filé***, *la **bagnole** est cassée* |
| **Courant** (standard) | usage quotidien, la plupart des textes | *Il est **parti***, *la **voiture** est cassée* |
| **Soutenu** (littéraire) | écrit soigné, discours, texte littéraire | *Il a **pris congé***, *l’**automobile** est hors service* |
:::

:::exemple Une même idée à trois niveaux
1. Soutenu : *« Je vous saurai gré de bien vouloir m’accorder un entretien. »*
2. Courant : *« Je voudrais vous voir, s’il vous plaît. »*
3. Familier : *« Dis donc, tu peux me voir deux minutes ? »*
:::

:::remarque Niveau de langue et registre, ce n’est pas pareil
Le **niveau** porte sur les mots (familier, courant, soutenu). Le **registre** porte sur la **tonalité** du texte : registre **pathétique** (émouvant), **lyrique** (introspectif, chantant), **satirique** (moqueur, critique), **humoristique** (comique), **épique** (héroïque), **tragique** (douloureux).
Un même texte peut changer de registre : l’épilogue d’un récit pathétique peut devenir lyrique.
:::

:::piege Le niveau familier n’est pas une faute
Le langage familier ou argotique n’est pas « du mauvais français » : c’est un **registre adapté à une situation**. L’erreur serait de l’employer dans une rédaction soignée ou une lettre officielle. À l’écrit, on privilégie le niveau **courant**, avec passages **soutenus**.
:::

## Ce qu’il faut retenir

- Le **lexique** est l’ensemble des mots ; il se travaille par **familles de mots** et par **champs lexicaux**.
- Les mots se forment par **dérivation** (préfixe, suffixe), **composition**, mot-valise, **troncature**, conversion, emprunt.
- Tout mot a un **sens propre** et parfois un **sens figuré** : vérifie si le sens littéral fonctionne.
- Les **figures de sens** (comparaison, métaphore, personnification, hyperbole, litote, antithèse…) changent l’idée ; les **figures de forme** (anaphore, gradation, allitération…) organisent les mots. Cite toujours la figure **et son effet**.
- Trois **niveaux de langue** : familier, courant, soutenu ; plusieurs **registres** : pathétique, lyrique, satirique, humoristique…
- Méthode rapide : radical → affixes → procédé → sens ; expression → figure → effet ; texte → champ lexical ; discours → niveau et registre.
