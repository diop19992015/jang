## L’essentiel du chapitre

:::formule Les trois piliers du texte argumentatif
- **Thèse** : l’opinion défendue par l’auteur.
- **Arguments** : les raisons qui soutiennent la thèse (*en effet, car, parce que*).
- **Exemples** : les faits concrets qui prouvent les arguments (*par exemple, ainsi*).
:::

:::formule La règle du nombre de mots
$$
\text{mots du résumé} \leqslant \text{limite demandée}
$$

On compte les articles. Vise 90 % de la limite pour être sûr de ne pas dépasser.
:::

:::formule Ce qu’un résumé doit contenir
| Garder | Supprimer |
| --- | --- |
| La thèse | Les détails et précisions inutiles |
| Chaque argument | Les exemples (sauf si le sujet les exige) |
| Les liens logiques (*mais, donc*) | Les répétitions et les reformulations redondantes |
| Le sens exact du texte | L’opinion personnelle |
:::

:::formule Le mouvement de la discussion
**Thèse de l’auteur → ton avis → tes raisons → un exemple concret**
:::

## Méthode express

1. Lire l’énoncé : noter la limite de mots de chaque partie (résumé / discussion).
2. Repérer la thèse : titre, première phrase, connecteurs *en effet, car, donc*.
3. Lister les arguments : un par connecteur ou par phrase.
4. Résumer : reformuler chaque idée avec ses propres mots, jamais copier.
5. Compter les mots, couper le superflu.
6. Discuter : *je suis d’accord / je ne suis pas tout à fait d’accord*, puis 2 raisons et 1 exemple personnel (Dakar, Thiès, Saint-Louis, ton collège).
7. Conclure en une phrase.

:::erreur Les erreurs qui coûtent des points
1. Copier le texte mot pour mot au lieu de reformuler.
2. Dépasser le nombre de mots demandé.
3. Ajouter son avis dans le résumé.
4. Oublier un argument du texte.
5. Discuter sans exemple concret ou sans raisons.
6. Changer le sens : *peut* → *doit*, *certains* → *tous*.
:::

## Vocabulaire

- **Texte argumentatif** : texte qui vise à convaincre.
- **Thèse** : opinion défendue par l’auteur.
- **Argument** : raison donnée pour soutenir la thèse.
- **Exemple** : fait concret qui illustre un argument.
- **Résumé** : reformulation courte et fidèle, sans opinion.
- **Reformuler** : dire la même chose avec d’autres mots.
- **Discussion** : réponse personnelle à la thèse (accord, nuance ou refus), justifiée.
- **Connecteur** : mot qui relie les idées (*car, donc, mais, ainsi*).
- **Fidélité** : respect du sens exact du texte source.
