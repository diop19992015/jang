## L’essentiel du chapitre

:::formule Les temps de l’indicatif
- **Passé** : imparfait (description, habitude) · passé composé (action terminée) · plus-que-parfait (antériorité) · passé simple (récit écrit) · passé antérieur.
- **Présent** : action actuelle ou vérité générale.
- **Futur** : futur simple (action future) · futur antérieur (antériorité).
:::

:::formule Le subjonctif
Mode de la **volonté**, du **doute** et de la **nécessité**, presque toujours après *que* :
*Il faut que tu **révises** · Je doute qu’il **vienne** · Bien qu’il **soit** fatigué.*
Terminaisons : *-e, -es, -e, -ions, -iez, -ent* (verbes irréguliers : *sois, ait, aille, fasse, puisse, sache, vienne*).
:::

:::formule Le conditionnel
Base du futur + terminaisons de l’imparfait : *je chanterais, il chanterait, nous chanterions*.
Trois valeurs : **hypothèse** (*Si j’avais le temps, je réviserais*), **politesse** (*Pourriez-vous répéter ?*), **information non confirmée** (*Il serait à Dakar*).
:::

:::formule La concordance des temps
| Principale | Subordonnée de temps | Après *que* (subjonctif) |
| --- | --- | --- |
| Présent / futur | présent ou futur : *Quand il **arrive**, je pars* | subjonctif présent : *Je veux qu’il **vienne*** |
| Passé | imparfait ou plus-que-parfait : *Quand il **est arrivé**, je suis parti* | subjonctif : *Je voulais qu’il **vienne*** |
:::

:::formule Les trois voix
| Voix | Construction | Exemple |
| --- | --- | --- |
| Active | sujet + verbe + COD | *Le maître corrige les copies.* |
| Passive | COD + *être* + participe passé + *par/de* + agent | *Les copies sont corrigées par le maître.* |
| Pronominale | sujet + *se* + verbe | *Les élèves se réjouissent.* |
:::

## Méthode express

1. Repère le **mode** : indicatif (réel) / subjonctif (volonté, doute) / conditionnel (hypothèse, politesse).
2. Choisis le **temps** : où se situe l’action ? précède-t-elle une autre action ? s’agit-il d’une description ou d’un récit ?
3. Vérifie la **concordance** : principale au passé → subordonnée à l’imparfait/au plus-que-parfait ; après *que* → subjonctif.
4. Pour la **voix passive** : COD de l’active → sujet + *être* au même temps + participe passé accordé + *par/de* + agent.
5. Pour la **voix pronominale** : le sujet agit sur lui-même ; l’accord se fait avec le sujet.

:::erreur Les erreurs qui coûtent des points
1. Écrire *Si tu réviserais* → après *si*, jamais de conditionnel : *Si tu révises, tu réussiras*.
2. Écrire *Je veux que tu viens* → subjonctif obligatoire : *Je veux que tu **viennes***.
3. Oublier l’accord à la voix passive : *Les copies sont corrigé**es***.
4. Confondre habitude et action terminée : *Je lisais chaque jour* (imparfait) vs *J’ai lu ce livre* (passé composé).
:::

## Vocabulaire

- **Mode** : forme du verbe selon l’attitude du locuteur (indicatif, subjonctif, conditionnel, impératif, infinitif).
- **Temps simple** : un seul mot (*il chantait*).
- **Temps composé** : auxiliaire + participe passé (*il a chanté*).
- **Participe passé** : forme invariable ou accordable du verbe (*écrit, arrivés*).
- **Concordance des temps** : accord du temps de la subordonnée avec celui de la principale.
- **Voix active** : le sujet fait l’action.
- **Voix passive** : le sujet subit l’action (COD de l’active + *être* + PP).
- **Agent** : celui qui fait l’action à la passive (*par le maître*).
- **Voix pronominale** : le sujet fait l’action sur lui-même (*se laver, se réjouir*).
