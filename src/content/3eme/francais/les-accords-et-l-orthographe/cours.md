:::remarque À quoi ça sert au BFEM ?
La dictée et les questions d’accord reviennent presque chaque année au BFEM : on te demande d’accorder un participe passé, de corriger des fautes d’accord ou d’écrire un mot juste (pluriel, homophone). Ce sont des points **faciles et rapides** : avec les règles de ce chapitre, tu peux les décrocher sans hésiter.
:::

## Le participe passé

:::definition Formation du participe passé
- **1er groupe** (*-er*) : base + *-é* → *chanter → chanté*, *travailler → travaillé*.
- **2e groupe** (*-ir*) : base + *-i* → *finir → fini*, *choisir → choisi*.
- **3e groupe** : irréguliers à apprendre par cœur → *avoir → eu*, *être → été*, *faire → fait*, *voir → vu*, *prendre → pris*, *écrire → écrit*, *lire → lu*, *mettre → mis*, *venir → venu*, *mourir → mort*, *naître → né*, *ouvrir → ouvert*, *devoir → dû*, *pouvoir → pu*.
:::

:::formule Les trois règles d’or du participe passé
| Auxiliaire | Règle | Exemple |
| --- | --- | --- |
| **être** | s’accorde **toujours** avec le sujet, en genre et en nombre | *Elles sont arriv**ées** à l’heure.* |
| **avoir** | invariable avec le sujet ; s’accorde avec le COD **seulement si le COD est placé avant** le verbe | *Les lettres qu’elle a écrite**s*** / *Elle a écrit les lettres.* |
| **verbe pronominal** | s’accorde avec le sujet ; sauf s’il y a un COD **personnel placé après** | *Elles se sont réjoui**es*** / *Elles se sont lavé les mains.* |
:::

:::methode Vérifier un accord en trois questions
1. Quel est l’auxiliaire : *être*, *avoir* ou un verbe pronominal ?
2. S’il y a un COD, est-il **avant** ou **après** le verbe ?
3. Accorde avec le sujet (*être*, pronominal) ou avec le COD (*avoir* + COD avant)… ou ne t’accorde **pas du tout** (avoir + COD après, COD *en* ou *y*, *il y a*).
:::

:::exemple Les cas difficiles
- COD **après** : *J’ai lu les trois livres* → pas d’accord (*lus* serait une faute).
- COD **avant** : *Les trois livres que j’ai lu**s*** → accord avec *livres*.
- Avec **en** : *Les galettes sénégalaises, j’en ai mangé trois* → invariable, *en* n’est jamais COD complet.
- Avec **il y a** : *Il y a deux élèves absents* → toujours invariable, même au pluriel.
- Participe employé **seul** (adjectif) : *un soldat **mort** au combat* → s’accorde comme un adjectif : *des soldats morts*.
- Expressions administratives **invariables** : *ci-joint, vu, attendu, supposé, étant donné* : *Vous trouverez ci-joint le bulletin.*
:::

:::erreur Les erreurs qui coûtent des points (participe passé)
1. S’accorder avec le sujet à l’auxiliaire *avoir* : *Les filles ont **fini** leurs leçons* (et non *finies*).
2. S’accorder quand le COD est après : *Elle a mangé des mangues* (et non *mangées*).
3. Oublier l’accord à la voix passive : *Les copies sont corrigé**es***.
4. Accorder *il y a* : on écrit toujours *Il y a eu des incidents* (et non *ils y ont eu des incidents*).
:::

## Les accords difficiles

:::formule Les cas à maîtriser
| Cas | Règle | Exemple |
| --- | --- | --- |
| Sujet composé avec *et* | verbe au **pluriel** | *Aminata et Moussa arriv**ent**.* |
| *ou*, *ni…ni* | verbe au singulier si les sujets sont de nature différente ; au pluriel si ce sont des personnes | *Ni le professeur ni les élèves n’**étaient** absents.* |
| *chacun, chaque, quelqu’un, personne, rien, un, on* | verbe au **singulier** | *Chacun des élèves a **son** cahier.* |
| *plusieurs, beaucoup de, la plupart, un certain nombre de* | verbe au **pluriel** | *Plusieurs élèves **ont** réussi.* |
| Attribut avec un verbe d’état | s’accorde avec le **sujet** | *Elles sont devenu**es** professeures.* |
| Nom attribut après *être* | **invariable** | *Elle est devenue médecin.* |
| Adjectif | s’accorde en genre et en nombre | *de joli**es** filles*, *un petit garçon* |
| Après *beaucoup de, peu de, trop de* + nom | le déterminant reste **invariable** | *beaucoup de leçons* (et non *beaucoup des*) |
:::

:::exemple Application
- *Fatou et Khady ont révisé leur leçon.* → sujet composé avec *et* → pluriel : *ont révisé*.
- *Personne n’est venu au cours de français.* → *personne* est toujours singulier.
- *C’est l’un des meilleurs collèges de Dakar.* → *l’un* reste au singulier devant *des meilleurs*.
:::

:::piege « Il y a » n’est jamais accordé
*Il y a trois jours*, *il y a eu un accident*, *il y avait des élèves* : *il y a* est une expression impersonnelle, elle ne s’accorde jamais. On la reconnaît à la structure *il + y + avoir*.
:::

## L’orthographe d’usage

### Les pluriels irréguliers

:::formule Les pluriels à connaître
| Règle | Singulier | Pluriel | Exceptions |
| --- | --- | --- | --- |
| *-eau, -au* → *-eaux* | tableau, journal | tableaux, journaux | *bleu → bleus*, *pneu → pneus*, *lieu → lieux* |
| *-eu* → *-eux* | cheveu, jeu | cheveux, jeux | *bleu, pneu* (voir ci-dessus) |
| *-al* → *-aux* | cheval, journal | chevaux, journaux | *bal → bals*, *carnaval → carnavals*, *festival → festivals*, *chacal → chacals*, *opéra → opéras*, *pastel → pastels* |
| *-ail* → *-ails* | détail, seuil | détails, seuils | *travail → travaux*, *corail → coraux*, *émail → émaux* |
| mots en *-ou* | bijou, genou, chou, caillou, hibou, joujou | bijoux, genoux, choux, cailloux, hiboux, joujoux | tous les autres : *clou → clous*, *trou → trous* |
| mots invariables | après-midi | après-midi | aussi : *des ciseaux, des lunettes, des vacances, des funérailles* (toujours au pluriel) |
:::

:::formule Les pluriels réguliers
La plupart des noms prennent **-s** au pluriel (*un élève → des élèves*) ; ceux en *-eau, -au, -eu, -al, -ail* suivent le tableau ci-dessus. Les mots en *-eau* prennent aussi *-x* devant une voyelle : *le **beau** jour*, *les **beaux** jours*.
:::

### Les homophones et les mots difficiles

:::formule Les homophones du BFEM
| Mots | Différence | Exemple |
| --- | --- | --- |
| **à / a** | *à* = préposition ; *a* = verbe *avoir* | *Il est **à** Thiès.* / *Il **a** son cahier.* |
| **et / est** | *et* = liaison ; *est* = verbe *être* | *Toi **et** moi.* / *Elle **est** fatiguée.* |
| **ou / où** | *ou* = alternation ; *où* = lieu ou temps | *Mardi **ou** mercredi ?* / ***Où** habites-tu ?* |
| **son / sont / s’en** | déterminant / verbe *être* / pronom | *son cahier* / *ils **sont** là* / *il **s’en** va* |
| **ce / se** | déterminant démonstratif / pronom réfléchi | *ce livre* / *il **se** repose* |
| **leur / leurs** | singulier / pluriel | *à **leur** avis* / ***leurs** cahiers* |
:::

:::erreur Les mots souvent mal écrits
Écris bien : *malgré, néanmoins, cependant, lorsqu’on, puisque, quoique, bien qu’, aussitôt, exercice, difficile, agréable, heureux, parce que, d’après, déjà, beaucoup*. Dans la dictée, souligne d’abord les homophones (*à/a, ou/où, et/est*), ils causent la plupart des fautes.
:::

:::piege Le piège du pluriel en dictée
La plupart des mots en *-al* prennent *-aux* (*journal → journaux*), mais certains prennent *-s* : *festival → festivals*, *bal → bals*, *carnaval → carnavals*. Et n’oublie pas : *les travaux* (et non *les travailes*), mais *les détails*.
:::

## Ce qu’il faut retenir

- Le participe passé s’accorde avec le **sujet** après *être*, avec le **COD placé avant** après *avoir*, et avec le **sujet** aux verbes pronominaux (sauf COD personnel après).
- *Il y a*, *en*, *y* et les expressions *ci-joint, vu, attendu* restent **invariables**.
- Sujet composé avec *et* → pluriel ; *chacun, personne, rien, on* → singulier ; *plusieurs, beaucoup de* → pluriel.
- Les pluriels irréguliers : *-eau/-au → -eaux*, *-eu → -eux*, *-al → -aux*, *-ail → -ails*, les six mots en *-ou*.
- Dans la dictée, traque d’abord les homophones : *à/a, et/est, ou/où, son/sont, ce/se, leur/leurs*.
