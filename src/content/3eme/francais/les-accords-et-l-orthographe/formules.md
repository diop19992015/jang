## La formation du participe passé

| Groupe | Règle | Exemple |
| --- | --- | --- |
| 1er groupe (*-er*) | base + *-é* | *chanter → chanté*, *travailler → travaillé* |
| 2e groupe (*-ir*) | base + *-i* | *finir → fini*, *choisir → choisi* |
| 3e groupe | irréguliers | *avoir → eu*, *être → été*, *faire → fait*, *voir → vu*, *prendre → pris*, *écrire → écrit*, *lire → lu*, *mettre → mis*, *venir → venu*, *mourir → mort*, *naître → né*, *ouvrir → ouvert*, *devoir → dû* |

## Les accords du participe passé

:::formule Les trois règles d’or
- **Auxiliaire *être*** : accord toujours avec le **sujet** : *Elle est arrivée*, *Ils sont partis*.
- **Auxiliaire *avoir*** : jamais d’accord avec le sujet ; accord avec le COD **seulement placé avant** : *La lettre qu’il a écrite* / *Il a écrit la lettre*.
- **Verbe pronominal** : accord avec le **sujet**, sauf s’il y a un COD personnel placé après : *Elles se sont lavées* / *Elles se sont lavé les mains*.
:::

| Phrase | Accord ? | Pourquoi |
| --- | --- | --- |
| *Elle a mangé des mangues* | non | COD *des mangues* après le verbe |
| *Les mangues qu’elle a mangées* | oui (*mangées*) | COD avant le verbe |
| *Je les ai mangées* | oui | pronom COD *les* avant le verbe |
| *J’en ai mangé trois* | non | *en* n’est jamais le COD complet |
| *Il y a eu des incidents* | non | *il y a* est invariable |
| *Les élèves sont sortis* | oui (*sortis*) | accord avec le sujet après *être* |
| *Elles se sont réjouies* | oui | pronominal, COD = sujet |
| *Vous trouverez ci-joint le bulletin* | non | expression administrative invariable |

:::remarque Participes invariables ou adjectivaux
Les participes employés seuls se comportent comme des adjectifs et s’accordent : *un homme **mort** au combat*, *des fleurs **écloses***. Restent invariables : *ci-joint, vu, attendu, supposé, étant donné*.
:::

## Les accords difficiles

| Cas | Règle | Exemple |
| --- | --- | --- |
| Sujet + *et* | verbe au pluriel | *Aminata et Moussa **travaillent*** |
| *ou*, *ni…ni* | accord avec le plus proche (pluriel si même nature) | *Ni le professeur ni les élèves n’**étaient** là* |
| *chacun, chaque, quelqu’un, personne, rien, un, on* | singulier | *Chacun **a** son cahier* |
| *plusieurs, beaucoup de, la plupart, un certain nombre de* | pluriel | *Plusieurs élèves **ont** réussi* |
| Attribut avec *être / devenir* | accord avec le sujet | *Elles sont devenu**es** professeures* |
| Nom attribut après *être* | invariable | *Elle est devenue médecin* |
| Adjectif | genre + nombre | *de joli**es** filles*, *un petit garçon* |
| Quantité avant un nom | déterminant invariable | *beaucoup de leçons*, *peu de temps* |
| *ce qui / ce que* | *ce qui* = sujet, *ce que* = COD | *Ce qui **m’étonne**, c’est **ce que** tu dis* |

:::formule Test rapide du sujet composé
$$
\text{sujet composé avec } et \;\Rightarrow\; \text{verbe au pluriel}
$$

Sauf si les sujets désignent **une seule et même personne** : *Le directeur et principal est arrivé* (une seule personne).
:::

## Les pluriels irréguliers

| Singulier | Pluriel | Règle |
| --- | --- | --- |
| *tableau, journal, bateau* | *tableaux, journaux, bateaux* | *-eau, -au → -eaux* |
| *bleu, pneu* | *bleus, pneus* | exceptions : *-eu → -s* |
| *cheveu, jeu, lieu* | *cheveux, jeux, lieux* | *-eu → -eux* |
| *cheval, journal* | *chevaux, journaux* | *-al → -aux* |
| *bal, carnaval, festival, chacal, choral, opéra, pastel, régal* | *bals, carnavals, festivals…* | exceptions : *-al → -s* |
| *travail, corail, émail* | *travaux, coraux, émaux* | exceptions : *-ail → -aux* |
| *détail, seuil, éventail* | *détails, seuils, éventails* | *-ail → -ails* |
| *bijou, genou, chou, caillou, hibou, joujou* | *bijoux, genoux, choux, cailloux, hiboux, joujoux* | mots en *-ou → -oux* |
| *clou, trou* | *clous, trous* | tous les autres mots en *-ou* prennent *-s* |
| *après-midi* | *après-midi* | invariable |
| *ciseaux, lunettes, vacances, funérailles* | — | toujours au pluriel |

:::remarque Les quatre groupes à réciter
*Les journaux, les chevaux, les travaux, les bijoux* : chacun illustre une règle différente. Si tu hésites encore, écris le singulier au brouillon avant de faire le pluriel.
:::

## Les homophones

| Mots | Fonction | Exemple |
| --- | --- | --- |
| *à* | préposition | *Il va **à** Saint-Louis* |
| *a* | verbe *avoir* | *Il **a** son livre* |
| *et* | conjonction de coordination | *Fatou **et** Khady* |
| *est* | verbe *être* | *Elle **est** arrivée* |
| *ou* | conjonction de choix | *Mardi **ou** mercredi* |
| *où* | pronom interrogatif (lieu, temps) | ***Où** es-tu ?* |
| *son* | déterminant possessif | ***son** cahier* |
| *sont* | verbe *être* | *ils **sont** là* |
| *s’en* | pronom + en | *il **s’en** va* |
| *ce* | déterminant démonstratif | ***ce** texte* |
| *se* | pronom réfléchi | *il **se** repose* |
| *leur* | déterminant singulier | ***leur** avis* |
| *leurs* | déterminant pluriel | ***leurs** cahiers* |

:::remarque Méthode de dictée
Souligne d’abord, au brouillon, tous les mots qui peuvent être des homophones (*à, a, et, est, ou, où, ce, se, son, sont, leur, leurs*), choisis le bon selon la fonction, puis écris le reste. Tu élimines ainsi la majorité des fautes d’orthographe d’usage.
:::
