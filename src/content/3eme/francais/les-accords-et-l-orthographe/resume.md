## L’essentiel du chapitre

:::formule Les trois règles d’or du participe passé
| Auxiliaire | Règle | Exemple |
| --- | --- | --- |
| *être* | s’accorde avec le **sujet** | *Elles sont arriv**ées*** |
| *avoir* | s’accorde avec le COD **seulement si le COD est avant** | *Les lettres qu’elle a écrite**s*** / *Elle a écrit les lettres* |
| pronominal | s’accorde avec le **sujet** (sauf COD personnel après) | *Elles se sont réjoui**es*** / *se sont lavé les mains* |
:::

:::formule Invariables à connaître
*Il y a…* · *en* · *y* · *ci-joint, vu, attendu, supposé, étant donné* : jamais d’accord.
*Avec avoir + COD après* : *J’ai lu les livres* (et non *lus*).
:::

:::formule Les accords difficiles
| Cas | Règle | Exemple |
| --- | --- | --- |
| Sujet composé avec *et* | pluriel | *Aminata et Moussa arriv**ent*** |
| *chacun, quelqu’un, personne, rien, on* | singulier | *Chacun a **son** cahier* |
| *plusieurs, beaucoup de, la plupart* | pluriel | *Plusieurs élèves **ont** réussi* |
| Attribut avec *être* | s’accorde avec le sujet | *Elles sont devenu**es** professeures* |
| Nom attribut après *être* | invariable | *Elle est devenue médecin* |
:::

:::formule Les pluriels irréguliers
| Terminaison | Pluriel | Exemple | Exceptions |
| --- | --- | --- | --- |
| *-eau, -au* | *-eaux* | *tableaux, journaux* | *bleus, pneus, lieux* |
| *-eu* | *-eux* | *cheveux, jeux* | *bleus, pneus* |
| *-al* | *-aux* | *chevaux, journaux* | *bals, carnavals, festivals, opéras* |
| *-ail* | *-ails* | *détails, seuils* | *travaux, coraux, émaux* |
| *-ou* | *-oux* | *bijoux, genoux, choux, cailloux, hiboux, joujoux* | tous les autres : *clous, trous* |
:::

:::formule Les homophones
*à* (préposition) / *a* (avoir) · *et* (liaison) / *est* (être) · *ou* (alternation) / *où* (lieu, temps) · *son* (déterminant) / *sont* (être) / *s’en* (pronom) · *ce* / *se* · *leur* (singulier) / *leurs* (pluriel).
:::

## Méthode express

1. **Participe passé** : identifie l’auxiliaire (*être / avoir / pronominal*).
2. Repère le COD : **avant** le verbe → accord ; **après** → rien ; *en / y / il y a* → rien.
3. **Sujet composé** : *et* → pluriel ; *chacun, personne, rien, on* → singulier ; *plusieurs, beaucoup de* → pluriel.
4. **Pluriel** : regarde la terminaison du singulier (*-eau, -al, -eu, -ail, -ou*) et applique la table.
5. **Dictée** : chasse d’abord les homophones (*à/a, ou/où, et/est*), puis relis les mots difficiles.

:::erreur Les erreurs qui coûtent des points
1. *Les filles ont fini**es** leurs leçons* → COD après : *ont fini* sans accord.
2. *Elle est allé à l’école* → avec *être*, accord avec le sujet : *elle est allée*.
3. Écrire *ils y ont eu des incidents* → on dit toujours *il y a eu des incidents* : l’expression *il y a* est invariable.
4. *beaucoup **des** leçons* → *beaucoup de leçons*.
5. *un festival**s*** ou *le travail**s*** → *festivals*, *travaux* : les exceptions comptent !
:::

## Vocabulaire

- **Participe passé** : forme du verbe invariable ou accordable (*écrit, finis, allées*).
- **Auxiliaire** : verbe *avoir* ou *être* qui aide à former les temps composés.
- **COD placé avant** : complément qui se trouve avant le verbe, souvent pronom (*les, la, l’, leur, en*).
- **Verbe pronominal** : verbe accompagné de *se* (*se réjouir, se laver*).
- **Attribut du sujet** : qualité ou identité attribuée au sujet par un verbe d’état (*être, devenir*).
- **Sujet composé** : sujet formé de plusieurs noms ou pronoms reliés par *et, ou, ni…ni*.
- **Homophone** : mot qui s’écrit pareil qu’un autre mais avec un sens différent (*ou / où*).
- **Orthographe d’usage** : règles de pluriel et mots qui s’écrivent selon la tradition.
