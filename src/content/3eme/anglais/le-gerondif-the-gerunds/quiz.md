## Question

Complétez : *I enjoy ___ English every day.*

- [ ] to learn
- [x] learning
- [ ] learn
- [ ] to learning

> *enjoy* appartient aux verbes qui exigent le gérondif : *enjoy + verbe-en-ing*. L’infinitif (*to learn*) est impossible après *enjoy*, et le verbe nu ne peut pas suivre un verbe déjà conjugué.

## Question

Complétez : *She is interested in ___ mathematics.*

- [ ] to study
- [x] studying
- [ ] study
- [ ] she studies

> *in* est une **préposition** : toute préposition suivie d’un verbe exige le gérondif en *-ing*. On n’écrit jamais ~~*interested in study*~~ ni ~~*interested in to study*~~.

## Question

Dans « He stopped smoking last year », que signifie la phrase ?

- [ ] Il s’est arrêté pour fumer.
- [x] Il a arrêté de fumer.
- [ ] Il a essayé de fumer.
- [ ] Il a continué de fumer.

> *stop + -ing* = **arrêter de faire** une action : *stopped smoking* = il a cessé de fumer. *He stopped **to** smoke* voudrait dire « il s’est arrêté **pour** fumer » (il a fait une pause).

## Question

Quelle phrase est correcte ?

- [ ] It’s no use to cry.
- [ ] How about to go to the beach?
- [x] It’s worth reading this book.
- [ ] I want passing the BFEM.

> *it’s worth* est une expression qui réclame obligatoirement le gérondif : ***worth reading***. Les trois autres sont fautives : *it’s no use **crying***, *How about **going**?*, *I want **to pass** the BFEM* (verbe à infinitif).
