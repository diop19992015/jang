## L’essentiel du chapitre

:::formule Qu’est-ce que le gérondif ?
$$
\text{verbe} + \text{-ing} = \text{gérondif (utilisé comme un nom)}
$$

- ***Swimming** is healthy.* (Nager, c’est sain.) → sujet = nom ⇒ gérondif.
- *They **are swimming**.* (Ils nagent.) → verbe conjugué ⇒ pas un gérondif.
:::

:::formule Les fonctions du gérondif
| Fonction | Exemple | Traduction |
| --- | --- | --- |
| Sujet | ***Getting up** early is hard.* | Se lever tôt, c’est dur. |
| COD | *I **enjoy reading**.* | J’aime lire. |
| Après une préposition | *He left **without saying** bye.* | Il est parti sans dire au revoir. |
| Attribut | *My hobby is **drawing**.* | Mon passe-temps, c’est dessiner. |
:::

:::formule Verbes + gérondif (-ing)
*admit, avoid, can’t stand, consider, discuss, enjoy, finish, give up, imagine, keep, mind, miss, practise, postpone, put off, suggest*

- *I **enjoy learning** English.* — *She **finished writing**.* — *He **gave up smoking**.*
:::

:::formule Verbes + infinitif (to)
*afford, agree, choose, decide, expect, hope, learn, manage, need, offer, plan, promise, refuse, seem, want, wish, would like*

- *I **want to pass** the BFEM.* — *They **decided to leave**.*
:::

:::formule Les deux, avec un changement de sens
| Verbe | + -ing | + to |
| --- | --- | --- |
| stop | *stop **smoking*** (arrêter de fumer) | *stop **to smoke*** (s’arrêter **pour** fumer) |
| remember | *remember **locking*** (se souvenir d’avoir verrouillé) | *remember **to lock*** (se souvenir de verrouiller) |
| try | *try **using*** (essayer d’utiliser) | *try **to open*** (essayer d’ouvrir) |
| like / love / hate | *I like **swimming*** | *I like **to swim** early* |
:::

:::formule Préposition + -ing (la règle d’or)
**Toute préposition** est suivie d’un nom ou d’un **-ing**, jamais de *to + infinitif* :

- *interested **in learning*** (et non ~~*in learn*~~ / ~~*to learn*~~)
- *good **at drawing***, *without **asking***, *by **reading***, *instead of **staying***
- *look forward **to seeing***, *be used **to getting** up early*
:::

:::formule Expressions fixes à -ing
*It’s no use crying · It’s worth reading · I can’t help laughing · She is busy preparing · How about going? · I feel like swimming*
:::

## Méthode express

1. Repérer la **préposition** devant le verbe → **-ing** (c’est la règle la plus sûre).
2. Regarder le verbe qui commande : liste « gérondif » (*enjoy, avoid, finish, mind, keep, give up…*) → **-ing** ; liste « infinitif » (*want, hope, decide, would like…*) → **to**.
3. Vérifier les expressions figées : *it’s no use -ing, it’s worth -ing, how about -ing?*
4. Attention aux verbes à double sens : *stop doing* (arrêter de faire) vs *stop to do* (s’arrêter pour faire).
5. Test final : après une préposition, relis la phrase et remplace par un nom → si c’est possible, le verbe doit être en *-ing*.

:::erreur Les erreurs qui coûtent des points
1. ~~*I enjoy **to read**.*~~ → *I enjoy **reading**.*
2. ~~*I want **reading**.*~~ → *I want **to read**.*
3. ~~*He is interested in **learn** English*~~ → *… in **learning** English*.
4. ~~*It’s no use **to cry**.*~~ → *It’s no use **crying**.*
5. ~~*How about **to go** to the beach?*~~ → *How about **going** to the beach?*
6. Confondre le gérondif et le présent continu : *I like **swimming*** (gérondif, COD) vs *I am **swimming*** (verbe conjugué).
:::

## Vocabulaire

- **Gérondif (gerund)** : verbe en *-ing* utilisé comme un nom.
- **Infinitif (infinitive)** : verbe avec *to* : *to read, to go*.
- **Préposition (preposition)** : *in, at, of, without, about*… toujours suivie d’un nom ou d’un *-ing*.
- **COD (direct object)** : le complément qui répond à Quoi ? Qui ? : *I enjoy **reading***.
- **Verbe à gérondif** : *enjoy, avoid, finish, mind*…
- **Verbe à infinitif** : *want, hope, decide, plan*…
- **Expression figée** : groupe à sens constant : *it’s worth -ing, look forward to -ing*.
- **Changement de sens** : *stop to do* ≠ *stop doing*.
