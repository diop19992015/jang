## La structure générale du passif

:::formule Schéma à retenir
$$
\text{Sujet} + \text{be} + \text{participe passé (V3)} + (\text{by + agent})
$$

| Voix | Sujet | Verbe | Complément |
| --- | --- | --- | --- |
| Active | agent | verbe conjugué | COD |
| Passive | ancien COD | be + V3 | *by + agent* (facultatif) |
:::

:::remarque Le test pour trouver le sujet du passif
Pose la question « Quoi ? / Qui ? » après le verbe de la phrase active : la réponse devient le sujet de la phrase passive.
:::

## Le passif dans tous les temps

:::formule Tableau complet : *to write* et *to clean*
| Temps | Actif | Passif |
| --- | --- | --- |
| Present simple | *He writes a note.* | *A note **is written**.* |
| Present continuous | *He is writing a note.* | *A note **is being written**.* |
| Present perfect | *He has written a note.* | *A note **has been written**.* |
| Past simple | *He wrote a note.* | *A note **was written**.* |
| Past continuous | *He was writing a note.* | *A note **was being written**.* |
| Past perfect | *He had written a note.* | *A note **had been written**.* |
| Future simple | *He will write a note.* | *A note **will be written**.* |
| Present simple (pluriel) | *They clean the room.* | *The room **is cleaned**.* |
| Past simple (pluriel) | *They cleaned the room.* | *The room **was cleaned**.* |
| Modaux | *They can clean the room.* | *The room **can be cleaned**.* |
:::

## Correspondance des temps : actif → passif

| Temps du verbe actif | « be » à utiliser | Participe |
| --- | --- | --- |
| Présent simple | am / is / are | V3 |
| Présent continu | am / is / are **being** | V3 |
| Present perfect | has / have **been** | V3 |
| Passé simple | was / were | V3 |
| Passé continu | was / were **being** | V3 |
| Past perfect | had **been** | V3 |
| Futur simple | will **be** | V3 |
| Modal | can / must / should / may **be** | V3 |

:::formule Les trois formules à écrire les yeux fermés
- Présent : *The room **is cleaned** every day.*
- Passé : *The room **was cleaned** yesterday.*
- Futur : *The room **will be cleaned** tomorrow.*
:::

## Les cas particuliers

### Verbes + préposition : la préposition reste

| Actif | Passif |
| --- | --- |
| *talk about* | *be talked about* |
| *laugh at* | *be laughed at* |
| *look at* | *be looked at* |
| *look after* | *be looked after* |
| *listen to* | *be listened to* |
| *worry about* | *be worried about* |
| *pay for* | *be paid for* |

### Verbes à deux compléments : deux passifs possibles

:::formule Give / send / show / teach / lend / offer / buy / write
- *The teacher gave **the pupils** **a book**.*
- *The pupils **were given** a book.* (complément de personne en sujet)
- *A book **was given to** the pupils.* (complément de chose en sujet)
:::

### Verbes sans passif

:::remarque Intransitifs
*be, have, belong to, happen, occur, take place, arrive, come, go, die, seem, appear, last* n’ont **jamais** de passif car ils n’ont pas de COD.
:::

### Passif impersonnel et questions

:::formule Structures supplémentaires
- *It is said that the thief was arrested.* → *The thief **is said to be** arrested.*
- *It is believed that…* → *… **is believed to**…*
- Question : ***Was** the letter **posted**?* — Négation : *The letter **was not posted**.*
- Question sur un mot : *It was written **yesterday**.* → ***When was** it written?*
:::

## Les participes passés irréguliers les plus utiles

| Verbe | V2 (passé simple) | V3 (participe passé) |
| --- | --- | --- |
| write | wrote | written |
| give | gave | given |
| take | took | taken |
| make | made | made |
| steal | stole | stolen |
| send | sent | sent |
| buy | bought | bought |
| teach | taught | taught |
| build | built | built |
| keep | kept | kept |
| clean | cleaned | cleaned |
| post | posted | posted |

:::remarque Où trouver la liste complète ?
Le tableau des participes irréguliers se trouve aussi dans la fiche des temps du passé : apprends *write–wrote–written*, car le passif du futur (*will be written*) en dépend directement.
:::
