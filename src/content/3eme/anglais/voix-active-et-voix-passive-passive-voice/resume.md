## L’essentiel du chapitre

:::formule La structure du passif
$$
\text{Sujet (ce qui subit)} + \text{be} + \text{participe passé (V3)} + (\text{by + agent})
$$

- Active : *The teacher wrote a note.* (Le maître a écrit un mot.)
- Passive : *A note was written by the teacher.* (Un mot a été écrit par le maître.)
:::

:::formule Le passif dans tous les temps
| Temps | Passif | Exemple |
| --- | --- | --- |
| Present simple | is/are + V3 | *The room **is cleaned** every day.* |
| Present continuous | is/are being + V3 | *The room **is being cleaned** now.* |
| Present perfect | has/have been + V3 | *The room **has been cleaned**.* |
| Past simple | was/were + V3 | *The room **was cleaned** yesterday.* |
| Past continuous | was/were being + V3 | *The room **was being cleaned** when I came.* |
| Future simple | will be + V3 | *The room **will be cleaned** tomorrow.* |
| Modaux | can/must/should be + V3 | *The room **must be cleaned**.* |
:::

:::formule Les emplois du passif
- L’agent est **inconnu** : *My bike was stolen.* (Mon vélo a été volé.)
- L’agent est **évident ou sans intérêt** : *English is spoken here.*
- Langue officielle, presse, consignes : *The results will be published next month.*
:::

:::formule Les cas particuliers
- Verbe + préposition : *The joke **was laughed at**.* (la préposition reste)
- Deux compléments : *The pupils **were given** a book* = *A book **was given to** the pupils.*
- Passif impersonnel : *It is said that…* → *He **is said to be**…*
- Passif avec *get* : *He **got hurt**.* (Il s’est fait mal.)
:::

## Méthode express

1. Repérer le **COD** de la phrase active (quoi ? / qui ? après le verbe).
2. Faire de ce COD le **sujet** de la nouvelle phrase.
3. Choisir le temps de **be** = temps exact du verbe actif.
4. Mettre le verbe au **participe passé** (V3).
5. Ajouter **by + agent** seulement si l’agent est vraiment utile.
6. Vérifier la question ou la négation : l’inversion se fait avec *be* (*Was it stolen? — It wasn’t stolen.*).

:::erreur Les erreurs qui coûtent des points
1. Oublier *be* : ~~*The letter written*~~ → ***The letter was written***.
2. Confondre V2, V3 et *being* : au passé continu, c’est *was being written*, pas ~~*was written*~~.
3. Supprimer la préposition des verbes à particule : ~~*The joke was laughed*~~ → ***was laughed at***.
4. Écrire un passif impossible : ~~*The accident was happened*~~ → ***The accident happened***.
5. Mettre l’agent avec *by* alors qu’on peut le supprimer : *The letter was written by my cousin* (utile) / *English is spoken ~~by many countries~~* (inutile).
:::

## Vocabulaire

- **Voix active (active voice)** : le sujet fait l’action.
- **Voix passive (passive voice)** : le sujet subit l’action.
- **Agent** : celui qui fait l’action, placé après *by*.
- **Participe passé (past participle, V3)** : *written, cleaned, stolen*.
- **Patient** : la personne ou la chose qui subit l’action.
- **Verbe à particule** : verbe + préposition (*talk about, look after*).
- **Passif impersonnel** : *It is said that…* (On dit que…).
- **Verbe intransitif** : verbe sans COD, donc sans passif (*happen, arrive, die*).
