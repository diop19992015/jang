## L’essentiel du chapitre

:::formule Futur avec will
- **Structure** : **will + base verbale** (jamais de *to*, jamais de *-s*).
- **Usage** : décision prise sur le moment, promesse, offre, prédiction.
- Négation : *will not (**won’t**)* — Question : ***Will** + sujet + base ?*
- Exemple : *I **will help** you tomorrow.* (Je t’aiderai demain.)
:::

:::formule Futur avec be going to
- **Structure** : **am / is / are + going to + base verbale**.
- **Usage** : projet déjà décidé, action proche visible à l’œil.
- Exemple : *We **are going to visit** Gorée next holiday.* (Nous allons visiter Gorée les prochaines vacances.)
:::

:::formule Présent à valeur de futur
- **Structure** : **présent simple** (parfois présent continu) avec une date future.
- **Usage** : horaires, programmes officiels, rendez-vous fixés ; aussi après *when, if, before, as soon as*.
- Exemple : *The bus **leaves** at 8 tomorrow.* (Le bus part demain à 8 h.)
:::

:::formule Will ou going to ou présent ?
| Situation | Moyen | Phrase |
| --- | --- | --- |
| Je décide en parlant | will | *I’m cold. I **will close** the window.* |
| C’était mon plan | be going to | *I **am going to close** the window at 6.* |
| C’est à l’horaire | présent simple | *The window cleaner **comes** at 9 tomorrow.* |
:::

## Méthode express

1. Repérer les marqueurs du futur : *tomorrow, next week, soon, in 2027, at 6 o’clock*.
2. Horaire ou programme écrit → **présent simple** (*leaves, starts, begins*).
3. Projet décidé à l’avance ou signe visible (nuages, sourire…) → **be going to**.
4. Décision soudaine, promesse, offre, prédiction → **will**.
5. Vérifier la construction : *will + base* / *am-is-are + going to + base* (pas de *-s*, pas d’infinitif).

:::erreur Les erreurs qui coûtent des points
1. ~~will goes / will to go~~ → *will **go***.
2. ~~They going to play~~ → *They **are going to play***.
3. ~~He is going to plays~~ → *He is going to **play***.
4. *The train will leave at 9* pour un horaire officiel → préfère *The train **leaves** at 9* (valeur de programme).
5. Oublier *won’t* pour la négation : ~~will not comes~~ → *won’t **come***.
:::

## Vocabulaire

- **Will (heureux !)** : auxiliaire du futur, invariable après le sujet.
- **Be going to** : futur du projet, avec *be* conjugué (*am/is/are*).
- **Base verbale** : infinitif sans *to* (*go, leave, start*).
- **Prédiction** : dire ce qu’on pense qui va arriver (*I think it will…*).
- **Promesse / offre** : *I will…* (je le ferai / je te le ferai).
- **Horaire / timetable** : programme fixé à l’avance (bus, cours, examens).
- **Projet / plan** : décision prise avant de parler (→ *be going to*).
- **Marqueur temporel** : mot-repère (*tomorrow, next week*…).
- **Conjonction de temps** : *when, before, as soon as* (présent simple pour le futur après *when/if*).
