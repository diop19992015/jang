## L’essentiel du chapitre

:::formule Les quatre types de conditionnelles
| Type | Sens | Condition (if…) | Conséquence | Exemple |
| --- | --- | --- | --- | --- |
| **0** | vérité générale | présent simple | présent simple | *If you heat water, it boils.* |
| **1** | réel / probable | présent simple | *will* + infinitif | *If it rains, we will stay at home.* |
| **2** | irréel présent (conseil) | prétérit | *would* + infinitif | *If I were you, I would revise.* |
| **3** | irréel passé (regret) | past perfect | *would have* + V3 | *If he had revised, he would have passed.* |
:::

:::formule La structure
**Condition (if-clause) + virgule + conséquence (main clause)**
- Condition en tête : *If you revise, you will pass.*
- Condition à la fin : *You will pass if you revise.* (pas de virgule)
:::

:::formule Type 2 : le conseil
*If I **were** you, I **would** work harder.* (Si j’étais toi, je travaillerais plus.)
→ *were* avec tous les sujets à l’écrit.
:::

:::formule Unless = if… not
*If you **do not** revise, you will fail* = ***Unless** you revise, you will fail.* (Jamais de *not* après *unless*.)
:::

## Méthode express

1. Lire la phrase et se demander : la condition est-elle **générale** (type 0), **probable** (type 1), **imaginaire maintenant** (type 2) ou **passée et impossible** (type 3) ?
2. Appliquer le tableau : type 0 → présent + présent ; type 1 → présent + *will* ; type 2 → prétérit + *would* ; type 3 → past perfect + *would have* + V3.
3. Vérifier la règle d’or : **jamais de *will* après *if***.
4. Placer la virgule si la condition est en tête.
5. Repérer les mots-pièges : *when* (certain) ≠ *if* (possible), *unless* = *if… not*.

:::erreur Les erreurs qui coûtent des points
1. ~~*If you will revise, you will pass*~~ → *If you revise, you will pass*.
2. ~~*If I would have money…*~~ → *If I had money, I would buy a bike.*
3. ~~*If he had revised, he would pass*~~ → *If he had revised, he **would have** passed.*
4. ~~*If I was you…*~~ (à l’écrit) → *If I **were** you…*
5. Oublier la virgule : ~~*If it rains we will stay*~~ → *If it rains**,** we will stay.*
:::

## Vocabulaire

- **a conditional sentence** : une phrase conditionnelle.
- **the if-clause** : la proposition de condition (celle avec *if*).
- **the main clause** : la proposition principale (la conséquence).
- **a general truth** : une vérité générale (type 0).
- **real / unreal** : réel / irréel.
- **a regret** : un regret (type 3 : *if only…* = si seulement…).
- **to revise** : réviser, réviser ses leçons.
- **to pass / to fail (an exam)** : réussir / échouer à un examen.
- **unless** : à moins que, si… ne.
- **would rather** : préférer (voir le chapitre sur les préférences).
