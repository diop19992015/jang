## Question

Quelle phrase est au **type 1** (condition réelle) ?

- [ ] If I were you, I would revise every evening.
- [x] If you revise your lessons, you will pass the BFEM.
- [ ] If you heat water, it boils.
- [ ] If he had got up early, he would have caught the bus.

> Le type 1 combine **présent simple dans la condition** et **will + infinitif dans la conséquence** : *If you revise, you will pass*. La première est un type 2 (prétérit + *would*), la troisième un type 0 (présent + présent), la quatrième un type 3 (past perfect + *would have*).

## Question

Complète : « If it ______ tomorrow, we will stay at home. »

- [ ] will rain
- [x] rains
- [ ] rained
- [ ] would rain

> Après *if*, on met toujours le **présent simple** : *If it rains, we will stay at home*. Le futur est déjà marqué par *will* dans la conséquence ; écrire ~~*will rain*~~ est l’erreur la plus sanctionnée au BFEM.

## Question

Quelle est la forme correcte d’un conseil au **type 2** ?

- [ ] If I was you, I would work harder.
- [ ] If I would be you, I will work harder.
- [x] If I were you, I would work harder.
- [ ] If I had been you, I would have worked harder.

> Au type 2 (irréel présent), on écrit **if + prétérit** avec *were* pour tous les sujets, puis **would + infinitif** : *If I were you, I would work harder*. *If I had been… would have worked* exprimerait un regret passé (type 3).

## Question

Quelle phrase exprime un regret passé (type 3) ?

- [ ] If you revise, you will pass the BFEM.
- [ ] If I had a bicycle, I would ride to school.
- [x] If Moussa had revised, he would have passed the BFEM.
- [ ] If it rains, the roads become flooded.

> Le type 3 associe **past perfect (had + V3)** dans la condition et **would have + participe passé** dans la conséquence : *If Moussa had revised, he would have passed*. C’est le seul schéma qui exprime un regret sur un fait révolu.
