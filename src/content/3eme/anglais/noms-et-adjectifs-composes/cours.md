:::remarque À quoi ça sert au BFEM ?
Les noms composés (*school bag, mother-in-law, ice cream*) et les adjectifs composés (*well-known, six-year-old, French-speaking*) sont partout dans les textes du BFEM : titres d’articles, horaires, présentations de personnes. Le correcteur aime tester le **trait d’union** et surtout le **pluriel** (*sons-in-law*, ~~*son-in-laws*~~) : deux points faciles à gagner si on connaît les trois règles de composition.
:::

## Rappel : nom et adjectif

- un **nom** désigne une personne, un animal, une chose ou une idée : *a pupil, the sun, courage* ;
- un **adjectif** qualifie un nom : *a **clever** pupil, the **hot** sun*.

Un **mot composé** (compound word) est formé de deux mots (parfois trois) réunis en un seul concept.

## Les noms composés

:::definition Nom composé
Un **nom composé** (*compound noun*) est un nom formé de deux mots qui fonctionnent ensemble : le deuxième mot est le nom principal, le premier le complète ou le qualifie.
:::

:::formule Les trois façons de former un nom composé
| Type | Exemple | Traduction |
| --- | --- | --- |
| Deux mots écrits **séparément** | *a school bag, a swimming pool, a post office* | cartable, piscine, bureau de poste |
| Deux mots avec **trait d’union** | *a son-in-law, a mother-in-law, a brother-in-law* | beau-fils, belle-mère, beau-frère |
| Un seul mot (fusion) | *a blackboard, a bedroom, a football, sunshine* | tableau, chambre, football, ensoleillement |
:::

:::formule Les types les plus courants
| Type | Construction | Exemple |
| --- | --- | --- |
| nom + nom | le 1er complète le 2e | *a **book** shop* (librairie), *a **bus** stop* |
| adj + nom | le qualifie | *a **black** board*, *a **high** school* |
| nom + **-ing** | activité | *a **swimming** pool, **reading** glasses* |
| nom/participle + **-ed** | état, caractéristique | *a **broken** window, **left** hand* |
| nom + **-er/-or** | personne ou machine | *a **driver**, a **worker**, a **computer*** |
| prép. + nom | relation de lieu | *an **indoor** game, an **onlooker*** |
:::

:::exemple Noms composés au quotidien au Sénégal
- *My **school bag** is heavy.* (Mon cartable est lourd.)
- *We bought **ice cream** near the beach.* (Nous avons acheté de la glace près de la plage.)
- *My **mother-in-law** lives in Saint-Louis.* (Ma belle-mère habite à Saint-Louis.)
- *The **post office** opens at eight.* (Le bureau de poste ouvre à huit heures.)
- *There is a **swimming pool** in our neighbourhood.* (Il y a une piscine dans notre quartier.)
:::

### Les grandes familles de noms composés

:::formule Les noms composés les plus utiles
| Famille | Exemples |
| --- | --- |
| La famille | *mother-in-law, father-in-law, brother-in-law, sister-in-law, son-in-law, daughter-in-law* |
| L’école | *school bag, school bus, school year, notebook, blackboard, classroom, homework, playground* |
| Les lieux | *post office, bus stop, police station, car park, market place, swimming pool, football pitch* |
| Le temps | *weekend, morning break, lunchtime, holiday maker, summer camp* |
| La nourriture | *ice cream, fruit juice, fried rice, peanut butter, breakfast, dinner time* |
| Les transports | *airplane, motorway, car park, ticket office, railway station* |
:::

:::remarque Le nom principal commande toujours
Dans *school **bag***, c’est *bag* qui est le nom : on dit *two school **bags***. Le premier mot (*school*) ne prend jamais le *-s* : il joue le rôle de **modificateur**, comme un adjectif.
:::

### Les noms composés dans une phrase

:::methode Repérer et analyser un nom composé
1. Cherche un **groupe de deux mots qui forme une seule idée** : *bus stop*, *ice cream*.
2. Identifie le **nom principal** : généralement le **deuxième** mot (*stop, cream*).
3. Au pluriel, mets le *-s* sur ce nom principal : *bus stops, ice creams*.
4. Vérifie l’orthographe dans le dictionnaire : certains composés s’écrivent en un seul mot (*blackboard*), d’autres séparés (*bus stop*), d’autres avec trait d’union (*mother-in-law*).
:::

:::exemple Une phrase, plusieurs noms composés
« After the **morning break**, the pupils bought **fruit juice** near the **bus stop**. »

Dans cette phrase : *morning break* (la récréation du matin), *fruit juice* (jus de fruit), *bus stop* (arrêt de bus) — trois noms composés, trois groupes de deux mots à ne pas séparer au pluriel : *the morning breaks, fruit juices, bus stops*.
:::

### Le pluriel des noms composés

:::formule Les trois règles du pluriel
| Type de nom composé | Où met-on le **-s** ? | Exemple |
| --- | --- | --- |
| Deux mots **séparés** | sur le **nom principal** (le 2e) | *school **bags**, bus **stops*** |
| Nom composé irrégulier | sur le mot qui porte le sens | *tooth**brush** → tooth**brushes***, *fireman → fire**men*** |
| Composition avec **-in-law** | sur le **premier** mot | *son**s**-in-law, mother**s**-in-law* |
| Noms composés à deux noms pluriels | sur les deux mots | *women doctors, men teachers* |
| Lettres et sigles | on ajoute **’s** | *There are two M.P.’s here.* (députés) |
:::

:::erreur Les pluriels fautifs
- ~~*sons-in-laws*~~ → ***sons-in-law*** (le trait d’union bloque le -s du second mot).
- ~~*school bags*~~ reste correct, mais ~~*schools bag*~~ est faux : c’est *bag* qui devient pluriel.
- ~~*moneys*~~ → ***money*** n’a pas de pluriel courant.
:::

:::piege Attention aux irréguliers composés
Certains noms composés prennent un pluriel irrégulier parce que le mot principal est irrégulier : *mother-in-law → mothers-in-law*, mais *man → men* : *firemen* (pompiers), *policemen* (policiers) ; *foot → feet* : *footprints* ; *tooth → teeth* : *toothbrushes*.
:::

## Les adjectifs composés

:::definition Adjectif composé
Un **adjectif composé** (*compound adjective*) réunit deux mots (souvent reliés par un trait d’union) pour qualifier un nom. Il se place **avant** le nom qu’il qualifie.
:::

:::formule Les types d’adjectifs composés
| Type | Exemple | Traduction |
| --- | --- | --- |
| adj + participe passé | *a **well-known** actor, a **newly-built** school* | célèbre, nouvellement construite |
| adj + adj | *a **grey-haired** man, a **cold-blooded**…* | aux cheveux gris |
| nom + participe en **-ing** | *a **French-speaking** country, a **football-loving** boy* | francophone, amateur de football |
| chiffre + nom (+ **-ed**) | *a **ten-year-old** boy, a **three-legged** table* | un garçon de dix ans, une table à trois pieds |
| adverbe + participe | *a **hard-working** pupil, a **well-dressed** woman* | travailleur, bien mis |
| prép. + nom | *an **off-road** vehicle, an **indoor** game* | tout-terrain, jeu en salle |
:::

:::exemple Les adjectifs composés en contexte
- *Thiès is a **French-speaking** city.* (Thiès est une ville francophone.)
- *He is a **hard-working** pupil.* (C’est un élève travailleur.)
- *My **six-year-old** sister started school.* (Ma petite sœur de six ans a commencé l’école.)
- *Our **newly-built** library is open now.* (Notre bibliothèque toute neuve est ouverte.)
:::

:::formule Accords et pluriel de l’adjectif composé
- L’adjectif composé **ne se décline pas** : il reste invariable devant le nom.
- Si un **chiffre** fait partie de l’adjectif, le nom après le trait d’union reste **singulier** : *a **ten-year-old** boy* (et non ~~*ten-years-old boy*~~).
- Mais le chiffre se met au pluriel quand il compte les unités : *two **ten-year-old** boys* (le *-s* est sur *ten*, pas sur *year*).

Exemple : *She has **two three-year-old** brothers.* (Elle a deux frères de trois ans.)
:::

:::methode Placer correctement un adjectif composé
1. Repère le **nom** à qualifier.
2. Cherche si l’idée demande deux mots : *an English teacher* (un prof d’anglais) vs *an **English-speaking** teacher* (un prof qui parle anglais).
3. Relie les mots par un trait d’union et place le groupe **avant** le nom.
4. Vérifie : si l’adjectif est après le nom, il n’a pas de trait d’union (*The boy is ten years old*).
:::

:::erreur Les erreurs qui coûtent des points
1. Oublier le trait d’union : ~~*a ten year old boy*~~ → ***a ten-year-old boy***.
2. Mettre le nom au pluriel dans l’adjectif : ~~*a ten-years-old boy*~~ → ***a ten-year-old boy***.
3. Placer l’adjectif composé après le nom avec un trait d’union : ~~*The boy is ten-year-old*~~ → *The boy is **ten years old***.
4. Confondre deux groupes différents : *a **high school** student* (un lycéen) ≠ *a **high-school** student* (trait d’union seulement si adjectif composé).
:::

## Ce qu’il faut retenir

- Un nom composé se forme en deux mots, avec trait d’union, ou en un seul mot : *school bag, son-in-law, blackboard*.
- Au pluriel, on déplace le **-s** : *school **bags***, mais ***son**s-in-law* (le trait d’union verrouille le second mot).
- L’adjectif composé se place **avant** le nom et reste **invariable**.
- Devant un nom, un chiffre dans un adjectif composé reste singulier : *a ten-year-old boy* ; le pluriel se marque sur le chiffre : *two **ten-year-old** boys*.
- *French-speaking, hard-working, well-known, newly-built* : le trait d’union est obligatoire.
- Toujours distinguer *an English teacher* (nom + nom) et *an English-speaking teacher* (adjectif composé).
