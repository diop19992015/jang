---
titre: Type BFEM — Noms et adjectifs composés
difficulte: 3
type: bfem
annee: 2023
indices:
  - Dans un texte, cherche d’abord les groupes de deux mots qui forment une seule idée (bus stop, hard-working…).
  - Pour le pluriel, identifie le nom principal puis vérifie s’il n’y a pas un -in-law ou un irrégulier.
  - Pour transformer en adjectif composé, relie les mots par un trait d’union et place le groupe avant le nom.
---

## Énoncé

Le texte suivant est composé à la manière d’un sujet de BFEM.

« Last Friday, a **(1)** ceremony took place in our school hall. The headmaster gave prizes to the **(2)** pupils of the year and thanked all the **(3)** for their work. During the party, the teachers served drinks and everybody brought **(4)**. The photos of the event were published in the local newspaper on **(5)**. »

**Partie A.** Complétez le texte par un nom ou un adjectif composé. Les indications vous aident. (5 × 1 point = 5 points)

1. (*well + know*) → qui est connu de tous
2. (*hard + work*) → qui travaille avec application
3. (*teach + -er*) → la personne qui enseigne
4. (*school + bag*) → où l’on range les cahiers
5. (*week + end*) → le samedi et le dimanche

**Partie B.** Transformez comme dans l’exemple.

*Example : a girl of six years old → a six-year-old girl*

6. *a boy of twelve years old* (1 point)
7. *a country where people speak French* (utilisez *French*) (1,5 point)
8. *All the bags of the school were lost.* (mettez *bag* au pluriel correct) (1,5 point)

**Partie C.** Questions de grammaire. (4 points)

9. Écrivez au pluriel : *a son-in-law*, *a school bus*. Justifiez la différence. (2 points)
10. Pourquoi écrit-on *a six-year-old girl* et non ~~*a six-years-old girl*~~ ? (1 point)
11. Dans la phrase 8, où se place le *-s* et pourquoi ? (1 point)

## Solution

**Partie A.**

1. ***well-known*** — adjectif composé *well* + *participe passé* : *a **well-known** ceremony* (une cérémonie bien connue / renommée).
2. ***hard-working*** — adverbe + participe présent, trait d’union obligatoire : *the **hard-working** pupils* (les élèves travailleurs).
3. ***teachers*** — nom + *-er* ; au pluriel, le *-s* se place sur le nom principal : ***teach + er → teachers*** (les enseignants).
4. ***school bags*** — nom composé à deux mots : le *-s* se place sur le nom principal *bag* → *school **bags*** (les cartables).
5. ***weekends*** — nom composé fusionné : *weekend* → *week**ends*** (les week-ends).

**Partie B.**

6. ***a twelve-year-old boy.*** — Adjectif composé de chiffre : trait d’union entre tous les éléments et *year* reste **singulier** devant le nom.
7. ***a French-speaking country.*** — Nom + participe en *-ing*, relié par un trait d’union, placé **avant** le nom : *a **French-speaking** country* (un pays francophone).
8. ***All the school bags were lost.*** — Le nom composé prend le *-s* sur le nom principal : *school **bags*** (Tous les cartables de l’école ont été perdus).

**Partie C.**

9. *a son-in-law → **sons-in-law*** ; *a school bus → **school buses***.
   Différence : le premier contient **-in-law**, composition figée par un trait d’union → le *-s* se place sur le **premier** mot. Le second est un groupe de deux mots libres → le *-s* va sur le **nom principal**, *bus*. (2 points : les deux pluriels corrects + justification *-in-law* / nom principal.)
10. Parce que *six-year-old* est un **adjectif composé invariable** placé devant le nom : le nom interne *year* reste au singulier ; seul le chiffre pourrait se décliner si l’ensemble était après le nom (*The girl is six years old*). (1 point : adjectif composé invariable + nom singulier.)
11. Le *-s* se place sur ***bags***, le **nom principal** : *school **bags***. Le premier mot *school* reste invariable car il joue le rôle de modificateur. (1 point : le *-s* sur le nom principal.)

:::piege Attention à « well-known » et « hard-working »
Au BFEM, les adjectifs composés avec *well-*, *hard-*, *newly-* exigent tous le trait d’union : ~~*a well known actor*~~ → ***a well-known actor***. Oublier ce tiret fait perdre le point, même si le sens est juste.
:::
