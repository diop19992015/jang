## L’essentiel du chapitre

:::formule Les trois formes du nom composé
- **Deux mots séparés** : *a school bag, a post office, a swimming pool*
- **Trait d’union** : *a son-in-law, a mother-in-law, a brother-in-law*
- **Un seul mot** : *a blackboard, a bedroom, sunshine, football*

Règle : le **deuxième** mot est le nom principal ; le premier le complète.
:::

:::formule Le pluriel des noms composés
| Situation | Où va le **-s** ? | Exemple |
| --- | --- | --- |
| Deux mots séparés | sur le 2e mot | *school **bags**, bus **stops*** |
| Composition irrégulière | sur le mot qui porte le sens | *tooth**brushes**, fire**men*** |
| Avec **-in-law** | sur le **1er** mot | *son**s**-in-law, mother**s**-in-law* |
| Deux noms déjà pluriels | sur les deux | *women doctors, men teachers* |
:::

:::formule Les adjectifs composés (toujours avant le nom)
| Type | Exemple | Traduction |
| --- | --- | --- |
| adj + participe | *a **well-known** actor* | un acteur célèbre |
| adverbe + participe | *a **hard-working** pupil* | un élève travailleur |
| nom + **-ing** | *a **French-speaking** country* | un pays francophone |
| chiffre + nom + **-ed** | *a **ten-year-old** boy* | un garçon de dix ans |
| adj + adj | *a **grey-haired** man* | un homme aux cheveux gris |
:::

:::formule Accord et pluriel de l’adjectif composé
- L’adjectif composé est **invariable** : il ne prend jamais de *-s*.
- Devant un nom, le nom interne reste **singulier** : *a **ten-year-old** boy*.
- Le pluriel porte sur le chiffre : *two **ten-year-old** boys*.
- Après le nom, pas de trait d’union : *The boy is **ten years old***.
:::

## Méthode express

1. Repérer le **nom principal** du groupe (c’est lui qui peut prendre le *-s*).
2. Nom composé au pluriel → poser la question : deux mots séparés ? → *-s* sur le 2e ; *-in-law* ? → *-s* sur le 1e ; irrégulier ? → pluriel du mot-sens.
3. Adjectif composé → le placer **avant** le nom, le relier par un trait d’union, le laisser **invariable**.
4. Chiffre + *year-old* devant un nom → nom interne singulier : *a six-year-old girl*.
5. Après le nom, l’adjectif redevient tout à fait normal : *She is twenty years old*.

:::erreur Les erreurs qui coûtent des points
1. ~~*sons-in-laws*~~ → ***sons-in-law*** (le trait d’union empêche le *-s* final).
2. ~~*a ten years old boy*~~ → ***a ten-year-old boy*** (trait d’union + *year* singulier).
3. ~~*She is ten-year-old*~~ → *She is **ten years old*** (après le nom : ni trait d’union, ni invariabilité).
4. Oublier le trait d’union : ~~*a hard working pupil*~~ → ***a hard-working pupil***.
5. Confondre *an English teacher* (prof d’anglais : nom + nom) et *an English-speaking teacher* (prof anglophone : adjectif composé).
:::

## Vocabulaire

- **Nom composé (compound noun)** : nom formé de deux mots : *school bag, post office*.
- **Adjectif composé (compound adjective)** : adjectif formé de deux mots, avant le nom : *hard-working*.
- **Trait d’union (hyphen)** : le tiret qui relie les éléments : *ten-year-old*.
- **Modificateur** : le premier mot, qui complète le nom principal (*school* in *school bag*).
- **Nom principal (head noun)** : le mot qui commande le groupe et porte le pluriel (*bag* in *school bags*).
- **Invariable** : qui ne prend jamais de *-s* ni d’accord.
- **Beau-frère / belle-mère (in-law)** : famille par alliance : *my brother-in-law*.
