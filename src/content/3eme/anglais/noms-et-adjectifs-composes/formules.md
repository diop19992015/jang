## La formation des noms composés

:::formule Tableau de référence : noms composés
| Type | Exemples | Traduction |
| --- | --- | --- |
| nom + nom | *bus stop, book shop, toothbrush, football, classroom* | arrêt de bus, librairie, brosse à dents, football, classe |
| adj + nom | *blackboard, high school, greenhouse* | tableau, lycée, serre |
| nom + **-ing** | *swimming pool, reading glasses, parking lot* | piscine, lunettes de lecture, parking |
| participe + nom | *broken window, frozen food* | fenêtre cassée, surgelés |
| nom + **-er/-or** | *driver, teacher, computer, washer* | chauffeur, enseignant, ordinateur |
| prép. + nom | *indoor, outdoor, onlooker, bystander* | en salle, en plein air, badaud |
| deux mots fusionnés | *bedroom, sunshine, keyboard, lookout* | chambre, ensoleillement, clavier, guérite |
| famille | *mother-in-law, son-in-law, father-in-law, sister-in-law* | belle-mère, beau-fils, beau-père, belle-sœur |
:::

## Le pluriel des noms composés

:::formule Les règles à appliquer dans l’ordre
1. Le composé contient **-in-law** ? → **-s** sur le premier mot : *son**s**-in-law*.
2. Les deux éléments sont des **noms pluriels déjà** ? → **-s** sur les deux : *women doctors, men teachers*.
3. Cas général : **-s** sur le **nom principal** (le dernier) : *school **bags**, bus **stops**, book **shops***.
4. Mot irrégulier : on applique le pluriel irrégulier du mot-sens : *fireman → fire**men**, toothbrush → tooth**brushes***.
5. Sigle ou lettre : **’s** : *M.P.’s, P’s and Q’s*.
:::

| Singulier | Pluriel |
| --- | --- |
| a school bag | school **bags** |
| a bus stop | bus **stops** |
| a son-in-law | **son**s-in-law |
| a mother-in-law | **mother**s-in-law |
| a toothbrush | tooth**brushes** |
| a fireman | fire**men** |
| a woman doctor | women **doctors** |

:::remarque Le piège du trait d’union
Le trait d’union « fige » le mot : c’est pour cela qu’on écrit *sons-in-law* et jamais ~~*son-in-laws*~~. Au contraire, *school bag*, sans trait d’union, suit la règle normale : *school bags*.
:::

## La formation des adjectifs composés

:::formule Tableau de référence : adjectifs composés
| Type | Exemples | Traduction |
| --- | --- | --- |
| adv. + participe passé | *well-known, newly-built, well-dressed* | célèbre, neuf, bien mis |
| adverbe + participe présent | *hard-working, long-lasting* | travailleur, durable |
| adj + participe | *ready-made, free-spoken* | prêt à l’emploi, franc |
| nom + participe en **-ing** | *French-speaking, football-loving, sea-loving* | francophone, amateur de football |
| adj + adj | *grey-haired, deaf-mute* | aux cheveux gris, sourd-muet |
| chiffre + nom (+ **-ed**) | *ten-year-old, three-legged, five-minute break* | de dix ans, à trois pieds, cinq minutes de récréation |
| prép. + nom | *indoor games, off-road vehicle* | jeux en salle, véhicule tout-terrain |
| nom + adj | *world-famous, colour-blind* | mondialement connu, daltonien |
:::

:::formule Les trois règles incontournables
$$
\text{adjectif composé} = \text{mot}_1 + \text{-} + \text{mot}_2 \quad \text{(toujours AVANT le nom, invariable)}
$$

- **Avant le nom** : *a **ten-year-old** boy*.
- **Invariable** : ~~*a ten-year-old**s** boy*~~ n’existe pas.
- **Nom interne singulier** : ~~*a ten-years-old boy*~~ → *a **ten-year-old** boy* ; pluriel : *two **ten-year-old** boys* (le *-s* est sur le chiffre).
:::

:::remarque Après le nom, tout change
Avec l’âge, la mesure ou la couleur, l’adjectif composé se place **après** le nom et perd son trait d’union, ses éléments devenant pluriels si besoin :
- *The boy **is ten years old**.* (Le garçon a dix ans.)
- *The table **is two metres long**.* (La table fait deux mètres de long.)
:::

## Identifier rapidement la nature d’un groupe

| Groupe | Nature | Test |
| --- | --- | --- |
| *an **English** teacher* | nom + nom (prof d’anglais) | il enseigne l’anglais |
| *an **English-speaking** teacher* | adjectif composé (prof anglophone) | il parle anglais — trait d’union obligatoire |
| *a **high school** student* | nom composé (lycéen) | lycéen |
| *a **hard-working** student* | adjectif composé | un élève qui travaille dur |
