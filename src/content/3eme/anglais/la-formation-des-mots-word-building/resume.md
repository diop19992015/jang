## L’essentiel du chapitre

:::formule Le schéma d’un mot dérivé
$$
\text{préfixe} + \text{radical} + \text{suffixe} = \text{nouveau mot}
$$

- **un + happy = unhappy** (le préfixe inverse le sens).
- **care + ful = careful** (le suffixe change la catégorie : nom → adjectif).
- **careful + ly = carefully** (nouveau suffixe : adjectif → adverbe).
:::

:::formule Les préfixes
| Préfixe | Sens | Exemples |
| --- | --- | --- |
| **un-** | contraire | *unhappy, unfair, unusual, unfinished* |
| **dis-** | contraire | *dislike, disagree, dishonest* |
| **re-** | à nouveau | *rewrite, reread, rebuild* |
| **mis-** | mal | *mistake, misplace, misunderstand* |
| **in-/im-/ir-** | contraire | *indirect, impossible, irregular* |
| **over- / under-** | trop / trop peu | *overcrowded, underestimate* |
| **pre- / inter- / non-** | avant / entre / sans | *preview, international, non-smoker* |
:::

:::formule Les suffixes
| Suffixe | Catégorie | Exemples |
| --- | --- | --- |
| **-ful / -less** | adjectif (plein de / sans) | *careful, helpful / careless, useless* |
| **-ly** | adverbe | *carefully, slowly, easily* |
| **-ment** | nom (action, résultat) | *enjoyment, movement, development* |
| **-tion / -sion** | nom (action, état) | *education, decision, invitation* |
| **-ness** | nom (qualité) | *happiness, kindness, darkness* |
| **-er / -or / -ist** | nom (personne, machine) | *teacher, visitor, artist* |
| **-ous / -ive / -al / -y** | adjectif | *dangerous, active, national, rainy* |
:::

:::formule Les familles de mots
| Radical | Nom | Adjectif | Adverbe |
| --- | --- | --- | --- |
| care | *care* | *careful / careless* | *carefully / carelessly* |
| happy | *happiness* | *happy* | *happily* |
| help | *help* | *helpful / helpless* | *helpfully* |
| beauty | *beauty* | *beautiful* | *beautifully* |
| decide | *decision* | *decisive* | *—* |
| invite | *invitation* | *invited* | *—* |
| act | *action / activity* | *active* | *actively* |
:::

:::formule L’orthographe : les 3 règles
1. *e* final qui tombe : *care → care**ful***, *beauty → beaut**iful***, *noise → nois**y***.
2. Consonne doublée avant *-er/-ed/-ing* : *begin → begin**n**er*, *run → run**n**er*.
3. *y → i* devant un suffixe consonne : *happy → happ**i**ness*, *easy → eas**ily***.
:::

## Méthode express

1. Identifier la **catégorie demandée** : nom (-tion, -ment, -ness), adjectif (-ful, -less, -ous, -ive, -al, -y), adverbe (-ly), personne (-er, -or, -ist).
2. Repérer le **radical** dans le texte (souvent le même mot en français).
3. Choisir le préfixe pour le sens : contraire (*un-, dis-, in-*), répétition (*re-*), erreur (*mis-*), excès (*over-*).
4. Appliquer les règles d’orthographe (*e* qui tombe, *y → i*, consonne doublée).
5. Relire la phrase : le mot doit être grammaticalement juste **et** avoir le bon sens.

:::erreur Les erreurs qui coûtent des points
1. ~~*happly*~~ → ***happiness*** / ***happily*** (*y → i* avant un suffixe consonne).
2. ~~*carefull*~~, ~~*beautifull*~~ → ***careful***, ***beautiful*** (pas de *l* final).
3. ~~*carentful*~~ → ***careful*** (le *e* tombe, pas de *t*).
4. ~~*He is happyly*~~ → *He is **happy*** (adjectif) ; *He works **happily*** (adverbe).
5. Confondre **-ful** et **-less** : *useful* (utile) ≠ *useless* (inutile).
:::

## Vocabulaire

- **Radical / racine (root)** : mot de base sans préfixe ni suffixe : *care, happy, decide*.
- **Préfixe (prefix)** : élément placé avant le radical : *un-, re-, dis-*.
- **Suffixe (suffix)** : élément placé après le radical : *-ful, -ment, -tion*.
- **Mot dérivé (derived word)** : mot formé d’un radical + un affixe.
- **Famille de mots (word family)** : tous les mots dérivés d’un même radical.
- **Catégorie grammaticale (part of speech)** : nom, adjectif, adverbe, verbe.
- **Contraire (opposite)** : *careful ↔ careless*, *happy ↔ unhappy*.
- **Orthographe (spelling)** : *happiness, beautiful, beginner*.
