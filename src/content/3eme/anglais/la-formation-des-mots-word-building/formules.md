## Le schéma général de formation

:::formule Structure d’un mot dérivé
$$
\text{préfixe} + \text{radical} + \text{suffixe} = \text{nouveau mot}
$$

| Partie | Rôle | Exemple dans *unhappiness* |
| --- | --- | --- |
| Préfixe | change le **sens** | **un-** (contraire) |
| Radical | le mot de base | **happy** |
| Suffixe | change la **catégorie** | **-ness** (adjectif → nom) |

:::remarque Deux questions à se poser
1. Le mot a-t-il changé de **catégorie** ? → c’est le suffixe (*happy → happiness*).
2. Le mot a-t-il changé de **sens** ? → c’est le préfixe (*happy → unhappy*).
:::

## Les préfixes

:::formule Tableau des préfixes
| Préfixe | Sens | Exemples | Traduction |
| --- | --- | --- | --- |
| **un-** | contraire | *unhappy, unfair, unusual, unlucky, unlock* | malheureux, injuste, inhabituel, malchanceux, déverrouiller |
| **dis-** | contraire | *dislike, disagree, dishonest, disappear* | ne pas aimer, désaccord, malhonnête, disparaître |
| **re-** | à nouveau | *rewrite, reread, return, rebuild, reorganise* | réécrire, relire, revenir, reconstruire, réorganiser |
| **mis-** | mal | *mistake, misplace, misunderstand, mislead* | se tromper, égarer, mal comprendre, égarer |
| **in-** | contraire | *indirect, inactive, informal* | indirect, inactif, informel |
| **im-** | contraire (devant m, p, b) | *impossible, impatient, imbalance* | impossible, impatient, déséquilibre |
| **ir-** | contraire (devant r) | *irregular, irresponsible, irrelevant* | irrégulier, irresponsable, hors sujet |
| **il-** | contraire (devant l) | *illegal, illiterate, illogical* | illégal, illettré, illogique |
| **over-** | trop, en excès | *overwork, overcrowded, overeat* | surcharger, surpeuplé, manger trop |
| **under-** | trop peu, dessous | *underground, underestimate, undergo* | souterrain, sous-estimer, subir |
| **pre-** | avant | *preview, prehistory, pre-war* | avant-première, préhistoire, d’avant-guerre |
| **inter-** | entre | *international, interchange, inter-school* | international, échange, interscolaire |
| **non-** | sans, contraire | *nonsense, non-violent, non-stop* | non-sens, non violent, sans arrêt |
| **semi-** | à demi | *semicircle, semifinal* | demi-cercle, demi-finale |
| **ex-** | ancien | *ex-president, ex-pupil* | ex-président, ancien élève |
:::

:::remarque Choisir un-, dis- ou in- ?
Pas de règle logique : on apprend le préfixe **avec le mot**. *Un-* sert surtout aux participes et adjectifs courants (*unhappy, unknown*), *dis-* aux verbes et adjectifs (*dislike, dishonest*), *in-* aux adjectifs latins (*impossible, irregular*).
:::

## Les suffixes

:::formule Tableau des suffixes
| Suffixe | Catégorie obtenue | Sens | Exemples |
| --- | --- | --- | --- |
| **-ful** | adjectif | plein de, qui a | *careful, helpful, beautiful, hopeful, painful* |
| **-less** | adjectif | sans (contraire de -ful) | *careless, helpless, useless, endless, homeless* |
| **-ly** | adverbe (ou adjectif) | de la manière de | *carefully, slowly, easily, badly* ; *friendly, lovely* |
| **-ment** | nom | action, résultat | *enjoyment, movement, development, government* |
| **-tion / -sion** | nom | action, état | *education, decision, invitation, information* |
| **-ness** | nom | qualité, état | *happiness, kindness, darkness, business* |
| **-er / -or** | nom | personne ou machine | *teacher, worker, driver, visitor, computer* |
| **-ist** | nom | personne spécialisée | *artist, pianist, scientist, tourist* |
| **-ive** | adjectif | qui a tendance à | *active, creative, attractive, impressive* |
| **-ous** | adjectif | plein de | *dangerous, famous, nervous, generous* |
| **-al** | adjectif | relatif à | *national, traditional, accidental, political* |
| **-y** | adjectif | qui a, qui est | *rainy, cloudy, dusty, salty, wealthy* |
| **-en** | adjectif / verbe | fait de / devenir | *wooden, golden ; widen, sharpen* |
| **-ish** | adjectif | un peu, apparenté | *childish, foolish, English, selfish* |
:::

:::remarque -ful et -less : le couple des contraires
*careful ↔ careless* (soigneux ↔ négligent), *useful ↔ useless* (utile ↔ inutile), *helpful ↔ helpless* (serviable ↔ incapable), *hopeful ↔ hopeless* (plein d’espoir ↔ sans espoir).
:::

## Les règles d’orthographe

:::formule Les cinq règles
1. **Le *e* final tombe** devant *-ful, -ous, -y, -able* : *care → careful*, *beauty → beautiful*, *noise → noisy*, *value → valuable*.
2. **La consonne se double** après une consonne + voyelle courte : *begin → beginner*, *run → runner*, *stop → stopping*.
3. **Le *y* devient *i*** devant un suffixe consonne : *happy → happiness*, *easy → easily*, *angry → angrily*.
4. **Verbe en *-e* + *-tion*** : *invite → invitation*, *educate → education*, *discuss → discussion*, *decide → decision*.
5. **Verbe en *-y* + *-tion*** : *apply → application*, *satisfy → satisfaction* ; *fly → flight*.
:::

:::formule Le test rapide des familles
- Nom → adjectif : ajoute **-ful** ou **-less** (*care → careful / careless*).
- Adjectif → adverbe : ajoute **-ly** (*careful → carefully*).
- Verbe → nom : ajoute **-tion** (*decide → decision*) ou **-ment** (*enjoy → enjoyment*).
- Nom → personne : ajoute **-er/-ist** (*teach → teacher*, *art → artist*).
:::
