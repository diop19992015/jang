:::remarque À quoi ça sert au BFEM ?
Au BFEM, le « Word building » apparaît dans les questions de vocabulaire : donner l’adjectif d’un nom (*care → careful*), le nom d’un verbe (*decide → decision*), ou former le contraire avec *un-, dis-, -less*… Apprendre les familles de mots et les suffixes, c’est multiplier son vocabulaire sans tout réapprendre : un seul radical (*happy, care, use*) fait naître toute une famille. Ce sont aussi des points décisifs en production écrite, où les fautes de formation de mots coûtent des points.
:::

## Le principe : préfixe + radical + suffixe

:::definition Mot dérivé
Un **mot dérivé** est formé à partir d’un **radical** (le mot de base) auquel on ajoute un **préfixe** (au début) ou un **suffixe** (à la fin) pour changer de catégorie grammaticale ou de sens.
:::

:::formule La structure de la formation des mots
$$
\text{préfixe} + \text{radical} + \text{suffixe} = \text{nouveau mot}
$$

- **un + happy** → *unhappy* (malheureux) — le préfixe change le **sens** (contraire).
- **care + ful** → *careful* (soigneux) — le suffixe change la **catégorie** (nom → adjectif).
- **care + ful + ly** → *carefully* (soigneusement) — le suffixe change encore la catégorie (adjectif → adverbe).
:::

## Les préfixes

:::definition Préfixe
Un **préfixe** se place **avant** le radical. Il ne change généralement **pas la catégorie** du mot : le mot reste nom, adjectif ou verbe, mais son **sens** s’inverse ou se précise.
:::

:::formule Les préfixes du programme
| Préfixe | Sens | Exemple | Traduction |
| --- | --- | --- | --- |
| **un-** | contraire (adjectifs, participes) | *unhappy, unfair, unusual, unfinished* | malheureux, injuste, inhabituel, inachevé |
| **dis-** | contraire (verbes, adjectifs) | *dislike, disagree, dishonest, disappear* | ne pas aimer, ne pas être d’accord, malhonnête, disparaître |
| **re-** | à nouveau, de nouveau | *rewrite, reread, return, rebuild, reunite* | réécrire, relire, revenir, reconstruire |
| **mis-** | mal, de travers | *mistake, misplace, misunderstand* | se tromper, égarer, mal comprendre |
| **non-** | absence, contraire | *nonsense, non-smoker, non-violent* | non-sens, non-fumeur, non violent |
| **in-/im-/ir-** | contraire (selon le mot) | *indirect, impossible, irregular* | indirect, impossible, irrégulier |
| **over-** | trop, en excès | *overwork, overcrowded, overeat* | surcharger, surpeuplé, manger trop |
| **under-** | trop peu, en dessous | *underground, underestimate, undergo* | souterrain, sous-estimer, subir |
| **pre-** | avant | *preview, prehistory, prewar* | avant-première, préhistoire, d’avant-guerre |
| **inter-** | entre, parmi | *international, inter-school, interchange* | international, interscolaire |
| **a-/ab-** | absence | *asleep, away, abnormal* | endormi, absent, anormal |
:::

:::exemple Les préfixes dans une phrase
- *The exam paper was **unfinished** when the bell rang.* (La copie d’examen était inachevée quand la cloche a sonné.)
- *Please **rewrite** the sentence.* (Réécris la phrase.)
- *I **dislike** hot weather.* (Je n’aime pas la chaleur.)
- *Dakar hosts an **international** airport.* (Dakar a un aéroport international.)
- *This rule is **unfair**.* (Cette règle est injuste.)
:::

:::remarque Un-, in- ou dis- ?
Les trois expriment le contraire, mais selon les mots :
- adjectifs et participes courants → **un-** : *unfair, unknown, untidy* ;
- adjectifs latins → **in- / im- / ir-** : *impossible, impatient, irregular, indirect* ;
- verbes et certains adjectifs → **dis-** : *disagree, dislike, dishonest*.

Il n’y a pas de règle de logique : on apprend le préfixe **avec le mot**.
:::

## Les suffixes

:::definition Suffixe
Un **suffixe** se place **après** le radical. Il change le plus souvent la **catégorie grammaticale** du mot : nom → adjectif, verbe → nom, adjectif → adverbe.
:::

:::formule Les suffixes du programme
| Suffixe | Catégorie obtenue | Exemple | Traduction |
| --- | --- | --- | --- |
| **-ful** | adjectif (qui a, qui est plein de) | *careful, helpful, beautiful, hopeful* | soigneux, utile, beau, plein d’espoir |
| **-less** | adjectif (sans, contraire de -ful) | *careless, helpless, useless, endless* | négligent, incapable, inutile, sans fin |
| **-ly** | adverbe (ou adjectif) | *carefully, slowly, friendly* (adj.) | soigneusement, lentement, amical |
| **-ment** | nom (action, résultat) | *enjoyment, movement, development, government* | plaisir, mouvement, développement, gouvernement |
| **-tion / -sion** | nom (action, état) | *education, decision, information, invitation* | éducation, décision, information, invitation |
| **-ness** | nom (qualité) | *happiness, kindness, darkness, business* | bonheur, gentillesse, obscurité, affaire |
| **-er / -or** | nom (personne ou machine) | *teacher, worker, driver, visitor* | enseignant, ouvrier, chauffeur, visiteur |
| **-ist** | nom (personne spécialisée) | *artist, pianist, scientist, tourist* | artiste, pianiste, scientifique, touriste |
| **-ive** | adjectif | *active, creative, attractive, impressive* | actif, créatif, attirant, impressionnant |
| **-ous** | adjectif (plein de) | *dangerous, famous, nervous, generous* | dangereux, célèbre, nerveux, généreux |
| **-al** | adjectif | *national, traditional, accidental* | national, traditionnel, accidentel |
| **-y** | adjectif (qui a) | *rainy, cloudy, dusty, salty* | pluvieux, nuageux, poussiéreux, salé |
| **-en** | adjectif/verbe (devenir) | *wooden, widen, sharpen, deepen* | en bois, élargir, aiguiser, approfondir |
:::

:::exemple Les suffixes en contexte
- *The market is **crowded** and **noisy**.* (Le marché est bondé et bruyant.)
- *Water is **essential** for **life**.* (L’eau est essentielle à la vie.)
- *She answered the teacher **carefully**.* (Elle a répondu au maître soigneusement.)
- *Reading gives me great **enjoyment**.* (La lecture me procure un grand plaisir.)
:::

### Les règles d’orthographe à connaître

:::formule Trois règles de formation
1. **Verbe en -e** : le *e* tombe avant *-ful, -ous, -y* : *care → care**ful***, *beauty → beaut**iful***, *noise → nois**y***.
2. **Consonne + voyelle courte** : on double la consonne avant *-er, -ed, -ing* : *begin → begin**n**er*, *stop → stop**p**ing*, *run → run**n**er*.
3. **Verbe en -y** : le *y* devient *i* avant un suffixe consonne : *happy → happ**i**ness*, *decide → decid**e → decision*** ; le suffixe **-tion** se prononce /ʃn/ : *invite → invitation, educate → education, discuss → discussion*.
:::

:::erreur Les erreurs qui coûtent des points
1. ~~*care + ful = carentful*~~ → jamais de *t* : ***careful***.
2. ~~*happly*~~ → *y + consonne + suffixe consonne* → ***happiness***.
3. ~~*beautifull*~~ → ***beautiful*** (pas de *l* final).
4. ~~*he is very happyly*~~ → *He is very **happy*** (adjectif après *very*) / *He smiled **happily*** (adverbe devant le verbe).
5. Mélanger **-ful** et **-less** : *care**ful*** = soigneux (qui a du soin), *care**less*** = négligent (sans soin).
:::

:::piege Attention aux faux amis de formation
*un-* ne s’ajoute pas à n’importe quel mot : on dit *unhappy, unfair*, mais jamais ~~*unsad*~~ ni ~~*unkindful*~~. De même, **-ful** ne s’ajoute pas aux noms d’émotion qui ont déjà leur forme : *hopeful* existe, mais ~~*sadful*~~ n’existe pas. En cas de doute, vérifier le mot dans le dictionnaire — et surtout, apprendre les familles complètes.
:::

## Les familles de mots

:::definition Famille de mots
Une **famille de mots** regroupe tous les mots dérivés d’un même radical. Connaître la famille complète, c’est pouvoir passer du nom à l’adjectif, puis à l’adverbe, sans hésiter.
:::

:::formule Les familles à connaître pour le BFEM
| Radical | Nom | Adjectif | Adverbe |
| --- | --- | --- | --- |
| care | *care* (soin) | *careful* | *carefully* |
| care (contraire) | — | *careless* | *carelessly* |
| happy | *happiness* | *happy* | *happily* |
| use | *use* (usage) | *useful / useless* | *usefully* |
| help | *help* | *helpful / helpless* | *helpfully* |
| beauty | *beauty* | *beautiful* | *beautifully* |
| loud | *loudness* | *loud* | *loudly* |
| easy | *ease* | *easy* | *easily* |
| friend | *friendship* | *friendly* | *—* |
| danger | *danger* | *dangerous* | *—* |
| decide | *decision* | *decisive* | *—* |
| invite | *invitation* | *invited* | *—* |
| invent | *invention* | *inventive* | *—* |
| educate | *education* | *educated* | *—* |
| act | *action / activity* | *active* | *actively* |
:::

:::methode Passer d’une catégorie à l’autre
1. Nom → adjectif : ajoute **-ful** ou **-less** (*care → careful / careless*).
2. Adjectif → adverbe : ajoute **-ly** (*careful → carefully*), sauf *y → ily* (*easy → easily*).
3. Verbe → nom : **-tion/-sion** (*decide → decision, invite → invitation*) ou **-ment** (*enjoy → enjoyment, develop → development*).
4. Nom → personne : **-er/-or** ou **-ist** (*teach → teacher, art → artist*).
5. Toujours vérifier l’orthographe : *-e* qui tombe, consonne doublée, *y → i*.
:::

:::methode Répondre à une question de word building au BFEM
1. Lire la phrase et identifier la **catégorie demandée** (nom ? adjectif ? adverbe ?).
2. Chercher le radical dans la phrase ou dans le texte.
3. Choisir le suffixe correspondant à la catégorie (tableau ci-dessus).
4. Appliquer les règles d’orthographe, puis relire : le mot doit avoir un sens dans la phrase.
:::

## Ce qu’il faut retenir

- Structure : **préfixe + radical + suffixe** ; le préfixe change le **sens**, le suffixe change la **catégorie**.
- Préfixes principaux : **un-/dis-/in-** (contraire), **re-** (à nouveau), **mis-** (mal), **over-/under-** (trop / trop peu), **pre-** (avant), **inter-** (entre).
- Suffixes principaux : **-ful/-less** (adjectifs opposés), **-ly** (adverbe), **-ment/-tion/-ness** (noms), **-er/-or/-ist** (personnes), **-ous/-ive/-al/-y** (adjectifs).
- Orthographe : *careful* (le *e* tombe), *happiness* (*y → i*), *beginner* (consonne doublée), *beautiful* (pas de *l* final).
- Les familles de mots : *care → careful / careless → carefully* ; *decide → decision* ; *happy → happiness → happily*.
- Au BFEM, lis la phrase avant de choisir : le suffixe doit donner **la bonne catégorie** et **le bon sens**.
