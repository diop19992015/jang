## Question

Quel est l’adjectif de *care* qui signifie « soigneux, qui fait attention » ?

- [ ] carely
- [x] careful
- [ ] careness
- [ ] carentful

> Le suffixe **-ful** (« plein de ») forme l’adjectif : *care → **careful***. Attention : le *e* de *care* tombe et il n’y a aucun *t* : ~~*carentful*~~ est fautif. *carely* n’existe pas, *careness* serait un nom mal formé.

## Question

Comment écrit-on correctement le contraire de *useful* ?

- [ ] usenful
- [ ] usefully
- [x] useless
- [ ] unuseful

> Le couple d’opposés est **-ful / -less** : *useful* (utile) → ***useless*** (inutile). *usefully* est l’adverbe (utilement), et *unuseful* n’est pas un mot.

## Question

Quelle est la forme correcte du nom dérivé de *happy* ?

- [ ] happyness
- [x] happiness
- [ ] happness
- [ ] happieness

> Règle d’orthographe : devant un suffixe consonne (*-ness*), le *y* final devient **i** : *happy → **happiness***. On ne garde jamais le *y* (~~*happyness*~~) et on ne le supprime pas (~~*happness*~~).

## Question

Dans « She answered the teacher carefully », quelle est la catégorie du mot *carefully* ?

- [ ] un nom
- [ ] un adjectif
- [x] un adverbe
- [ ] un verbe

> Le suffixe **-ly** forme l’adverbe : *careful + ly = **carefully*** (soigneusement), qui modifie le verbe *answered*. L’adjectif est *careful* (sans *-ly*), utilisé devant le nom ou après *be* : *She is careful*.
