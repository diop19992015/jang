## Énoncé

Le texte suivant est composé à la manière d’un sujet de BFEM.

« The teachers of our school are very **(1)** (help) with the pupils. They explain the lessons **(2)** (careful) and never get angry. Last Friday, the headmaster announced the **(3)** (invite) to the science fair. All the pupils were very **(4)** (excite) about it. Thanks to their **(5)** (prepare) for the BFEM, the results were excellent. »

**Partie A.** Complétez le texte avec le mot dérivé correct : mettez le mot entre parenthèses à la catégorie qui convient. (5 × 1 point = 5 points)

**Partie B.** Transformez les mots comme dans l’exemple.

*Example : happy (adverbe) → happily*

6. *care (adjectif)* (1 point)
7. *decide (nom)* (1 point)
8. *beautiful (adverbe)* (1,5 point)
9. *friendly (nom, l’amitié)* (1,5 point)

**Partie C.** Questions de grammaire. (4 points)

10. Pourquoi écrit-on *happiness* et non ~~*happyness*~~ ? Citez la règle d’orthographe. (1 point)
11. Expliquez la différence de sens entre *careful* et *careless*, puis donnez un exemple pour chacun. (1,5 point)
12. Dans le texte, le mot *invitations* est formé du verbe *invite*. Expliquez le changement d’orthographe et donnez la catégorie de ce mot. (1,5 point)

## Solution

**Partie A.**

1. ***helpful*** — *help* + **-ful** = adjectif « qui aide, serviable » : *The teachers are very **helpful*** (Les enseignants sont très serviables).
2. ***carefully*** — *careful* + **-ly** → adverbe qui modifie le verbe *explain* : *They explain the lessons **carefully*** (Ils expliquent les leçons soigneusement).
3. ***invitations*** — *invite* + **-ation** : le *e* tombe → *invitations* ; pluriel ici car c’est « les invitations » annoncées : *the **invitations** to the science fair* (les invitations au salon de sciences).
4. ***excited*** — participe passé adjectif : *be + excited* (excité) : *The pupils were very **excited*** (Les élèves étaient très excités).
5. ***preparation*** — *prepare* + **-ation** : le *e* final tombe → *preparation* (nom) : *Thanks to their **preparation** for the BFEM* (Grâce à leur préparation pour le BFEM).

**Partie B.**

6. ***careful*** — *care* + **-ful** (le *e* tombe) = soigneux : *A careful pupil checks his answers.* (Un élève soigneux vérifie ses réponses.)
7. ***decision*** — *decide* → *decisi- + on* : *decide → **decision*** (La décision du conseil).
8. ***beautifully*** — *beautiful* + **-ly** → adverbe : *She sang **beautifully**.* (Elle a chanté magnifiquement.) Pas de *l* ajouté ni doublé : ~~*beautifuly*~~ est fautif.
9. ***friendship*** — le nom qui correspond à *friendly* est ***friendship*** (l’amitié) : *Their **friendship** is strong.* (Leur amitié est forte.)

**Partie C.**

10. Parce que le **y final devient i** devant un suffixe consonne (*-ness*) : *happy → happ**i**ness*. On n’écrit donc jamais ~~*happyness*~~. (1 point : règle *y → i*.)
11. ***careful*** = soigneux, **qui fait attention** (*-ful* : plein de soin) ; ***careless*** = négligent, **qui ne fait pas attention** (*-less* : sans soin). Exemples : *Be careful with the glass.* / *He is careless with his things.* (1,5 point : les deux sens opposés + un exemple correct pour chacun.)
12. *invite* → ***invitations*** : devant le suffixe **-ation**, le *e* final du verbe tombe (*invite + ation → invitation*) et le nom est ici au **pluriel** (*announced the invitations*). Catégorie : c’est un **nom** issu d’un verbe (famille : *invite → invitation → invited*). (1,5 point : chute du *e* + catégorie nom + pluriel.)

:::piege Attention aux adjectifs en -ed et -ing
Dans le texte, *excited* décrit **ce que ressentent** les élèves (état) : *The pupils were excited*. On confond souvent avec *exciting* (qui excite) : *The science fair was exciting*. Règle : personne/animal → **-ed** ; chose/activité → **-ing**.
:::
