## L’essentiel du chapitre

:::formule Prétérit simple (Past Simple)
- **Usage** : action **terminée et datée** dans le passé.
- **Formation** : régulier = **-ed** (*play → played*) ; irrégulier = forme à apprendre (*go → went*, *see → saw*).
- **Négation** : *didn’t + base verbale* — **Question** : *Did + sujet + base verbale ?*
- Marqueurs : *yesterday, last week, …ago, in 2019, when I was young*.
:::

:::formule Prétérit continu (Past Continuous)
- **Usage** : action **en cours** à un moment précis du passé.
- **Formation** : **was / were + verbe en -ing**.
- *I / he / she / it → was* ; *you / we / they → were*.
- Marqueurs : *while, when, at 8 o’clock, at that moment, all morning*.
:::

:::formule Choisir entre les deux
| Idée | Temps | Exemple |
| --- | --- | --- |
| Fait raconté, terminé | Prétérit simple | *I **finished** my homework.* |
| Décor : action en cours | Prétérit continu | *I **was doing** my homework when he called.* |
| Action brève qui interrompt | Prétérit simple | *It **started** to rain.* |
| Action longue qui est interrompue | Prétérit continu | *We **were walking** home when it started to rain.* |
:::

:::formule Le couple incontournable
$$
\underbrace{\text{was/were + -ing}}_{\text{action longue}} \;+\; \underbrace{\text{did / prétérit simple}}_{\text{action brève}}
$$
*They **were playing** when the teacher **came**.* (Ils jouaient quand le maître est venu.)
:::

## Méthode express

1. Repérer les **marqueurs** : *yesterday, last year, …ago* → prétérit simple ; *while, when, at that moment* → prétérit continu.
2. Prétérit simple : choisir **régulier (-ed)** ou **irregulier** (*went, wrote, bought*…).
3. Question/négation du prétérit simple : toujours ***did + base verbale*** (jamais *did went*).
4. Prétérit continu : conjuguer ***was/were*** selon le sujet, puis ajouter **-ing**.
5. Dans un récit : l’action longue au continu, l’action brève au simple.

:::erreur Les erreurs qui coûtent des points
1. ~~didn’t went / did he went?~~ → *didn’t **go** / **did** he **go**?*
2. ~~we was playing~~ → *we **were** playing*.
3. ~~stoped~~ → *stop**ped*** (double consonne) ; ~~studyed~~ → *stud**ied***.
4. Verbes irréguliers inventés : ~~goed, seed, wroter~~ → *went, saw, wrote*.
5. ~~They was playing when I came~~ → *They **were** playing…*
:::

## Vocabulaire

- **Prétérit / passé simple (past simple)** : temps du récit, action terminée.
- **Prétérit continu (past continuous)** : « était en train de… » = *was/were + -ing*.
- **Verbe régulier** : forme son prétérit en *-ed* (*visit → visited*).
- **Verbe irrégulier** : prétérit spécial à apprendre (*write → wrote*).
- **Base verbale** : le verbe sans *to* ni terminaison (*go, see*).
- **Marqueur temporel** : mot-repère du temps (*yesterday, while*…).
- **Action longue / action brève** : distinction au cœur de la phrase *was walking … started*.
- **Auxiliaire** : *did* (prétérit simple), *was/were* (prétérit continu).
