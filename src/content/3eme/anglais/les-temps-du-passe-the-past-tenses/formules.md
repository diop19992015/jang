## Prétérit simple — conjugaison

:::formule La structure
$$
\text{prétérit simple} = \text{base verbale} + \text{-ed (réguliers) ou forme irrégulière}
$$

| Personne | Affirmation (régulier) | Négation | Question |
| --- | --- | --- | --- |
| I / he / she / it | worked | did not (didn’t) work | Did he work? |
| you / we / they | played | did not (didn’t) play | Did they play? |

:::remarque La règle du did
*Did* porte déjà le passé : après *did / didn’t*, le verbe redevient **toujours à la base verbale**.
- ✗ *Did you went?* → ✓ ***Did you go?***
- ✗ *I didn’t saw him.* → ✓ ***I didn’t see him.***
:::

## Les verbes réguliers : le -ed

| Règle | Exemples |
| --- | --- |
| Règle générale : **+ -ed** | *play → played*, *walk → walked*, *revise → revised* |
| Finale *-e* : **+ -d** | *live → lived*, *like → liked*, *arrive → arrived* |
| Consonne + *y* : **y → ied** | *study → studied*, *try → tried*, *carry → carried* |
| Consonne + voyelle + consonne : **double** | *stop → stopped*, *plan → planned*, *prefer → preferred* |
| Finale *-c* : **+ -ked** | *panic → panicked* |

:::remarque Voyelle + y
Si le *y* est précédé d’une voyelle, il ne change pas : *play → played*, *enjoy → enjoyed*, *buy → bought* (irrégulier).
:::

## Prétérit continu — conjugaison

:::formule La structure
$$
\text{was / were} + \text{verbe} + \text{-ing}
$$

| Personne | Affirmation | Négation | Question |
| --- | --- | --- | --- |
| I / he / she / it | was working | was not (wasn’t) working | Was he working? |
| you / we / they | were working | were not (weren’t) working | Were they working? |
:::

:::remarque Was ou were ?
- *I, he, she, it* → **was** (*He was reading.*)
- *you, we, they* → **were** (*You were reading.*)
- Même la 2e personne au singulier prend **were** : *You **were** late.*
:::

## Marqueurs temporels du passé

:::formule Quel temps avec quel marqueur ?
| Prétérit simple | Prétérit continu |
| --- | --- |
| *yesterday, the day before* | *while, whilst* (pendant que) |
| *last night, last week, last year* | *when* (quand — + action longue) |
| *…ago* (*two hours ago*, *ten years ago*) | *at 7 o’clock yesterday* |
| *in 2021* (année passée) | *at that moment, all morning* |
| *when I was young, one day, then* | *all day long* |
:::

## Le schéma à mémoriser : une action longue interrompue

:::formule Phrase type
$$
\text{Prétérit continu (long)} \;+\; \text{when} \;+\; \text{prétérit simple (bref)}
$$

- *I **was doing** my homework **when** the lights **went** out.* (Je faisais mes devoirs quand la lumière s’est éteinte.)
- *They **were playing** outside **when** it **began** to storm.* (Ils jouaient dehors quand un orage a commencé.)

Variante : *When + prétérit simple, prétérit continu* :
- ***When** he **arrived**, we **were having** lunch.* (Quand il est arrivé, nous déjeunions.)
:::

## Tableau récapitulatif des trois formes du passé

| Temps | Construction | Usage | Exemple |
| --- | --- | --- | --- |
| Prétérit simple | base + *-ed* / irrégulier | fait terminé | *She **wrote** a letter.* |
| Prétérit continu | *was/were + -ing* | action en cours | *She **was writing** a letter.* |
| Avec *did* | *did + base* | question / négation | ***Did** she **write**? / She **didn’t write**.* |
