## L’essentiel du chapitre

:::formule Le principe de la relative
Une **relative clause** complète un **nom** (antécédent) et est introduite par un pronom relatif :

*The pupil **who sits next to me** is my cousin.* (L’élève qui est assis à côté de moi est mon cousin.)
:::

:::formule Who, which, that
| Pronom | Pour | Exemple |
| --- | --- | --- |
| **who** | personne | *The girl **who lives here** is Aminata.* |
| **which** | chose / animal | *The bike **which was stolen** is mine.* |
| **that** | personne ou chose | *The man **that called you** is my uncle.* |
| **whose** | possession (« dont ») | *The boy **whose father is a fisherman** won.* |
:::

:::formule Where, when, why
| Relatif | Pour | Exemple |
| --- | --- | --- |
| **where** | lieu | *Dakar is the city **where I live**.* |
| **when** | temps | *I remember the day **when we arrived**.* |
| **why** | raison | *That is the reason **why he left**.* |
:::

:::formule La suppression du relatif
- Relatif **COD** → suppression possible : *The book **(that) I read** is great.*
- Relatif **sujet** → obligatoire : *The pupil **who** reads well* (jamais ~~*the pupil reads well*~~ dans ce sens).
- Après **préposition** → jamais supprimé : *The house **in which** he lives* / *The house **where** he lives*.
:::

## Méthode express

1. Repère le **nom** à compléter (l’antécédent).
2. Personne → *who/that* ; chose → *which/that* ; possession → *whose* ; lieu → *where* ; temps → *when* ; raison → *why*.
3. Le relatif est-il **sujet** du verbe suivant ? → il est obligatoire. Est-il **COD** ? → *that/which* peut disparaître.
4. Traduis les circonstances : *in Dakar → where*, *in 2019 → when*, *for this reason → why*.
5. Relis : la phrase doit rester claire, sans mot en trop.

:::erreur Les erreurs qui coûtent des points
1. ~~*The village that I was born*~~ → ***The village where I was born*** (lieu → *where*).
2. Oublier le relatif sujet : ~~*The pupil reads well*~~ → ***The pupil who reads well***.
3. ~~*who’s father*~~ → ***whose father*** (*who’s* = *who is*).
4. ~~*The girl which came*~~ → ***The girl who came*** (personne → *who*).
5. Supprimer un relatif sujet ou après préposition : ~~*The house he lives*~~ → ***The house where he lives***.
:::

## Vocabulaire

- **Relative clause** : subordonnée relative (« la relative »).
- **Antecedent** : nom que la relative complète.
- **Relative pronoun** : pronom relatif (*who, which, that, whose, where, when, why*).
- **Whose** : relatif de possession (« dont », « de qui »).
- **Defining relative** : relative sans virgule, qui identifie.
- **Non-defining relative** : relative entre virgules, qui ajoute une info facultative.
- **Subject / object** : sujet / complément d’objet direct (détermine la suppression du relatif).
