## L’essentiel du chapitre

:::formule Le point de départ
*If you revise, you will pass.* (Si tu révises, tu réussiras.) → **if + présent**, **will + infinitif**.
:::

:::formule Unless = if… not
| Forme négative | Reformulation |
| --- | --- |
| *If you **do not** revise, you will fail.* | ***Unless** you revise, you will fail.* |
| *If it **does not** rain, we will play.* | ***Unless** it rains, we will play.* |
| *If Aminata **is not** early, she will miss the test.* | ***Unless** Aminata **is** early, she will miss the test.* |
:::

:::formule Cause et conséquence
- **because** + cause : *He is late **because** the bus broke down.*
- **so** + conséquence : *The bus broke down, **so** he is late.*
- **that's why** + conséquence : *The bus broke down; **that's why** he is late.*
:::

:::formule Otherwise = sinon
**Impératif + otherwise + proposition avec will**
- ***Revise, otherwise** you will fail.* (Révise, sinon tu échoueras.)
:::

## Méthode express

1. Lire la phrase et dire son sens : condition (« si… ne »), cause (« parce que »), conséquence (« donc ») ou alternative (« sinon ») ?
2. Condition négative → remplacer *if… not* par **unless** + verbe affirmatif.
3. Cause → **because** ; conséquence → **so** ou **that's why** (jamais les deux ensemble).
4. « Sinon » → **impératif + otherwise + will**.
5. Vérifier les temps : *if / unless* + présent, *will* + infinitif, sens identique.

:::erreur Les erreurs qui coûtent des points
1. ~~*Unless you don't revise*~~ : la négation est déjà dans *unless*.
2. ~~*Because it rained, so we stayed*~~ : on choisit *because* **ou** *so*.
3. ~~*If you will revise*~~ : jamais *will* après *if* ou *unless*.
4. Oublier *will* après *otherwise* : *Hurry up, otherwise you **will** miss the bus.*
:::

## Vocabulaire

- **to reformulate** : reformuler (changer les mots, garder le sens).
- **condition** : condition (*if* introduit la condition).
- **cause** : cause (*because*).
- **consequence** : conséquence (*so*, *that's why*).
- **unless** : à moins que, si… ne.
- **otherwise** : sinon.
- **to hurry (up)** : se dépêcher.
- **to miss** : rater, manquer.
- **to fail (an exam)** : échouer à un examen.
- **an imperative** : l'impératif (*Hurry up !*).
