## L’essentiel du chapitre

:::formule Le comparatif de supériorité
- Adjectif **court** (1 syllabe, ou *-y*) → **-er + than** : *taller than*, *happier than*, *bigger than*.
- Adjectif **long** (2 syllabes ou plus) → **more + adjectif + than** : *more difficult than*, *more interesting than*.
:::

:::formule Les irréguliers
| Positif | Comparatif | Superlatif |
| --- | --- | --- |
| good | better | best |
| bad | worse | worst |
| far | farther / further | farthest / furthest |
| little | less | least |
| many / much | more | most |
:::

:::formule Égalité et infériorité
- Égalité : **as + adjectif + as** → *Aminata is as tall as Astou.*
- Infériorité : **less + adjectif + than** → *This box is less heavy than that one.*
- Noms : *fewer + nom pluriel* (*fewer pupils*), *less + indénombrable* (*less water*).
:::

:::formule Le superlatif
- Adjectif court : **the + -est** → *the tallest, the biggest*.
- Adjectif long : **the most + adjectif** → *the most beautiful, the most difficult*.
- Suivi de **in** (lieu : *the best pupil **in** the class*) ou **of** (groupe : *the youngest **of** the three*).
:::

:::formule Les adverbes
- En *-ly* : **more + adverbe** → *more quickly than*.
- Irréguliers : *well → better*, *badly → worse*, *fast → faster*, *hard → harder*, *early → earlier*.
:::

## Méthode express

1. Repère l’adjectif ou l’adverbe à comparer.
2. Compte les syllabes : courte → **-er** ; longue → **more**.
3. Plus → *-er/more … than* ; moins → *less … than* ; aussi → *as … as* ; le plus → *the -est / the most*.
4. Vérifie les irréguliers : *good/better/best*, *bad/worse/worst*, *far/farther/farthest*.
5. Relis : *than* bien présent ? *the* bien présent devant le superlatif ?

:::erreur Les erreurs qui coûtent des points
1. Double marque : ~~*more easier*~~ → ***easier*** ; ~~*more taller*~~ → ***taller***.
2. Oublier *than* : ~~*bigger Saint-Louis*~~ → ***bigger than Saint-Louis***.
3. Superlatif sans *the* : ~~*He is best*~~ → ***He is the best***.
4. *as … as* incomplet : ~~*as tall Astou*~~ → ***as tall as Astou***.
5. Irréguliers inventés : ~~*goodest*~~, ~~*worser*~~ → ***the best***, ***worse***.
6. Confondre *less* et *fewer* : *less* + indénombrable, *fewer* + pluriel.
:::

## Vocabulaire

- **Comparatif (comparative)** : degré qui compare deux termes (*taller than*).
- **Superlatif (superlative)** : degré du plus haut niveau (*the tallest*).
- **Positif (positive)** : degré simple de l’adjectif (*tall*).
- **Than** : conjonction qui introduit le terme comparé (« que »).
- **As … as** : structure de l’égalité (« aussi … que »).
- **Less / fewer** : « moins de » (indénombrable / pluriel).
- **Adverbe** : mot qui modifie un verbe (*fast, well, quickly*).
- **Syllabe** : nombre de sons d’un mot (détermine *-er* ou *more*).
