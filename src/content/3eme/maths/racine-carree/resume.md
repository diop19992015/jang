## L’essentiel du chapitre

:::formule Définition
Pour $a \geqslant 0$, $\sqrt{a}$ est le nombre **positif ou nul** dont le carré vaut $a$ :
$$
x = \sqrt{a} \iff x \geqslant 0 \text{ et } x^2 = a
$$
:::

:::formule Propriétés fondamentales
Pour $a \geqslant 0$ et $b \geqslant 0$ :
$$
(\sqrt{a})^2 = a
$$
$$
\sqrt{a^2} = |a|
$$
$$
\sqrt{a} \times \sqrt{b} = \sqrt{a \times b}
$$
$$
\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \quad (b > 0)
$$
:::

:::formule Équation du type $x^2 = a$
$$
x^2 = a \ (a \geqslant 0) \iff x = \sqrt{a} \text{ ou } x = -\sqrt{a}
$$
Si $a < 0$ : **aucune solution**.
:::

:::formule Calcul sur les radicaux
- Simplifier : $\sqrt{12} = 2\sqrt{3}$, $\sqrt{75} = 5\sqrt{3}$, $\sqrt{48} = 4\sqrt{3}$.
- Additionner : $5\sqrt{3} + 4\sqrt{3} = 9\sqrt{3}$.
- Produit : $2\sqrt{3} \times 5\sqrt{3} = 30$.
- Quotient : $\sqrt{50} \div \sqrt{2} = \sqrt{25} = 5$.
:::

:::formule Carré et Pythagore
- Côté d’un carré de surface $S$ : $a = \sqrt{S}$.
- Diagonale d’un carré de côté $a$ : $d = a\sqrt{2}$.
- Hypoténuse d’un triangle rectangle : $c = \sqrt{a^2+b^2}$.
:::

## Méthode express

1. **Calculer $\sqrt{a}$** : chercher le carré parfait le plus proche ; sinon décomposer $a = b^2 \times c$ et écrire $b\sqrt{c}$.
2. **Simplifier un radical** : sortir du radical tous les facteurs carrés parfaits ($\sqrt{4}=2$, $\sqrt{9}=3$, $\sqrt{25}=5$).
3. **Additionner** : réduire uniquement les radicaux semblables (même nombre sous le radical).
4. **Résoudre $x^2 = a$** : vérifier le signe de $a$, calculer $\sqrt{a}$, écrire les **deux** solutions opposées.
5. **Problème** : traduire « surface → côté » par $\sqrt{S}$ et « Pythagore → longueur » par $\sqrt{a^2+b^2}$.

:::erreur Les erreurs qui coûtent des points
1. Écrire $\sqrt{9} = -3$ : la notation $\sqrt{\phantom{x}}$ ne désigne que la valeur **positive**.
2. Confondre $\sqrt{a^2} = |a|$ avec $a$ : si $x$ peut être négatif, $\sqrt{x^2} = -x$.
3. Oublier la deuxième solution de $x^2 = 144$ : $x = 12$ **ou** $x = -12$.
4. Additionner sous le radical : $\sqrt{9}+\sqrt{16} = 7$, pas $\sqrt{25} = 5$.
5. Donner une longueur négative ou oublier l’unité (cm, m, FCFA).
:::

## Vocabulaire

- **Racine carrée** : nombre positif ou nul dont le carré est égal au nombre donné.
- **Radical** : signe $\sqrt{}$ et nombre qu’il encadre.
- **Carré parfait** : carré d’un entier ($1, 4, 9, 16, 25, 36, 49, 64, 81, 100$…).
- **Radicaux semblables** : radicaux qui portent sur le même nombre ($5\sqrt{3}$ et $4\sqrt{3}$).
- **Nombre irrationnel** : nombre qui ne s’écrit pas sous forme de fraction, comme $\sqrt{2}$.
- **$|a|$ (valeur absolue)** : partie positive de $a$ ; $|-7| = 7$.
