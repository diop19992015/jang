## Question

Que vaut $\sqrt{144}$ ?

- [ ] $-12$
- [x] $12$
- [ ] $144$
- [ ] $1{,}2$

> $\sqrt{144}$ désigne le nombre positif dont le carré vaut $144$. Or $12^2 = 144$, donc $\sqrt{144} = 12$. L’écriture $\sqrt{\phantom{x}}$ donne toujours un résultat positif ou nul.

## Question

Quelle est la forme simplifiée de $\sqrt{75}$ ?

- [ ] $25\sqrt{3}$
- [ ] $5\sqrt{5}$
- [x] $5\sqrt{3}$
- [ ] $3\sqrt{5}$

> On décompose $75 = 25 \times 3$, et $25$ est un carré parfait : $\sqrt{75} = \sqrt{25} \times \sqrt{3} = 5\sqrt{3}$. Vérification : $(5\sqrt{3})^2 = 25 \times 3 = 75$.

## Question

Combien de solutions a l’équation $x^2 = 49$ ?

- [ ] Une seule : $x = 7$
- [ ] Aucune
- [x] Deux : $x = 7$ ou $x = -7$
- [ ] Quatre

> Un carré égal à $49$ peut provenir de $7$ ou de $-7$, car $7^2 = 49$ et $(-7)^2 = 49$. Il faut donc toujours donner les **deux** solutions opposées.

## Question

Moussa calcule $\sqrt{9} + \sqrt{16}$. Que trouve-t-il ?

- [ ] $\sqrt{25} = 5$
- [ ] $12$
- [x] $7$
- [ ] $13$

> On calcule chaque racine séparément : $\sqrt{9} = 3$ et $\sqrt{16} = 4$, donc $3 + 4 = 7$. L’erreur classique est d’additionner ce qui est sous le radical : $\sqrt{9+16} = 5$ est un autre calcul !
