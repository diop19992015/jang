## Question

Dans un triangle $ABC$ rectangle en $A$, quelle est la définition de $\cos B$ ?

- [ ] $\cos B = \dfrac{AC}{BC}$, le côté opposé sur l'hypoténuse
- [x] $\cos B = \dfrac{AB}{BC}$, le côté adjacent sur l'hypoténuse
- [ ] $\cos B = \dfrac{AC}{AB}$, le côté opposé sur le côté adjacent
- [ ] $\cos B = \dfrac{BC}{AB}$, l'hypoténuse sur le côté adjacent

> Le cosinus est le rapport du côté **adjacent** à l'angle sur l'hypoténuse. Ici l'hypoténuse est $[BC]$ (opposée à l'angle droit $A$) et le côté adjacent à $B$ est $[AB]$, donc $\cos B = \dfrac{AB}{BC}$. Le rapport $\dfrac{AC}{AB}$ est la tangente de $B$.

## Question

Un triangle est rectangle en $A$, $AB=7$ cm et $BC=10$ cm. Quelle relation permet de calculer l'angle $B$ ?

- [ ] $\sin B = \dfrac{7}{10}$
- [x] $\cos B = \dfrac{7}{10}$, donc $B = \cos^{-1}(0{,}7)$
- [ ] $\tan B = \dfrac{7}{10}$
- [ ] $B = \cos(0{,}7)$ avec la touche cosinus

> $AB$ est le côté adjacent à $B$ et $BC$ est l'hypoténuse : on utilise le cosinus, $\cos B = \dfrac{7}{10} = 0{,}7$. Pour retrouver l'angle, on appuie sur la touche inverse $\cos^{-1}$ (et non sur $\cos$), ce qui donne $B \approx 45{,}6°$.

## Question

Quelle est la valeur de $\sin 30°$ ?

- [ ] $\dfrac{\sqrt{3}}{2}$
- [ ] $\dfrac{\sqrt{2}}{2}$
- [x] $\dfrac{1}{2}$
- [ ] $\sqrt{3}$

> Dans le triangle rectangle isocèle en $45°$, on trouve $\dfrac{\sqrt{2}}{2}$ ; $\sin 30° = \dfrac{1}{2}$ (le côté opposé à $30°$ vaut la moitié de l'hypoténuse). $\dfrac{\sqrt{3}}{2}$ est la valeur de $\sin 60°$.

## Question

Moussa est à $180$ m du pied d'un mât et mesure un angle d'élévation de $30°$. Quelle est la hauteur $h$ du mât ?

- [ ] $h = \dfrac{180}{\tan 30°} \approx 312$ m
- [x] $h = 180 \times \tan 30° \approx 103{,}9$ m
- [ ] $h = 180 \times \cos 30° \approx 155{,}9$ m
- [ ] $h = 180 \times \sin 30° = 90$ m

> La hauteur est le côté **opposé** à l'angle et la distance au sol est le côté **adjacent** : on utilise la tangente, $\tan 30° = \dfrac{h}{180}$, donc $h = 180 \times \dfrac{\sqrt{3}}{3} = 60\sqrt{3} \approx 103{,}9$ m.
