## Question

Quel est le coefficient directeur de l’application affine $y = -4x + 7$ ?

- [ ] $7$
- [x] $-4$
- [ ] $11$
- [ ] $-7$

> Dans $y = ax + b$, le coefficient directeur est $a$. Ici $a = -4$ et $b = 7$. Le coefficient directeur négatif indique que l’application est décroissante.

## Question

L’application $y = 3x - 5$ est :

- [ ] Décroissante
- [x] Croissante
- [ ] Constante
- [ ] Ni croissante ni décroissante

> Le coefficient directeur $a = 3$ est positif, donc l’application est croissante : quand $x$ augmente, $y$ augmente aussi. Le terme $-5$ n’intervient pas dans le sens de variation.

## Question

Pour $y = 2x + 1$, quelle est l’image de $4$ ?

- [ ] $2$ (car $4 - 2 = 2$)
- [ ] $8$
- [x] $9$
- [ ] $4{,}5$

> L’image de $4$ s’obtient en remplaçant $x$ par $4$ : $y = 2 \times 4 + 1 = 8 + 1 = 9$. Pour trouver un antécédent, c’est l’inverse : on résout une équation.

## Question

Un taxi facture $y = 100x + 500$ FCFA pour $x$ kilomètres. Combien coûte une course de $15$ km ?

- [ ] $1500$ FCFA
- [x] $2000$ FCFA
- [ ] $500$ FCFA
- [ ] $100$ FCFA

> On remplace $x$ par $15$ : $y = 100 \times 15 + 500 = 1500 + 500 = 2000$ FCFA. Le terme $500$ est la prise en charge, ajoutée quel que soit le trajet.
