## Deux manières de dominer

Après le congrès de Berlin (1884-1885), les puissances doivent **administer** les territoires conquis. Deux modèles dominent :

:::formule Deux systèmes coloniaux
| | Colonisation **française** | Colonisation **britannique** |
| --- | --- | --- |
| Doctrine | **Assimilation**, puis association | **Administration indirecte** |
| Principe | L’Africain doit devenir un « Français » : même administration, même droit | L’Africain est gouverné par ses **chefs traditionnels**, sous contrôle britannique |
| Rôle des chefs | Nommés, révocables, simples agents de l’administration | Maintenus : rois, émirs et chefs locaux, « bâtons » du roi |
| Exemples | AOF (Sénégal, Côte d’Ivoire…), Madagascar | Nigeria, Inde, Gold Coast, Uganda |
:::

:::definition Administration directe
Mode d’administration coloniale où l’État colonial gouverne lui-même le territoire par ses propres agents (gouverneurs, administrateurs, cercles), en marginalisant ou en plaçant sous contrôle les autorités traditionnelles. C’est le modèle français.
:::

:::definition Administration indirecte
Mode d’administration coloniale où l’État colonial s’appuie sur les **autorités traditionnelles** (rois, émirs, chefs) pour gouverner, tout en contrôlant ces chefs et en les empêchant de nuire à ses intérêts. C’est le modèle britannique (Lord Lugard).
:::

## La colonisation française : l’assimilation

Le principe officiel de la France est l’**assimilation** : en théorie, les colonies sont appelées à devenir des parties intégrantes de la France, avec les mêmes lois et les mêmes droits.

:::formule Les principes de l’assimilation
| Principe | Application |
| --- | --- |
| Centralisation | Un gouverneur général à la tête de chaque colony (puis de l’AOF) |
| Administration directe | Administrateurs français dans les cercles et les postes |
| Droit français | Les « citoyens » des communes sont soumis aux lois françaises |
| École | former les évolués : école **William Ponty** (1903) |
| Idéologie | La « mission civilisatrice » : éduquer pour assimiler |
:::

:::erreur L’assimilation, un principe inégalitaire
En réalité, **tous les Africains ne sont pas citoyens** : la majorité est composée de **« sujets »**, soumis au code de l’indigénat, sans droits politiques. Seuls les habitants des quatre communes du Sénégal (Saint-Louis, Gorée, Rufisque, Dakar) sont pleinement citoyens : **Blaise Diagne**, élu député du Sénégal en **1914**, est le premier Africain siégeant au Parlement français.
:::

### Le code de l’indigénat

:::definition Code de l’indigénat
Ensemble de règles qui soumet les « sujets » des colonies à des **pénalités administratives** jugées sans procès : amendes, corvées, assignations à résidence, travaux forcés.
:::

Avec l’indigénat, le système français réserve aux Africains un régime d’exception : pas de justice normale, obéissance immédiate à l’administrateur.

### L’administration directe à la française

- le **gouverneur général** (à Dakar pour l’AOF) nommé par Paris ;
- les **gouverneurs** de colonies et les **administrateurs de cercle** ;
- les **chefs de canton et de village** : nommés ou validés par l’administration, **salariés et révocables**, souvent appelés « chefs à bâton » ;
- les **prestations** (corvées) et l’**impôt de capitation** financent les routes et les chantiers.

:::exemple Le Sénégal dans l’AOF
Le Sénégal est le chef de file : l’**Afrique-Occidentale française** est créée en **1895** (capitale Saint-Louis, puis **Dakar** en 1902). Elle réunit **huit colonies** : Sénégal, Mauritanie, Guinée, Côte d’Ivoire, Haute-Volta, Niger, Dahomey et Soudan français. Dakar devient le grand port et l’entrée de l’empire français.
:::

## La colonisation britannique : l’administration indirecte

Les Britanniques préfèrent gouverner **à travers** les structures africaines existantes : c’est l’**administration indirecte**, théorisée par Lord **Lugard** (gouverneur du Nigeria, puis livre *Le Double Mandat*, 1922).

:::formule Le fonctionnement de l’administration indirecte
| Élément | Fonctionnement |
| --- | --- |
| Chefs traditionnels | Rois, émirs (émirat de Sokoto) et chefs maintenus en place |
| Résidents britanniques | Supervisent les chefs et contrôlent les décisions |
| Fiscalité | Les chefs lèvent les impôts pour le compte de la couronne |
| Justice | Tribunaux de « natifs » appliquant les coutumes, sauf gravité |
| Idéologie | Le « double mandat » : gouverner pour le peuple et pour l’Europe |
:::

:::remarque Les limites de l’indirect rule
Le chef traditionnel n’est plus vraiment indépendant : il est **choisi, contrôlé et révoqué** par les Britanniques s’il résiste. L’administration indirecte fait souvent une **coupe nette** : elle garde les structures qui servent et démantèle celles qui résistent (l’empire d’Asanté au Ghana est brisé après les guerres ashanti).
:::

:::piege Pas d’administration indirecte partout
L’administration indirecte s’applique là où existent des royaumes organisés (Nigeria du Nord, Inde, Ouganda). Dans les colonies de **peuplement** blanc (Kenya, Rhodésie du Sud, Afrique du Sud), les Britanniques appliquent une administration **directe** : terres confisquées, travail forcé, minorités blanches au pouvoir.
:::

## Comparaison des deux systèmes

:::formule Tableau récapitulatif
| Critère | France (administration directe) | Grande-Bretagne (administration indirecte) |
| --- | --- | --- |
| Doctrine | Assimilation, puis association | Indirect rule (double mandat) |
| Chefs | Nommés, révocables, agents de l’État | Maintenus, contrôlés par un résident |
| Droit | Code de l’indigénat pour les sujets | Tribunaux de natifs + coutumes |
| Citoyenneté | Possible en théorie (communes, évolués) | Statuts séparés : sujets, princes, blancs |
| Éducation | Écoles publiques (William Ponty) | Missions, écoles de chefs |
| Centralisation | Forte (gouverneur général) | Faible (autonomies locales) |
| Exemples | AOF, Madagascar | Nigeria, Inde, Gold Coast |
:::

3. Termine par **un exemple de chaque côté** (AOF pour la France, Nigeria pour la Grande-Bretagne).
:::

## Ce qu’il faut retenir

- Deux modèles : **administration directe** (française) et **administration indirecte** (britannique).
- La France prône l’**assimilation** : centralisation, agents français, code de l’indigénat, évolués (William Ponty, Blaise Diagne en 1914).
- La Grande-Bretagne pratique l’**indirect rule** de Lord Lugard : rois et émirs maintenus mais contrôlés, « double mandat » (1922).
- Les deux systèmes visent le même but : **dominer économiquement** (impôts, corvées, cultures d’exportation, chemins de fer) tout en gardant le pouvoir politique.
- Le Sénégal, pilier de l’**AOF (1895, Dakar en 1902)**, est le meilleur exemple français.
