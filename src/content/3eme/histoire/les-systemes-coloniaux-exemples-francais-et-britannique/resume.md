## L’essentiel du chapitre

:::formule Les deux systèmes
- **Administration directe** (France) : l’État colonial gouverne par ses propres agents (gouverneurs, administrateurs de cercle) ; les chefs traditionnels sont nommés, révocables, salariés.
- **Administration indirecte** (Grande-Bretagne) : l’État colonial gouverne **à travers** les chefs traditionnels (rois, émirs), qu’un résident contrôle : c’est le « double mandat » de Lord Lugard (1922).
:::

:::formule Comparaison France / Grande-Bretagne
| Critère | France | Grande-Bretagne |
| --- | --- | --- |
| Doctrine | Assimilation, puis association | Administration indirecte |
| Chefs | Agents de l’État, révocables | Maintenus mais contrôlés |
| Droit | Code de l’indigénat (sujets) | Tribunaux de natifs, coutumes |
| Citoyenneté | Possible (4 communes, évolués) | Statuts séparés |
| Exemples | AOF, Madagascar | Nigeria, Inde, Gold Coast |
:::

:::formule La colonisation française en détails
- **Assimilation** : mêmes lois en théorie, « mission civilisatrice », école (William Ponty, 1903).
- **Code de l’indigénat** : sanctions sans procès (amendes, corvées, travaux forcés) pour les sujets.
- **Administration directe** : gouverneur général → gouverneurs → administrateurs de cercle → chefs.
- **AOF (1895)** : huit colonies, capitale Saint-Louis puis **Dakar (1902)** ; Sénégal = pilier.
- **Blaise Diagne**, député en **1914** : premier Africain au Parlement français.
:::

:::formule La colonisation britannique en détails
- Lord **Lugard** : gouverneur du Nigeria, théoricien de l’indirect rule.
- **Émirs et rois** maintenus (émirat de Sokoto), **résident** britannique qui contrôle.
- Chefs : impôts et justice locaux pour le compte de la couronne.
- Exception : colonies de peuplement (Kenya, Afrique du Sud) → administration **directe** et terres confisquées.
:::

:::formule Ce que les deux systèmes ont en commun
| Domaine | Réalité coloniale |
| --- | --- |
| Politique | Perte de souveraineté des peuples africains |
| Économique | Impôts, corvées (prestations), cultures d’exportation (arachide), chemins de fer vers les ports |
| Social | Chefs utilisés, élites scolarisées, inégalités entre « citoyens » et « sujets » |
| Idéologique | « Mission civilisatrice » |
:::

## Méthode express

1. « Défie l’administration directe » → gouvernement **par les agents de l’État colonial** (France).
2. « Défie l’administration indirecte » → gouvernement **par les chefs traditionnels contrôlés** (Grande-Bretagne).
3. « Compare les deux » → tableau **4 critères** + **1 exemple** de chaque côté.
4. « Montre que l’assimilation est inégalitaire » → citoyens des 4 communes **vs** sujets du code de l’indigénat + Blaise Diagne (1914).
5. « Le Sénégal dans la colonisation française » → **AOF 1895, Dakar 1902, huit colonies, William Ponty**.

:::erreur Les erreurs qui coûtent des points
1. Inverser les modèles : la France = **directe**, la Grande-Bretagne = **indirecte**.
2. Croire que l’indirect rule laissait les chefs libres : ils étaient **contrôlés et révocables**.
3. Écrire que tous les Africains étaient citoyens : la majorité sont des **sujets** soumis à l’indigénat.
4. Oublier les exemples attendus : **AOF** pour la France, **Nigeria** (ou Inde) pour la Grande-Bretagne.
5. Donner l’assimilation comme une réussite : c’est un **principe** rarement appliqué, qui sert à justifier la domination.
:::

## Vocabulaire

- **Administration directe** : gouvernement par les agents de la puissance coloniale (modèle français).
- **Administration indirecte** : gouvernement par les chefs traditionnels contrôlés (modèle britannique).
- **Assimilation** : doctrine française visant à transformer les sujets en Français.
- **Association** : doctrine de la fin du XIXe siècle : associer les Africains sans les assimiler.
- **Indigénat** : code de sanctions administratives sans procès.
- **Sujet colonie** : Africain soumis à l’administration, sans droits politiques.
- **Évolué** : Africain scolarisé à l’européenne.
- **Cercle** : subdivision administrative dirigée par un administrateur français.
- **Résident** : agent britannique qui contrôle les chefs.
- **Double mandat** : idée de Lugard : gouverner pour le peuple et pour l’Europe.
- **AOF** : Afrique-Occidentale française (1895).
- **Prestation** : corvée de travail imposée aux populations.
