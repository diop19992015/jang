## Les deux systèmes coloniaux

:::formule Administration directe vs administration indirecte
| Critère | Administration directe (France) | Administration indirecte (Grande-Bretagne) |
| --- | --- | --- |
| Principe | L’État colonial gouverne lui-même | L’État colonial gouverne par les chefs |
| Chefs traditionnels | Nommés, salariés, révocables (« chefs à bâton ») | Maintenus, encadrés par un résident |
| Agents coloniaux | Gouverneur général, gouverneurs, administrateurs de cercle | Résidents, commissaires de district |
| Droit | Code de l’indigénat | Tribunaux de natifs et coutumes |
| Objectif | Assimiler puis intégrer | Contrôler en s’appuyant sur l’existence locale |
| Exemples | AOF, Madagascar, Indochine | Nigeria, Inde, Gold Coast, Ouganda |
:::

:::remarque Retenir en une phrase
- **Directe** = « c’est l’Europe qui commande directement » ;
- **Indirecte** = « c’est le chef africain qui signe, mais l’Européen qui décide ».
:::

## Chronologie

:::formule Dates clés de la colonisation administrative
| Date | Événement |
| --- | --- |
| 1884-1885 | Congrès de Berlin : règles du partage |
| 1885 | Chemin de fer Dakar–Saint-Louis achevé (Sénégal) |
| 1887-1900 | Généralisation du code de l’indigénat aux colonies |
| 1895 | Création de l’**Afrique-Occidentale française (AOF)** |
| 1902 | **Dakar** devient capitale de l’AOF |
| 1903 | Ouverture de l’école **William Ponty** (Sénégal) |
| 1912-1919 | Lord Lugard gouverne le **Nigeria** en administration indirecte |
| 1914 | **Blaise Diagne**, premier député africain de France |
| 1922 | Parution du **Double Mandat** de Lugard |
| 1945 | Création du franc CFA |
:::

## Acteurs et lieux

:::formule Qui est qui ?
| Acteur | Système | Rôle |
| --- | --- | --- |
| **Gouverneur général de l’AOF** | Français | Dirige l’empire d’Ouest depuis Dakar |
| **Administrateur de cercle** | Français | Commande le cercle, contrôle les chefs |
| **Chef de canton / village** | Français | Agent local, révocable, responsable de l’impôt |
| **Lord Lugard** | Britannique | Théoricien et appliquateur de l’administration indirecte |
| **Résident britannique** | Britannique | Contrôle le roi ou l’émir |
| **Roi / émir** | Britannique | Gouverne au quotidien pour le compte de la couronne |
| **Évolué (William Ponty)** | Français | Africain scolarisé, intermédiaire de l’administration |
:::

## Causes et conséquences

:::formule Finalités et effets des systèmes coloniaux
| Finalité coloniale | Moyen | Conséquence pour les Africains |
| --- | --- | --- |
| Rentabilité économique | Impôts, corvées (prestations), cultures d’exportation (arachide) | Travail forcé, abandon de cultures vivrières |
| Contrôle politique | Indigénat ou indirect rule | Perte de souveraineté, justice d’exception |
| Faible coût | Recours aux chefs | Chefs délégitimés parfois aux yeux des populations |
| Reproduction sociale | Écoles (William Ponty), missions | Élites évolués, puis premières revendications politiques |
:::

:::formule L’exemple sénégalais
| Repère | Détail |
| --- | --- |
| AOF | Fédération créée en 1895 : huit colonies |
| Capitale | Saint-Louis, puis **Dakar (1902)** |
| Élite | École William Ponty (1903), Blaise Diagne (1914) |
| Économie | Arachide, port de Dakar, chemin de fer |
| Citoyenneté | Quatre communes (Saint-Louis, Gorée, Rufisque, Dakar) : citoyenneté française |
:::
