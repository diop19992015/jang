## Question

Quelle est la caractéristique de l’administration britannique dite « indirecte » ?

- [ ] Les Britanniques suppriment tous les rois africains
- [ ] Ils gouvernent seuls, sans intermédiaire africain
- [x] Ils gouvernent à travers les chefs traditionnels qu’ils contrôlent
- [ ] Ils donnent l’indépendance aux royaumes africains

> L’administration indirecte s’appuie sur les rois, émirs et chefs locaux, encadrés par un résident britannique qui les contrôle et peut les révoquer : c’est le « double mandat » de Lord Lugard.

## Question

Quelle est la différence essentielle entre l’administration française et l’administration britannique ?

- [ ] La France abolit l’impôt, la Grande-Bretagne l’augmente
- [x] La France gouverne directement par ses agents, la Grande-Bretagne par les chefs traditionnels
- [ ] La France applique l’indirect rule et la Grande-Bretagne l’assimilation
- [ ] Aucune : les deux systèmes sont identiques

> La France pratique l’administration **directe** (gouverneurs et administrateurs de cercle, chefs nommés et révocables) au nom de l’assimilation ; la Grande-Bretagne pratique l’administration **indirecte** en maintenant les structures locales sous contrôle.

## Question

Quel régime juridique s’appliquait aux « sujets » des colonies françaises ?

- [ ] Le code civil français complet
- [ ] La Constitution britannique
- [x] Le code de l’indigénat
- [ ] Les coutumes locales uniquement

> Le code de l’indigénat soumet les sujets à des sanctions administratives (amendes, corvées, travaux forcés) sans procès. Le code civil complet ne s’applique pleinement qu’aux citoyens des quatre communes du Sénégal.

## Question

Quel exemple caractérise le système français en Afrique de l’Ouest ?

- [ ] Le Nigeria en administration indirecte
- [x] L’Afrique-Occidentale française (AOF), créée en 1895
- [ ] L’émirat de Sokoto sous un résident britannique
- [ ] Le Kenya, colonie de peuplement

> L’AOF (1895), fédération de huit colonies dirigée depuis Dakar (1902), est le parfait exemple du modèle français : administration directe, gouverneur général, code de l’indigénat. Le Nigeria et l’émirat de Sokoto illustrent le modèle britannique, le Kenya la colonie de peuplement.
