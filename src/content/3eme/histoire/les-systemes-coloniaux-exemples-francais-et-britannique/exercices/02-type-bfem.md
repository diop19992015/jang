## Énoncé

**Document 1**

« Dans l’Afrique-Occidentale française, le gouverneur général réside à Dakar. Sous lui, les gouverneurs de colonies et les administrateurs de cercle commandent directement. Les chefs de canton et de village, nommés ou validés par l’administration, perçoivent l’impôt et répondent de l’ordre. Ils sont salariés et peuvent être révoqués. Les sujets soumis au code de l’indigénat sont passibles d’amendes et de travaux forcés prononcés sans procès. »

*D’après un manuel d’administration coloniale.*

**Document 2**

« Au Nigeria, les Britanniques ont maintenu les émirs de l’ancien califat du Sokoto. Un résident britannique siège auprès de chaque émir : il contrôle la politique, les finances et la justice. Les émirs lèvent les impôts et administrent leurs États, mais toute décision importante doit recevoir l’accord du résident. L’émir qui résiste peut être révoqué et remplacé. »

*D’après Lord Lugard, Le Double Mandat (extraits).*

**Partie A.** (5 points)
1. Quel système est décrit dans le document 1 ? Cite deux caractéristiques de ce système. (2,5 pts)
2. Quel système est décrit dans le document 2 ? Qui est le chef de l’administration indirecte ? (2,5 pts)

**Partie B.** (3 points)
3. Complétez le tableau de comparaison : (3 pts)

| Critère | Colonisation française | Colonisation britannique |
| --- | --- | --- |
| Doctrine |  |  |
| Rôle des chefs |  |  |
| Exemple |  |  |

**Partie C.** (2 points)
4. Expliquez pourquoi les deux systèmes, malgré leurs différences, visaient le même objectif. (2 pts)

## Solution

**1.** Le document 1 décrit l’**administration directe** (modèle français). Deux caractéristiques parmi : centralisation depuis Dakar (gouverneur général, gouverneurs, administrateurs de cercle) ; chefs locaux **nommés, salariés et révocables**, simples agents ; application du **code de l’indigénat** aux sujets.

**2.** Le document 2 décrit l’**administration indirecte** (modèle britannique). Son théoricien et principal appliquateur est **Lord Lugard** (gouverneur du Nigeria, auteur du *Double Mandat* en 1922).

**3.**

| Critère | Colonisation française | Colonisation britannique |
| --- | --- | --- |
| Doctrine | Assimilation (puis association) | Administration indirecte (double mandat) |
| Rôle des chefs | Nommés, révocables, agents de l’État | Maintenus, mais contrôlés par un résident |
| Exemple | AOF (Sénégal, 1895) | Nigeria (émirat de Sokoto) |

**4. Paragraphe attendu (modèle).**

Même s’ils diffèrent sur la forme, les deux systèmes poursuivent le même objectif : **dominer** les colonies au moindre coût. L’administration directe permet à la France de centraliser le pouvoir et d’imposer l’impôt et le travail forcé par ses administrateurs ; l’administration indirecte permet à la Grande-Bretagne de faire la même chose à travers les chefs, qui perçoivent les impôts et font respecter l’ordre sans que Londres paie une armée d’agents. Dans les deux cas, la colonisation reste **économique** (cultures d’exportation, chemins de fer vers les ports) et **politique** (perte de souveraineté, sanctions d’exception), et dans les deux cas les Africains ne décident de rien : c’est ce qui nourrira les revendications d’indépendance.

:::methode Ce que le correcteur attend
- **Partie A (5 pts)** : administration directe + deux caractéristiques (2,5 pts) ; administration indirecte + Lugard (2,5 pts).
- **Partie B (3 pts)** : une ligne complète = 1 pt (doctrine, chefs, exemple).
- **Partie C (2 pts)** : un objectif commun (domination économique ou politique) argumenté avec un moyen de chaque système (1 pt), et une conclusion montrant que les Africains sont exclus du pouvoir (1 pt).
:::

:::erreur Les erreurs qui coûtent des points
1. Inverser les deux systèmes : **France = directe**, **Grande-Bretagne = indirecte**.
2. Écrire que les chefs traditionnels étaient libres sous l’indirect rule : ils étaient **contrôlés et révocables**.
3. Donner des exemples vagues : cite toujours **AOF** et **Nigeria (émirat de Sokoto)**.
4. Oublier l’objectif commun : contrôle politique **et** exploitation économique.
:::
