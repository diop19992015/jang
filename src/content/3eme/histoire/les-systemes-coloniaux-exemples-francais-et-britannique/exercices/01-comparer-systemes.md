## Énoncé

**1.** Complète la fiche de synthèse :
- L’administration **directe** est appliquée par : ……………………
- L’administration **indirecte** est appliquée par : ……………………
- Son théoricien est : ……………………
- Sa doctrine s’appelle : ……………………

**2.** Classe ces situations dans le bon modèle :
- (a) L’émir de Sokoto lève les impôts sous le contrôle d’un résident britannique.
- (b) L’administrateur français de cercle nomme lui-même le chef de village.
- (c) Le roi du Nigeria est maintenu en place mais révocable par les Britanniques.
- (d) Le gouverneur général français dirige l’AOF depuis Dakar.

**3.** Complète le tableau de comparaison :

| Critère | France | Grande-Bretagne |
| --- | --- | --- |
| Doctrine |  |  |
| Chefs traditionnels |  |  |
| Exemple | AOF |  |

**4.** Donne deux raisons pour lesquelles le système français ne pouvait pas être totalement « assimilateur ».

## Solution

**1.**
- Administration **directe** : appliquée par la **France**.
- Administration **indirecte** : appliquée par la **Grande-Bretagne**.
- Théoricien : **Lord Lugard** (gouverneur du Nigeria, *Le Double Mandat*, 1922).
- Doctrine britannique : l’**administration indirecte** (« indirect rule ») ; doctrine française : l’**assimilation**, puis l’association.

**2.**
- (a) **Indirecte** : le chef exécute mais le résident britannique contrôle.
- (b) **Directe** : l’agent français nomme lui-même les autorités locales.
- (c) **Indirecte** : maintien apparent du roi, révocation possible.
- (d) **Directe** : centralisation depuis Dakar à la française.

**3.**

| Critère | France | Grande-Bretagne |
| --- | --- | --- |
| Doctrine | Assimilation (puis association) | Administration indirecte |
| Chefs traditionnels | Nommés, salariés, révocables : agents de l’administration | Maintenus en place mais contrôlés par un résident |
| Exemple | AOF (Sénégal…) | Nigeria (émirat de Sokoto) |

**4.** Deux raisons parmi : (1) le **code de l’indigénat** crée un statut d’exception pour les « sujets » : ils n’ont pas les droits des citoyens ; (2) l’**assimilation coûte trop cher** et demanderait de donner à tous les Africains les droits politiques français ; (3) les administrations coloniales ont **besoin des chefs** pour gouverner à faible coût et faire lever l’impôt.

:::remarque Vérification
La phrase à retenir : « Française = directe, britannique = indirecte. » Si tu confonds, tout le tableau de comparaison bascule.
:::
