## L’essentiel du chapitre

:::formule Qui sont les tirailleurs sénégalais ?
Soldats recrutés dans **toutes les colonies d’Afrique noire** au service de la France (corps structuré dès **1857**) ; **tirage au sort** imposé en **1912** ; mission de recrutement de **Blaise Diagne** en 1918.
:::

:::formule Les tirailleurs dans la Première Guerre mondiale (1914-1918)
| Date | Bataille / fait |
| --- | --- |
| 1914 | Premier contingent sur le front français |
| 1916 | **Verdun** et la **Somme** |
| 1917 | **Chemin des Dames** (offensive Nivelle) |
| 1918 | Recrutement par **Blaise Diagne** |
| Bilan | ~60 000 engagés, ~**30 000 morts**, 30 000+ Médailles militaires |
:::

:::formule Les tirailleurs dans la Deuxième Guerre mondiale (1939-1945)
- **1939-1940** : combats pour la France, nombreux prisonniers.
- **1941** : campagne de **Syrie** (armée de Vichy).
- **Novembre 1942** : débarquement en Afrique du Nord → passage à la **France libre**.
- **1944** : batailles d’**Italie (Monte Cassino)**, débarquement de **Provence**, **libération de la France**.
- **30 nov.-2 déc. 1944** : **mutinerie de Thiaroye** (Dakar) pour le paiement des soldes : une trentaine de tirailleurs tués.
:::

:::formule Les objectifs du dossier (méthode)
1. **Problématique** : une question claire de départ.
2. **Sources** : au moins deux natures de documents (textes, images, chiffres), tous **datés** et situés.
3. **Analyse** : pour chaque document — nature, date, auteur, message, intérêt.
4. **Classement** : chronologique (1914-1918 puis 1939-1945) ou thématique (recrutement / batailles / retour et revendications).
5. **Rédaction** : introduction → paragraphes argumentés citant les documents → conclusion.
:::

## Méthode express

1. **Situer** chaque fait dans la bonne guerre : Verdun et le Chemin des Dames (1916-1917) = Première Guerre ; Monte Cassino et Thiaroye (1944) = Deuxième Guerre.
2. **Analyser un document** en quatre points : nature → date → auteur → message.
3. **Constituer le dossier** : problématique → collecte variée → vérification → classement → présentation.
4. **Rédiger une réponse argumentée** : introduction (contexte et question), deux ou trois paragraphes (idée + preuve datée + explication), conclusion (bilan).
5. **Citer les documents** dans la rédaction : « Comme le montre le document 2… ».

:::erreur Les erreurs qui coûtent des points
1. Donner des **dates sans analyse** : le BFEM attend une réponse argumentée, pas une liste.
2. Classer des documents **non datés** ou d’une **seule nature** : dossier incomplet.
3. Confondre les batailles : **Chemin des Dames = 1917** (Première Guerre) ; **Monte Cassino = 1944** (Deuxième Guerre).
4. Oublier **Thiaroye (30 novembre - 2 décembre 1944)** : c’est l’événement clé sénégalais du chapitre.
5. Négliger la structure : sans introduction ni conclusion, la réponse perd au moins un point sur trois.
:::

## Vocabulaire

- **Tirailleur** : soldat des troupes coloniales françaises d’Afrique noire.
- **Engagé / tirage au sort** : modes de recrutement (volontaire puis obligatoire, 1912).
- **Front** : ligne de combat entre deux armées.
- **Prisonnier de guerre** : soldat capturé par l’ennemi.
- **Mutinerie** : révolte de soldats contre leurs chefs (Thiaroye, 1944).
- **France libre** : mouvement du général de Gaulle opposé à Vichy (1940-1944).
- **Problématique** : question de départ qui organise le dossier.
- **Source** : document d’époque (texte, image, témoignage) utilisé par l’historien.
- **Argument** : raison qui soutient une affirmation, appuyée par une preuve.
