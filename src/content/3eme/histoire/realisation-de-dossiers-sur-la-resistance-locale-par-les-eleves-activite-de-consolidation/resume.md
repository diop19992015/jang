## L'essentiel du chapitre

:::formule Le dossier historique en une phrase
Un dossier = **sujet choisi** + **documents cherchés** + **documents classés** + **rédaction** (introduction, analyse, conclusion).
:::

:::formule Les deux types de sources
- **Source primaire** : contemporaine des faits (lettre, discours, traité, photo, rapport, presse de l'époque).
- **Source secondaire** : écrit après les faits (manuel, ouvrage d'historien, encyclopédie).
:::

:::formule Les trois classements
| Classement | Critère | Exemple |
| --- | --- | --- |
| Chronologique | la date | 1859 → 1867 → 1886 → 1898 |
| Thématique | le thème | causes → acteurs → conséquences |
| Par nature | le type | textes / images / cartes |
:::

:::formule Les acteurs de la résistance locale

## Méthode express

1. **Choisir** un sujet précis (lieu + période + acteur) dont on trouve au moins trois documents.
2. **Chercher** : manuels, encyclopédies, archives, presse, témoignages, sites fiables.
3. **Sélectionner** selon trois critères : pertinence, fiabilité, diversité.
4. **Classer** : chronologique le plus souvent, sinon thématique ou par nature.
5. **Rédiger** : introduction (présentation + annonce) → analyse document par document → conclusion (réponse).
6. **Citer** chaque source : auteur, titre, date, entre guillemets pour les citations.

:::erreur Les erreurs qui coûtent des points
1. Recopier le document au lieu de le reformuler et de l'expliquer.
2. Oublier d'annoncer la nature et l'origine d'un document.
3. Classer hors de l'ordre chronologique quand le sujet est chronologique.
4. Conclure sans répondre à la question posée.
5. Confondre une source primaire (contemporaine) et une source secondaire (après coup).
:::

## Vocabulaire

- **Dossier** : ensemble de documents classés et rédigés autour d'un sujet.
- **Source** : document qui fournit une information sur le passé.
- **Source primaire** : document issu de l'époque étudiée.
- **Source secondaire** : document qui interprète l'époque étudiée.
- **Recherche documentaire** : recherche méthodique de documents fiables.
- **Citation** : reproduction exacte d'un passage entre guillemets, avec sa source.
- **Problématique** : question qui organise le dossier.
- **Résistance** : action d'opposition à une domination militaire ou politique.
- **Damel** : titre du souverain du Cayor.
