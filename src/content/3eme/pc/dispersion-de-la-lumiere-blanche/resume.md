## L'essentiel du chapitre

:::formule Dispersion
La **lumière blanche** est un mélange de toutes les couleurs. Un **prisme triangulaire** la **décompose** en un **spectre** : chaque couleur est déviée différemment (expérience de **Newton**, 1666).
:::

:::formule Le spectre visible
| Ordre | Couleur | Longueur d'onde |
| --- | --- | --- |
| 1 | Rouge | $620$–$750\ \mathrm{nm}$ |
| 2 | Orange | $590$–$620\ \mathrm{nm}$ |
| 3 | Jaune | $570$–$590\ \mathrm{nm}$ |
| 4 | Vert | $495$–$570\ \mathrm{nm}$ |
| 5 | Bleu | $450$–$495\ \mathrm{nm}$ |
| 6 | Indigo | $420$–$450\ \mathrm{nm}$ |
| 7 | Violet | $380$–$420\ \mathrm{nm}$ |

Le **rouge** est le moins dévié, le **violet** le plus dévié. $1\ \mathrm{nm} = 10^{-9}\ \mathrm{m}$.
:::

:::formule Recomposition
Second prisme placé **à l'inverse** (sommet en bas) ou **disque de Newton** en rotation rapide → on retrouve la lumière **blanche**. La lumière blanche est donc bien un mélange.
:::

:::formule Couleur des objets
- Corps **opaque** : couleur = lumière **réfléchie** (un objet rouge renvoie seulement le rouge).
- Corps **transparent** : couleur = lumière **transmise** (un verre bleu transmet surtout le bleu).
- **Blanc** : réfléchit toutes les couleurs ; **noir** : les absorbe toutes.
- Un objet rouge sous lumière bleue paraît **noir**.
:::

:::formule Arc-en-ciel
Chaque goutte de pluie joue le rôle d'un prisme : décomposition de la lumière du Soleil. Conditions : **soleil derrière** l'observateur, **pluie devant**. Ordre : **rouge en haut, violet en bas**.
:::

## Méthode express

1. Dire que la lumière blanche est un **mélange** de toutes les couleurs.
2. Nommer le prisme et l'expérience : **décomposition par un prisme, Newton (1666)**.
3. Citer l'ordre complet du spectre : **R**ouge, **O**range, **J**aune, **V**ert, **B**leu, **I**ndigo, **V**iolet.
4. Expliquer la recomposition : second prisme inversé ou disque de Newton → blanc.
5. Pour un objet : identifier s'il est éclairé en lumière blanche, puis retenir la couleur **réfléchie** (opaque) ou **transmise** (transparent).
6. Pour l'arc-en-ciel : goutte = prisme, soleil derrière, pluie devant, rouge en haut.

:::erreur Les erreurs qui coûtent des points
1. Inverser l'ordre du spectre (le violet n'est pas le moins dévié).
2. Dire que le prisme « fabrique » les couleurs : il les **sépare** seulement.
3. Oublier que le corps opaque prend la couleur **réfléchie** : un objet vert renvoie le vert et absorbe le reste.
4. Écrire que l'arc-en-ciel apparaît « devant le soleil » : c'est le **soleil derrière** l'observateur, la pluie devant.
:::

## Vocabulaire

- **Dispersion** : séparation de la lumière blanche en ses couleurs.
- **Prisme triangulaire** : solide transparent à faces planes qui dévie la lumière.
- **Spectre** : bande des couleurs obtenue après décomposition (rouge → violet).
- **Décomposition** : séparation ; **recomposition** : réunion en lumière blanche.
- **Réfractivité** : aptitude d'un milieu à dévier la lumière (elle varie avec la couleur).
- **Longueur d'onde** : distance entre deux crêtes de la lumière, en nanomètres (nm).
- **Transparent / translucide / opaque** : corps qui laisse passer toute la lumière / une partie / aucune.
- **Couleurs primaires additives** : rouge, vert, bleu (écrans de télévision).
