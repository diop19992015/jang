## Question

Dans la combustion du méthane, quel est le comburant ?

- [ ] Le méthane $CH_4$
- [x] Le dioxygène $O_2$
- [ ] Le dioxyde de carbone $CO_2$
- [ ] L'eau $H_2O$

> Le combustible est le corps qui brûle (le méthane), et le comburant est le corps qui permet la combustion : ici le dioxygène de l'air.

## Question

Quelle est l'équation-bilan équilibrée de la combustion complète du méthane ?

- [ ] $CH_4 + O_2 \longrightarrow CO_2 + H_2O$
- [ ] $CH_4 + 3\,O_2 \longrightarrow CO_2 + 2\,H_2O$
- [x] $CH_4 + 2\,O_2 \longrightarrow CO_2 + 2\,H_2O$
- [ ] $2\,CH_4 + O_2 \longrightarrow 2\,CO_2 + 4\,H_2O$

> Il faut $4$ atomes d'hydrogène à gauche, donc $2\,H_2O$ à droite. Cela apporte $2$ atomes d'oxygène dans l'eau, plus $2$ dans $CO_2$ : il faut donc $2\,O_2$ à gauche. Vérification : $1$ C, $4$ H et $4$ O de chaque côté.

## Question

Une combustion incomplète du carbone produit principalement :

- [ ] du dioxyde de carbone $CO_2$
- [x] du monoxyde de carbone $CO$
- [ ] de l'eau $H_2O$
- [ ] du dioxygène $O_2$

> Lorsque le dioxygène est insuffisant, le carbone ne peut pas former $CO_2$ : il se forme du monoxyde de carbone $CO$, gaz incolore, inodore et très toxique.
