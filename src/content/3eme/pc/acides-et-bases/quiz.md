## Question

Quelle couleur prend le bleu de bromothymol (BBT) dans une solution acide ?

- [ ] Bleu
- [x] Jaune
- [ ] Vert
- [ ] Rouge

> Dans une solution **acide** (pH < 7), le BBT est **jaune** ; il est **vert** dans une solution neutre et **bleu** dans une solution basique.

## Question

Quelle est l'équation-bilan de la réaction entre l'acide chlorhydrique $HCl$ et la soude $NaOH$ ?

- [x] $HCl + NaOH \longrightarrow NaCl + H_2O$
- [ ] $HCl + NaOH \longrightarrow ClNa + HOH_2$
- [ ] $HCl + NaOH \longrightarrow H_2O + NaH$
- [ ] $HCl + NaOH \longrightarrow ClOH + NaH$

> Une **neutralisation** donne toujours un **sel** et de l'eau : $HCl + NaOH \longrightarrow NaCl + H_2O$. L'équation est déjà équilibrée : 1 H, 1 Cl, 1 Na, 1 O de chaque côté.

## Question

Lors d'un dosage, la solution contient du BBT vert. Que peut-on en conclure ?

- [ ] La solution est très acide
- [ ] La solution est très basique
- [x] La solution est neutre : on vient d'atteindre l'équivalence
- [ ] La solution ne contient plus d'eau

> La couleur **verte** du BBT correspond à un pH de 7 : le milieu est **neutre**. C'est le virage qui signale l'**équivalence**, moment où l'acide et la base sont exactement neutralisés.

## Question

On dosage $20$ mL d'une solution de soude à $0{,}5$ mol/L avec une solution d'acide de concentration inconnue. Quelle est la quantité de matière de soude utilisée ?

- [ ] $0{,}02$ mol
- [x] $0{,}01$ mol
- [ ] $10$ mol
- [ ] $0{,}001$ mol

> $n = C \times V = 0{,}5 \times 0{,}02 = 0{,}01$ mol. Les volumes doivent être convertis en litres avant la multiplication.
