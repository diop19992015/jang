## L'essentiel du chapitre

:::formule Les trois milieux et le BBT
| Milieu | pH | Couleur du BBT |
| --- | --- | --- |
| Acide | $< 7$ | **Jaune** |
| Neutre | $= 7$ | **Vert** |
| Basique | $> 7$ | **Bleu** |

Moyen mnémotechnique : **J**aune = a**c**ide, **B**leu = **b**asique.
:::

:::formule Définitions
- **Acide** (Arrhenius) : espèce qui libère des ions $H^+$ dans l'eau (ex. $HCl$).
- **Base** (Brønsted) : espèce qui capte les ions $H^+$ et libère des ions $OH^-$ (ex. $NaOH$).
- **pH** : $pH = -\log[H^+]$, échelle de $0$ à $14$.
:::

:::formule Neutralisation (réaction type)
$$
HCl + NaOH \longrightarrow NaCl + H_2O
$$

**Acide + base → sel + eau.** Autres exemples :
$$
H_2SO_4 + 2\,NaOH \longrightarrow Na_2SO_4 + 2\,H_2O
$$
:::

:::formule Calcul de dosage
$$
n_{\text{base}} = C_{\text{base}} \times V_{\text{base}}, \qquad n_{\text{acide}} = n_{\text{base}}, \qquad C_{\text{acide}} = \frac{n_{\text{acide}}}{V_{\text{acide}}}
$$
À l'**équivalence** : acide et base entièrement neutralisés, BBT **vert**.
:::

## Méthode express

1. **Identifier le milieu** : virer les gouttes de BBT dans un prélèvement → jaune = acide, vert = neutre, bleu = basique.
2. **Situer le pH** : $< 7$ acide, $= 7$ neutre, $> 7$ basique.
3. **Écrire la neutralisation** : acide + base → sel + eau, puis équilibrer avec des **coefficients**.
4. **Calculer un dosage** : convertir les volumes en L → $n_{\text{base}} = C \times V$ → $n_{\text{acide}} = n_{\text{base}}$ → $C_{\text{acide}} = n / V$.
5. **Nommer l'équivalence** : le virage vert, quand les quantités de matière réagissent exactement selon l'équation.

:::erreur Les erreurs qui coûtent des points
1. Inverser les couleurs du BBT (jaune = acide, bleu = base).
2. Oublier la conversion des volumes en litres dans un dosage.
3. Dire que le pH « augmente l'acidité » : un pH de $2$ est **plus acide** qu'un pH de $6$.
4. Modifier les indices des formules au lieu des coefficients pour équilibrer.
5. Confondre le point d'équivalence (milieu neutre) avec le virage de l'indicateur dans un autre sens.
:::

## Vocabulaire

- **Acide** : libère des ions $H^+$ dans l'eau.
- **Base** : capte les ions $H^+$, libère des ions $OH^-$.
- **Indicateur coloré** : substance qui change de couleur selon l'acidité (le **BBT**, bleu de bromothymol).
- **pH** : nombre de $0$ à $14$ qui mesure l'acidité d'une solution.
- **Neutralisation** : réaction acide + base → sel + eau.
- **Dosage** : détermination d'une concentration inconnue par réaction avec une solution titrée.
- **Équivalence** : instant où acide et base sont exactement consommés (milieu neutre).
- **Burette** : récipient gradué qui permet de verser un volume précis, goutte à goutte.
