:::remarque À quoi ça sert au BFEM ?
Savoir reconnaître une solution acide ou basique avec un indicateur, écrire la réaction d'une neutralisation et comprendre un dosage : c'est le trio classique des questions de chimie au BFEM. Ces notions servent aussi à la vie quotidienne (lessive, vinaigre, eau potable) et sont donc souvent illustrées par des documents concrets.
:::

## Reconnaître les solutions : les indicateurs colorés

Une **solution aqueuse** peut être **acide**, **basique** ou **neutre**. Pour les distinguer, on utilise un **indicateur coloré**, une substance qui change de couleur selon le milieu.

Le plus utilisé au programme est le **bleu de bromothymol (BBT)**.

:::formule Les couleurs du BBT
| Milieu | Solution | Couleur du BBT |
| --- | --- | --- |
| Acide | pH < 7 | **Jaune** |
| Neutre | pH = 7 | **Vert** |
| Basique | pH > 7 | **Bleu** |
:::

:::methode Tester une solution avec le BBT
1. Prélever un petit volume de la solution à étudier dans un tube.
2. Ajouter deux ou trois gouttes de BBT.
3. Observer la couleur obtenue et comparer avec le tableau.
4. Conclure : acide (jaune), neutre (vert) ou basique (bleu).
:::

:::exemple Quelques solutions du quotidien
- Vinaigre, jus de citron, jus de gastrique → BBT **jaune** → solution **acide**.
- Eau distillée, eau du robinet bien traitée → BBT **vert** → solution **neutre**.
- Lessive (soude), eau de Javel, savon → BBT **bleu** → solution **basique**.
:::

:::erreur Attention
Le BBT ne se verse jamais directement dans le flacon de la solution : on prélève d'abord un petit échantillon, sinon on altère toute la solution.
:::

## Définitions : acides et bases

:::definition Acide (définition d'Arrhenius)
Un **acide** est une espèce chimique qui, dissous dans l'eau, libère des **ions hydrogène $H^+$** (des protons). La solution obtenue est dite acide.
:::

:::definition Base (définition de Brønsted)
Une **base** est une espèce chimique qui, dissous dans l'eau, capte les ions $H^+$ ; elle libère des **ions hydroxyde $OH^-$**. La solution obtenue est dite basique.
:::

:::remarque Un couple acide-base (Brønsted)
Un acide, en cédant un ion $H^+$, devient une base conjuguée ; une base, en captant un ion $H^+$, devient un acide conjugué. Exemple : $HCl$ (acide fort) donne $Cl^-$ (base conjuguée faible) :
$$
HCl \rightleftharpoons H^+ + Cl^-
$$
:::

:::formule Le tableau d'Arrhenius
| | Acide | Base | Sel + eau |
| --- | --- | --- | --- |
| Exemple | $HCl$ | $NaOH$ | $NaCl + H_2O$ |
| Ions produits dans l'eau | $H^+$ | $OH^-$ | — |
| Goût (à ne jamais goûter !) | Acre, âcre | Glissant, savonneux | — |
:::

:::erreur À ne jamais faire
On **ne goûte jamais** une solution en laboratoire. Le goût décrit dans les manuels sert uniquement de repère : l'acide du vinaigre est dilué, celui de l'acide chlorhydrique du laboratoire brûle les muqueuses.
:::

## Le pH : mesurer l'acidité

Le **pH** est un nombre qui mesure l'acidité d'une solution aqueuse. Il va de $0$ à $14$.

:::formule Échelle du pH
$$
pH = -\log\left[\,H^+\,\right]
$$

| Solution | pH | Couleur du BBT |
| --- | --- | --- |
| Très acide (acide du gastrique) | $0$ à $3$ | Jaune |
| Légèrement acide (vinaigre) | $3$ à $6{,}5$ | Jaune |
| Neutre (eau pure) | $7$ | Vert |
| Légèrement basique (savon) | $7{,}5$ à $10$ | Bleu |
| Très basique (lessive) | $10$ à $14$ | Bleu |
:::

:::methode Situer un pH
1. Si $pH < 7$ : solution **acide** (plus le chiffre est petit, plus l'acide est fort).
2. Si $pH = 7$ : solution **neutre**.
3. Si $pH > 7$ : solution **basique** (plus le chiffre est grand, plus la base est forte).
:::

:::remarque Attention au sens du pH
Le pH ne se lit pas comme une concentration : un pH de $2$ est **plus acide** qu'un pH de $5$. Et un pH de $3$ et un pH de $11$ sont à la même distance de la neutralité : leurs solutions sont aussi « intenses » l'une que l'autre, mais de natures opposées.
:::

## La réaction acide chlorhydrique + soude : une neutralisation

L'**acide chlorhydrique** $HCl$ et la **soude** $NaOH$ réagissent pour former du sel et de l'eau :

:::formule Neutralisation HCl / NaOH
$$
HCl + NaOH \longrightarrow NaCl + H_2O
$$
:::

:::definition Neutralisation
Une **neutralisation** est une réaction au cours de laquelle un acide et une base réagissent pour donner un **sel** et de l'eau. Le milieu devient neutre : le BBT passe au **vert**.
:::

:::exemple Écrire une neutralisation
- Acide sulfurique + soude : $H_2SO_4 + 2\,NaOH \longrightarrow Na_2SO_4 + 2\,H_2O$
- Acide chlorhydrique + soude : $HCl + NaOH \longrightarrow NaCl + H_2O$

Dans les deux cas : acide + base → sel + eau.
:::

:::methode Équilibrer une neutralisation
1. Écrire acide + base → sel + eau.
2. Compter les ions $H^+$ et $OH^-$ : ils doivent s'équiper pour former autant d'eaux.
3. Ajuster les **coefficients**, jamais les indices des formules.
4. Vérifier chaque élément des deux côtés.
:::

## Dosage par neutralisation

:::definition Dosage
Un **dosage** est une opération qui permet de déterminer la concentration d'une solution inconnue en la faisant réagir avec une solution de concentration connue.
:::

Le dosage par neutralisation consiste à verser, dans un erlenmeyer, un volume précis de la solution acide, puis à verser goutte à goutte la solution de base de concentration connue à l'aide d'une **burette**. On ajoute quelques gouttes d'indicateur (BBT).

:::formule Réaction suivie pendant le dosage
$$
HCl + NaOH \longrightarrow NaCl + H_2O
$$

À l'équivalence, les quantités de matière sont dans le rapport stœchiométrique de l'équation : $n(HCl) = n(NaOH)$.
:::

:::definition Équivalence
L'**équivalence** est le moment exact où l'acide et la base sont entièrement neutralisés : la solution est neutre, le BBT est **vert** et le virage vient de s'opérer.
:::

:::methode Dosage : les étapes
1. Préciser un volume $V_{\text{acide}}$ exact de la solution inconnue (fiole jaugée ou pipette).
2. Ajouter deux ou trois gouttes de BBT.
3. Verser la base de concentration connue goutte à goutte en agitant.
4. S'arrêter au **virage vert** : c'est l'équivalence, on lit le volume $V_{\text{base}}$ utilisé.
5. Calculer $n_{\text{base}} = C_{\text{base}} \times V_{\text{base}}$, puis $n_{\text{acide}} = n_{\text{base}}$, enfin $C_{\text{acide}} = \dfrac{n_{\text{acide}}}{V_{\text{acide}}}$.
:::

:::exemple Dosage numérique
On titre $100$ mL d'une solution de $HCl$ inconnue avec de la soude à $0{,}1$ mol/L. Il a fallu $20$ mL de soude pour atteindre l'équivalence.

1. $n(NaOH) = 0{,}1 \times 0{,}02 = 0{,}002$ mol
2. D'après l'équation, $n(HCl) = n(NaOH) = 0{,}002$ mol
3. $C(HCl) = \dfrac{0{,}002}{0{,}1} = 0{,}02$ mol/L

La concentration de l'acide est **$0{,}02$ mol/L**.
:::

:::erreur Les erreurs qui coûtent des points
1. Oublier de convertir les volumes en litres avant tout calcul ($20$ mL = $0{,}02$ L).
2. Dire que le BBT est « bleu à l'équivalence » : à l'équivalence, il est **vert**.
3. Écrire $HCl + NaOH \to NaCl + H_2O$ sans vérifier l'équilibre, ou modifier les indices des formules.
4. Confondre acide (jaune au BBT, pH < 7) et base (bleu, pH > 7).
:::

## Pourquoi ces notions comptent

- **L'acide gastrique** ($HCl$ très dilué) est nécessaire à la digestion ; certains médicaments (antiacides) sont des bases qui le neutralisent.
- **L'eau potable** doit être légèrement neutre : on la contrôle avec des indicateurs et on y ajoute parfois un peu de chlore, légèrement basique, pour la désinfecter.
- **Les lessives et l'eau de Javel** sont basiques : elles attaquent les graisses, mais brûlent la peau, d'où les gants.

:::remarque Au Sénégal
Dans les ménages, on utilise souvent le vinaigre (acide acétique) pour nettoyer et la cendre de bois (bases) pour fabriquer du savon traditionnel : deux solutions de part et d'autre de la neutralité, réunies par la même réaction acide + base → sel + eau.
:::

## Ce qu'il faut retenir

- **Acide** : libère $H^+$ (pH < 7, BBT **jaune**). **Base** : libère $OH^-$ (pH > 7, BBT **bleu**). **Neutre** : pH = 7, BBT **vert**.
- Le **pH** mesure l'acidité : $pH = -\log[H^+]$.
- **Neutralisation** : acide + base → **sel + eau**. Exemple : $HCl + NaOH \longrightarrow NaCl + H_2O$.
- Un **dosage** détermine une concentration inconnue ; à l'**équivalence**, l'acide et la base sont exactement consommés et le milieu est neutre.
- Calcul de dosage : $n_{\text{base}} = C_{\text{base}} \times V_{\text{base}}$, puis $n_{\text{acide}} = n_{\text{base}}$, puis $C_{\text{acide}} = n_{\text{acide}} / V_{\text{acide}}$.
