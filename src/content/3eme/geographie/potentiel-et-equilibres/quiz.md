## Question

Parmi ces ressources, laquelle est NON renouvelable ?

- [ ] L'eau du lac de Guiers
- [x] Les phosphates de Taiba
- [ ] Le vent de la côte sahélienne
- [ ] Les poissons des bancs de la Mauritanie

> Les phosphates se sont formés il y a des millions d'années et ne se reconstituent pas à l'échelle humaine : c'est une ressource non renouvelable. L'eau, le vent et les poissons sont renouvelables… à condition de ne pas les surexploiter.

## Question

Quelle est la bonne définition d'une ressource renouvelable ?

- [ ] Une ressource que l'on peut utiliser sans limite
- [x] Une ressource qui se reconstitue naturellement en quelques années ou décennies
- [ ] Une ressource fabriquée par l'homme
- [ ] Une ressource qui ne se trouve que dans le sous-sol

> Une ressource renouvelable se régénère rapidement **si les prélèvements ne dépassent pas les capacités de régénération**. Elle peut disparaître si on la surexploite : renouvelable ne veut pas dire inépuisable.

## Question

Dans la chaîne alimentaire « mil → chèvre → hyène », quel est le producteur ?

- [ ] La hyène, qui est en haut de la chaîne
- [ ] La chèvre, qui mange le mil
- [x] Le mil, qui fabrique sa matière organique grâce à la photosynthèse
- [ ] Le décomposeur, qui termine la chaîne

> Les **producteurs** sont les plantes : elles fabriquent leur matière organique à partir de la lumière. La chèvre est consommateur primaire, la hyène consommateur secondaire.

## Question

Quelles sont, dans l'ordre, les étapes du cycle de l'eau ?

- [x] Évaporation → condensation → précipitations → ruissellement et infiltration
- [ ] Précipitations → évaporation → ruissellement → condensation
- [ ] Condensation → ruissellement → évaporation → précipitations
- [ ] Infiltration → précipitations → condensation → évaporation

> Le Soleil provoque l'**évaporation**, la vapeur se condense en nuages, l'eau retombe en **précipitations**, puis ruisselle ou s'infiltre avant de revenir vers la mer : le cycle recommence.
