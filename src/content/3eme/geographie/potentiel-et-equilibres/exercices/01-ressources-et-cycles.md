## Énoncé

**Exercice 1. Renouvelable ou non renouvelable ?**

Classe les ressources suivantes dans le tableau : pétrole, eau du lac de Guiers, phosphates de Taiba, forêts de Casamance, vent, or.

| Ressource | Renouvelable | Non renouvelable |
| --- | --- | --- |
| ... | ... | ... |

**Exercice 2. Les cycles.**

1. Décris le cycle de l'eau en quatre étapes.
2. Explique ce qui se passe dans le cycle du carbone quand les hommes brûlent beaucoup de charbon.

**Exercice 3. Les chaînes alimentaires.**

3. Complète la chaîne : mil → ... → ... → décomposeurs, en précisant le rôle de chaque maillon.
4. Que se passe-t-il si les décomposeurs disparaissent d'un écosystème ?

## Solution

**1.**

| Ressource | Renouvelable | Non renouvelable |
| --- | --- | --- |
| Eau du lac de Guiers | ✓ (cycle de l'eau) | |
| Forêts de Casamance | ✓ (reboisement) | |
| Vent | ✓ (inépuisable) | |
| Pétrole | | ✓ (millions d'années) |
| Phosphates de Taiba | | ✓ (gisements épuisables) |
| Or | | ✓ (gisement limité) |

Justification : le pétrole, les phosphates et l'or se sont formés sur des millions d'années et ne se reconstituent pas à l'échelle humaine ; l'eau, les forêts et le vent se reconstituent en quelques années ou sont perpétuellement disponibles.

**2.** 1) Le Soleil chauffe les mers, les rivières et les sols : c'est l'**évaporation**, l'eau monte en vapeur dans l'atmosphère. 2) En altitude, la vapeur se refroidit : c'est la **condensation**, elle forme les nuages. 3) L'eau retombe sous forme de **précipitations** (pluie, neige). 4) L'eau **ruisselle** vers les rivières et les lacs ou **s'infiltre** dans le sol pour alimenter les nappes phréatiques, puis repart vers les mers : le cycle recommence.

3) Quand les hommes brûlent beaucoup de charbon, ils libèrent dans l'atmosphère un excès de CO₂ que les plantes ne suffisent plus à absorber par la photosynthèse. Le bilan du cycle du carbone devient alors déséquilibré : le gaz à effet de serre s'accumule et participe au réchauffement climatique.

**3.** Chaîne complète : **mil (producteur)** → **chèvre (consommateur primaire, herbivore)** → **hyène ou lion (consommateur secondaire, carnivore)** → **décomposeurs** (bactéries, champignons, vers de terre).

**4.** Si les décomposeurs disparaissent, la matière morte (feuilles, cadavres, déjections) ne se décompose plus : les éléments minéraux ne retournent pas au sol, la fertilité chute et les plantes ne peuvent plus pousser. La chaîne alimentaire entière s'effondre à terme : c'est la rupture de l'équilibre écologique.

:::remarque À retenir
Une chaîne sans décomposeurs est une chaîne **bloquée** : l'arrêt du recyclage de la matière est aussi grave que l'arrêt de la photosynthèse.
:::
