## La grille de collecte des documents

:::formule Le tableau à remplir avant d’écrire
| Document | Nature | Source (auteur, date) | Idée 1 | Idée 2 | Points communs / divergences |
| --- | --- | --- | --- | --- | --- |
| Doc 1 | | | | | |
| Doc 2 | | | | | |
| Doc 3 | | | | | |
:::

:::remarque La règle des deux idées
Chaque document doit apporter **au moins deux idées principales**. Une seule idée signifie que tu n’as pas lu le document jusqu’au bout : la source, la nuance et la conclusion s’y trouvent souvent.
:::

## Le plan type de la synthèse

:::formule Structure complète
**Introduction (10 à 15 %)** : thème · présentation des documents (nature + source) · annonce de la démarche (« nous montrerons d’abord… puis… »).

**Partie I — Les convergences (35 %)** : ce que tous les documents établissent.

**Partie II — Les divergences (35 %)** : ce où ils s’opposent ou se complètent.

**Partie III — Complémentarité et bilan (15 %)** : ce que l’ensemble permet de comprendre, sans opinion.

**Aucune conclusion d’opinion.**
:::

:::remarque Pourquoi pas de conclusion personnelle ?
La synthèse **rend compte** : elle ne tranche pas. On peut seulement conclure sur ce que **l’ensemble des documents** montre — jamais sur ce que **toi** tu en penses.
:::

## Les tournures de neutralité

:::formule À éviter / à écrire
| Partisan | Neutre |
| --- | --- |
| *« Je pense que… »* | *« Le document soutient que… »* |
| *« Heureusement… »* | *« Selon l’auteur… »* |
| *« C’est faux que… »* | *« Le document 2 nuance cette analyse en montrant que… »* |
| *« Il faut… »* | *« L’auteur plaide pour… »* |
| *« Le graphique prouve que… »* | *« Le graphique indique une hausse de… entre… et… »* |
:::

:::formule Les tournures d’attribution
*selon · d’après · pour l’auteur · le document souligne · l’article avance · le graphique montre · la caricature dénonce · si le document 1 affirme…, le document 3 nuance…*
:::

## Les connecteurs de la synthèse

:::formule Tableau de référence
| Fonction | Connecteurs |
| --- | --- |
| Convergences | *également, de la même façon, en outre, tous les documents convergent pour dire* |
| Divergences | *en revanche, cependant, au contraire, tandis que, là où* |
| Opposition de sources | *si le document A…, le document B…* |
| Ajout | *par ailleurs, en complément, le document C apporte* |
| Chiffres | *de 62 % à 78 %, soit une progression de 16 points* |
| Bilan | *ainsi, au terme de cet examen, l’ensemble des documents* |
:::

:::remarque Le connecteur empêche la liste
Une phrase qui commence par *« Le document 2… »* après *« Le document 1… »* est un résumé successif. Un connecteur logique (*en revanche, par ailleurs*) prouve que tu as **mis les documents en relation** : c’est la différence entre un résumé et une synthèse.
:::

## Lecture des documents non textuels

:::formule Graphique, tableau, caricature
| Document | Plan de lecture en 4 temps |
| --- | --- |
| **Graphique** | 1. titre et unité · 2. période · 3. tendance (hausse / baisse / stagnation) · 4. 2 ou 3 chiffres clés |
| **Tableau** | 1. colonnes et lignes · 2. comparaison · 3. valeur maximale · 4. valeur minimale |
| **Caricature** | 1. légende et auteur · 2. procédé comique (exagération, déformation) · 3. cible · 4. message critique |
:::

:::formule Modèle d’analyse d’un graphique dans une synthèse
*« Le graphique montre que l’inscolarisation progresse de 62 % en 2010 à 78 % en 2020, soit 16 points en dix ans, avec un décalage persistant entre zones urbaines et rurales. Cette évolution corrobore l’analyse du document 1. »*
:::

## Contrôle avant de rendre

:::formule La checklist des 7 points
1. **Documents** : chacun est-il traité au moins une fois ?
2. **Thème** : le plan est-il thématique et non document par document ?
3. **Neutralité** : aucune première personne, aucun jugement ?
4. **Attribution** : chaque idée est-elle rattachée à sa source ?
5. **Connecteurs** : assez de *également, en revanche, ainsi* ?
6. **Proportion** : nombre de mots respecté ?
7. **Langue** : orthographe des noms propres, accords, ponctuation ?
:::

:::remarque Ce que le correcteur surligne
Les mots de méthode — **convergences, divergences, nuance, corroborer, tandis que** — et les **connecteurs**. Une synthèse sans connecteur ressemble à quatre résumés collés : le correcteur le sanctionne immédiatement.
:::
