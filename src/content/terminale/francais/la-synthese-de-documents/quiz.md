## Question

Quelle est la structure correcte d’une synthèse de documents ?

- [ ] Document 1 → document 2 → document 3, chacun résumé en entier
- [x] Introduction, convergences, divergences, complémentarité et bilan neutre
- [ ] Introduction, avis personnel, développement, conclusion personnelle
- [ ] Une partie par figure de style trouvée dans les documents

> Le plan doit être **thématique**, pas document par document : on regroupe ce que les documents ont en commun, puis ce où ils divergent. Résumer les documents l’un après l’autre est un résumé successif, pas une synthèse.

## Question

Comment présenter l’idée du document 2 dans une synthèse ?

- [x] *« Le graphique indique une hausse de 62 % à 78 % entre 2010 et 2020. »*
- [ ] *« Heureusement, l’inscolarisation progresse vraiment. »*
- [ ] *« Je trouve que ces chiffres sont encourageants. »*
- [ ] *« Le document 2. Inscolarisation. »*

> La neutralité impose d’attribuer l’idée à sa source avec une tournure neutre (*indique, montre, selon, d’après*), de citer les chiffres clés sans les commenter, et de rejeter toute première personne.

## Question

Un document sur le thème est absent de ta copie. Que se passe-t-il ?

- [ ] Rien, si les autres documents sont bien traités
- [x] Le correcteur coche chaque document traité : un document oublié coûte des points, surtout s’il s’agit du graphique ou de la caricature
- [ ] Il suffit de citer le document dans l’introduction
- [ ] Le document n’a de valeur que s’il est un texte

> L’exhaustivité est une des quatre règles d’or. Chaque document doit apparaître au moins une fois, avec ses idées principales — et les documents non textuels (graphique, tableau, caricature) comptent autant que les textes.

## Question

Quel connecteur introduit correctement une divergence entre deux documents ?

- [ ] *« De plus… »*
- [x] *« En revanche… »*
- [ ] *« Ainsi… »*
- [ ] *« Par exemple… »*

> *En revanche, cependant, au contraire, tandis que* marquent l’opposition : ils prouvent que tu as mis les documents en relation. *De plus* ajoute, *ainsi* conclut, *par exemple* introduit une illustration — inutile puisque les exemples sont déjà dans les documents.
