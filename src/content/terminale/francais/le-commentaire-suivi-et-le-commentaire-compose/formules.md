## L’introduction du commentaire

:::formule Les cinq étapes obligatoires
1. **Amorce** : remarque sur le thème, question ou citation.
2. **Situation** : auteur · œuvre · époque · genre · extrait.
3. **Situation de communication** : qui parle, à qui, dans quelles circonstances.
4. **Problématique** : la difficulté centrale du texte.
5. **Annonce de plan** : *« Nous verrons d’abord que… puis que… avant de montrer que… »*
:::

:::remarque Le modèle en une phrase
*« Dans* Une si longue lettre*, publié en 1979, Mariama Bâ fait de Ramatoulaye une femme qui écrit pour comprendre et pour dire. Mais comment une confidence intime peut-elle devenir le plaidoyer de toutes les femmes ? Après avoir montré que le texte est une confession, nous verrons qu’il devient un manifeste, avant de montrer que la lettre elle-même est l’acte qu’elle décrit. »*
:::

## Les plans autorisés

:::formule Plan du commentaire composé (3 axes)
- **Axe I — Ce que le texte dit** : thème, énonciation, mouvements (2 ou 3 parties).
- **Axe II — Comment il le dit** : ressources linguistiques + figures de style, avec effets.
- **Axe III — Pourquoi il le dit ainsi** : registre, visée, lien avec l’œuvre, l’auteur, l’époque.
:::

:::formule Plan du commentaire suivi (linéaire)
- **Séquence 1** : annonce de l’état → analyse phrase par phrase → effet + transition.
- **Séquence 2** : ce qui change → analyse → effet + transition.
- **Séquence 3** : le dépassement ou la conclusion du texte → analyse → effet.
:::

:::remarque Trois réflexes de correction
1. Chaque paragraphe contient au moins **une citation exacte**, suivie de son analyse.
2. La **forme** est étudiée avec le sens, jamais dans un paragraphe isolé.
3. L’introduction **situe** et **annonce**, la conclusion **répond**.
:::

## Grille des ressources à exploiter

:::formule Bloc linguistique
| Ressource | Ce qu’on cherche | Question d’effet |
| --- | --- | --- |
| Lexique | champ lexical, connotations, registre de langue | quelle couleur, quelle distance ? |
| Syntaxe | phrases longues/courtes, subordination, ordre | quel rythme ? |
| Ponctuation | virgule, tiret, deux-points, suspension | quelle respiration ? |
| Temps | présent, imparfait, futur, conditionnel | quel rapport au temps ? |
| Énonciation | personnes, pronoms, verbes de parole | qui parle, à qui ? |
:::

:::formule Bloc stylistique
| Figure | Repère | Effet type |
| --- | --- | --- |
| Comparaison | *comme, ainsi que, tel* | rendre sensible |
| Métaphore | aucun mot de comparaison | intensité, densité |
| Personnification | verbe humain pour une chose | animation, pathétique |
| Antithèse | deux idées opposées | tension, débat |
| Oxymore | termes contraires réunis | étonnement, densité |
| Anaphore | répétition en début de phrase/vers | martèlement, lyrisme |
| Gradation | ordre croissant ou décroissant | montée en intensité |
| Accumulation | liste de mots/propositions | ampleur, plénitude |
| Hyperbole | exagération | emphase |
| Litote | affirmation négative du contraire | pudeur, ironie |
:::

## Les registres

:::formule Repérer et justifier un registre
| Registre | Indices | Effet |
| --- | --- | --- |
| Lyrique | *je*, images, émotion, adresse | émouvoir |
| Satirique / polémique | ironie, dérision, dénonciation | indigner par le rire |
| Tragique | fatalité, malheur, opposition | émouvoir par la peur ou la pitié |
| Comique | chute, quiproquo, décalage | faire rire |
| Épique | héros, exploits, intensité | émerveiller |
| Descriptif | tableau, détails, simultanéité | faire voir |
| Narratif | récit, temps de l’histoire | raconter |
:::

:::remarque Deux registres peuvent coexister
*Le Misanthrope* est à la fois **comique** et **satirique** ; une lettre de Ramatoulaye est **lyrique** et **narratif**. Dis toujours lequel **domine** et lequel **accompagne**.
:::

## Les questions types du BAC

:::formule Ce qu’on peut te demander
| Formulation | Ce qu’il faut faire |
| --- | --- |
| *« Vous analyserez la situation de communication »* | locuteur, destinataire, circonstances, visée + effet |
| *« Vous analyserez les ressources linguistiques »* | lexique, syntaxe, ponctuation, temps |
| *« Vous analyserez les effets produits par les figures »* | nommer → citer → expliquer |
| *« Vous montrerez comment le texte… »* | commentaire composé en 3 axes |
| *« Vous ferez un commentaire linéaire »* | séquences, dans l’ordre, avec transitions |
:::

:::formule Le plan en trois axes, à écrire en tête de copie
**I. Un texte qui dit…** (thème, énonciation, mouvements)
**II. Un texte qui se dit ainsi…** (lexique, syntaxe, ponctuation, figures + effets)
**III. Un texte qui le dit pour…** (registre, visée, œuvre, époque)
:::

## La conclusion

:::formule Les trois temps
1. **Bilan** : *« Nous avons montré que… puis que… enfin que… »*
2. **Réponse** à la problématique, sans hésitation.
3. **Ouverture** : lien avec une autre œuvre du programme, question nouvelle — jamais d’analyse supplémentaire.
:::

:::remarque Ce que le correcteur surligne
Les mots techniques justes (**énonciation, apostrophe, champ lexical, métaphore, anaphore, antithèse, registre, thèse, visée**), les **citations exactes**, les **transitions** et l’**annonce de plan**.
:::
