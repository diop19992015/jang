## La structure à mémoriser

:::formule Le schéma du passif
$$
\text{Sujet (patient)} + \text{be} + \text{participe passé (V3)} + (\text{by + agent})
$$

| Voix | Sujet | Verbe | Complément |
| --- | --- | --- | --- |
| Active | agent | verbe conjugué | COD |
| Passive | ancien COD | be + V3 | *by + agent* (facultatif) |
:::

:::remarque Le test pour trouver le sujet du passif
Pose la question « Quoi ? / Qui ? » après le verbe de la phrase active : la réponse devient le sujet de la phrase passive. *The pupils wrote **the report*** → *the report* → ***The report** was written.*
:::

## Le passif dans tous les temps

:::formule Tableau complet (verbes *write* et *explain*)
| Temps | Actif | Passif |
| --- | --- | --- |
| Present simple | *He writes a note.* | *A note **is written**.* |
| Present continuous | *He is writing a note.* | *A note **is being written**.* |
| Present perfect | *He has written a note.* | *A note **has been written**.* |
| Past simple | *He wrote a note.* | *A note **was written**.* |
| Past continuous | *He was writing a note.* | *A note **was being written**.* |
| Past perfect | *He had written a note.* | *A note **had been written**.* |
| Future simple | *He will write a note.* | *A note **will be written**.* |
| Modal | *He must write a note.* | *A note **must be written**.* |
| Infinitif | *He wants to write a note.* | *He wants **to be written** (a note).* |
:::

## Correspondances actif → passif

| Phrase active | Phrase passive |
| --- | --- |
| *They build schools in every region.* | *Schools are built in every region.* |
| *The jury chose Fatou.* | *Fatou was chosen by the jury.* |
| *Someone has stolen my bag.* | *My bag has been stolen.* |
| *They will publish the results next week.* | *The results will be published next week.* |
| *People talk about the BAC everywhere.* | *The BAC is talked about everywhere.* |
| *The teacher gave the pupils a book.* | *The pupils were given a book.* |

## Les emplois (quand utiliser le passif)

| Emploi | Exemple |
| --- | --- |
| Agent inconnu | *My phone **has been stolen**.* |
| Agent évident / général | *English **is spoken** in many countries.* |
| Langue officielle, presse | *The results **will be announced**.* |
| Politesse, prudence | *You **are invited** to the ceremony.* |

## Les cas particuliers

:::formule Verbes à particule : la préposition reste
*laugh at → was laughed at · talk about → is talked about · look after → is looked after · listen to → was listened to*
:::

:::formule Verbes sans passif
*be, have, belong to, happen, occur, take place, arrive, come, go, die, seem, appear, last, cost*
→ ~~The accident was happened~~ → ***The accident happened.***
:::

:::formule Passif impersonnel
- *It is said / believed / known / expected that…*
- *… is said / believed / known / expected to + infinitif* (avec le passé : *to have been + V3*)
:::

:::remarque Actif ou passif au BAC ?
Le passif s’impose dans la langue officielle et les transformations ; l’actif reste préférable quand l’agent est important et que la phrase doit être vivante. Dans une rédaction, alterner les deux voix donne du style.
:::
