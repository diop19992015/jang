## L’essentiel du chapitre

:::formule La structure du passif
$$
\text{Sujet} + \text{be (au temps du verbe)} + \text{participe passé (V3)} + (\text{by + agent})
$$

Le **COD actif devient sujet** ; *by + agent* seulement si l’agent est utile.
:::

:::formule Le passif dans les temps clés
| Actif | Passif |
| --- | --- |
| *The teacher **explains** the rule.* | *The rule **is explained**.* |
| *The teacher **is explaining** the rule.* | *The rule **is being explained**.* |
| *The teacher **has explained** the rule.* | *The rule **has been explained**.* |
| *The teacher **explained** the rule.* | *The rule **was explained**.* |
| *The teacher **will explain** the rule.* | *The rule **will be explained**.* |
| *The teacher **can explain** the rule.* | *The rule **can be explained**.* |
:::

:::formule Les deux passifs avec deux compléments
*The teacher **gave the pupils** a booklet.*

- *A booklet **was given to** the pupils.*
- *The pupils **were given** a booklet.* (le plus courant)
:::

:::formule Passif impersonnel
- *It is said that…* → ***… is said to…*** : *It is said that he left. / He **is said to have left**.*
- Même schéma : *believed, known, expected, told*.
:::

## Méthode express

1. Repérer le **COD** de la phrase active.
2. En faire le **sujet** de la phrase passive.
3. Choisir le temps de **be** = temps du verbe actif.
4. Mettre le verbe en **V3** (participe passé).
5. Ajouter *by + agent* seulement si nécessaire.
6. Questions/négations : l’inversion se fait avec **be** conjugué.

:::erreur Les erreurs qui coûtent des points
1. ~~The letter written~~ → *The letter **was** written* (jamais sans *be*).
2. ~~is explained~~ pour « est en train d’être expliquée » → ***is being explained***.
3. ~~was talked~~ → *was **talked about*** (la préposition reste).
4. ~~The accident was happened~~ → ***The accident happened*** (verbe sans passif).
5. ~~was wrote~~ → ***was written*** (V3 irrégulier).
6. ~~is been written~~ → ***has been written*** (jamais *is been*).
:::

## Vocabulaire

- **Voix active** : le sujet fait l’action (*The pupils clean the room*).
- **Voix passive** : le sujet subit l’action (*The room is cleaned*).
- **Agent** : celui qui fait l’action (*by the pupils*).
- **Patient** : celui qui subit (l’ancien COD, devenu sujet).
- **Participe passé (V3)** : *written, taken, chosen*.
- **Verbe à particule** : verbe + préposition (*talk about, laugh at, look after*).
- **Passif impersonnel** : *It is said that… / … is said to…*
