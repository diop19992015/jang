## L’essentiel du chapitre

:::formule Les trois articles
- **a / an** : première mention, chose non identifiée — choix selon le **son** : *a book, an hour, a university*.
- **the** : chose connue, unique, précise : *Close the door.*
- **Ø (zéro)** : généralités, noms propres, matières, repas, jeux : *I like football.*
:::

:::formule The ou Ø ? Les règles d’or
| **the** | **Ø (aucun article)** |
| --- | --- |
| chose connue / 2e mention | généralité : *Books are useful.* |
| unique : *the sun* | pays, villes, continents : *Senegal, Dakar* |
| superlatif, ordinal : *the best, the first* | langues : *speak English* |
| instruments : *play the piano* | repas, jeux, matières : *have lunch, play football* |
| fleuves, déserts, *of* : *the Nile, the University of Dakar* | pluriels indéterminés : *I bought books* |
:::

:::formule Le son, pas la lettre
*an hour, an honest man* (h muet) — *a house* (h prononcé) — *a university* (« you ») — *an umbrella* — *a European*.
:::

:::formule Premier et deuxième mention
*I saw **a** dog. **The** dog was black.* (un → le, car la chose devient connue.)
:::

## Méthode express

1. Nom **singulier comptable** à la première mention → **a/an**.
2. Chose **connue, unique ou précisée** → **the**.
3. **Généralité** (pluriel ou indénombrable) → **Ø**.
4. **Nom propre** de pays/ville/langue → **Ø** (sauf fleuves, déserts, *of*, pluriels).
5. Vérifier le **son** devant *a/an* et l’absence de double déterminant.

:::erreur Les erreurs qui coûtent des points
1. ~~a English~~ → ***an** English* ; ~~an university~~ → ***a** university*.
2. ~~the France~~ → ***France***.
3. ~~go to the school~~ (études) → ***go to school***.
4. ~~He is doctor~~ → *He is **a** doctor*.
5. ~~best pupil~~ → ***the best** pupil*.
6. ~~the rice~~ pour une généralité → ***Rice***.
:::

## Vocabulaire

- **Article indéfini** : *a/an* (un, une).
- **Article défini** : *the* (le, la, les).
- **Article zéro (Ø)** : absence d’article.
- **Nom indénombrable** : non dénombrable (*water, rice, information*).
- **Première / deuxième mention** : apparition puis reprise d’une chose.
- **Superlatif** : *the best, the tallest*.
- **Son voyelle / consonne** : critère du choix *a/an*.
