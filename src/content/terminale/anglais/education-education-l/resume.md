:::formule Les conditionnels (grammaire du chapitre)
| Type | Structure | Exemple |
| --- | --- | --- |
| Première | *if + présent, will + base* | *If you **revise**, you **will pass** the BAC.* |
| Deuxième | *if + passé, would + base* | *If I **were** the minister, I **would build** more schools.* |
| Troisième | *if + had + V3, would have + V3* | *If they **had started** earlier, they **would have finished**.* |

:::formule Les modaux du devoir scolaire
- *Pupils **must** respect the rules.* (obligation)
- *Parents **should** help with homework.* (conseil)
- *Students **may** use the library after class.* (permission)
- *He **must have revised** — he answered everything.* (déduction passée)
:::

:::formule La règle d’or
$$
\text{Jamais de } will \text{ ni de } would \text{ après } if
$$

*If the government **invests** in schools, more children **will** attend.* (✗ *if… will invest*)
:::

## Méthode express

1. Activer le bon vocabulaire : tradition / système scolaire / valeurs.
2. Pour décrire un système : présent simple (règles générales) ou present perfect (évolutions récentes).
3. Pour proposer une solution : **conditionnelle** — avenir réel (1re), hypothèse (2e), passé manqué (3e).
4. Pour prescrire : *must* (obligation), *should* (conseil), *may* (permission).
5. Relier avec les connecteurs : *first, moreover, however, therefore, in conclusion*.
6. Vérifier : présent simple après *if*, base verbale après un modal, comparatif sans *more*.

:::erreur Les erreurs qui coûtent des points
1. ~~If the government will invest~~ → *If the government **invests***.
2. ~~If I would be the headmaster~~ → *If I **were** the headmaster*.
3. ~~must to revise~~ → ***must revise***.
4. ~~I learn him English~~ → *I **teach** him English*.
5. ~~more easier / more better~~ → ***easier / better***.
:::

## Vocabulaire

- **to educate / education** : éduquer / l’éducation ; **to teach** : enseigner (à quelqu’un).
- **to learn** : apprendre ; *I teach **him*** ≠ *I learn **from** him*.
- **an apprentice / a skill** : un apprenti / une compétence ; **a craft** : un métier artisanal.
- **to hand down / oral tradition** : transmettre / tradition orale ; **a proverb** : un proverbe.
- **the school system / the curriculum** : le système scolaire / le programme scolaire.
- **literacy** : l’alphabétisation ; **to drop out (of school)** : abandonner l’école.
- **a scholarship** : une bourse d’études ; **to revise / homework** : réviser / les devoirs.
- **civic education / a citizen** : l’éducation civique / un citoyen ; **duty** : un devoir.
- **discipline / tolerance / mutual respect** : discipline / tolérance / respect mutuel.
- **peace / a conflict** : la paix / un conflit ; **to live together** : vivre ensemble.
