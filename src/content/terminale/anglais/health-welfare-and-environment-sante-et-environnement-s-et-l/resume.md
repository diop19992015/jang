:::formule La voix passive (grammaire du chapitre)
$$
\text{Sujet + be (au bon temps) + participe passé (V3)}
$$

- *The price of rice **has been reduced**.* (Le prix du riz a été réduit.)
- *Groundnuts **are exported** to Europe.* (Les arachides sont exportées en Europe.)
- *New jobs **will be created** by the factory.* (De nouveaux emplois seront créés par l’usine.)
:::

:::formule Les modaux pour argumenter
| Modal | Idée | Exemple |
| --- | --- | --- |
| **must** | obligation forte | *We **must** protect the environment.* |
| **should / ought to** | conseil | *The government **should** create jobs.* |
| **may / might** | possibilité | *Poverty **may** decrease.* |
| **can** | capacité, permission | *Young people **can** change the country.* |
| **have to** | nécessité extérieure | *Farmers **have to** save water.* |
:::

:::formule Les conditionnels pour proposer
- 1re : *If the government **invests** in education, unemployment **will fall**.*
- 2e : *If I **were** the minister, I **would build** more schools.*
- 3e : *If they **had started** earlier, they **would have finished** the dam.*
:::

## Méthode express

1. Repérer le sous-thème du texte (prix / pauvreté / agriculture / technologie) pour activer le bon vocabulaire.
2. Souligner les verbes : dans ces textes, beaucoup sont au **passif** — ne pas traduire par une phrase à sujet humain inutilement.
3. Choisir le **modal** selon l’intention : obligation (*must*), conseil (*should*), possibilité (*may*).
4. Pour une solution hypothétique, employer la **conditionnelle** (1re pour l’avenir, 2e pour l’irréel).
5. Structurer la rédaction : introduction → causes → solutions → conclusion avec *moreover, however, therefore, in conclusion*.
6. Vérifier les pièges : *cheaper* (jamais *more cheaper*), *money* indénombrable, *for* (durée) vs *since* (début).

:::erreur Les erreurs qui coûtent des points
1. ~~more cheaper / more easier~~ → ***cheaper / easier***.
2. ~~moneys~~ → *money* (indénombrable) ; ~~poors~~ → ***the poor*** (nom collectif).
3. ~~People create jobs~~ là où l’agent est sans intérêt → ***Jobs are created***.
4. ~~I can’t afford buying~~ → *I can’t afford **to buy***.
5. ~~since ten years~~ → ***for** ten years* / ***since** 2015*.
:::

## Vocabulaire

- **the cost of living** : le coût de la vie.
- **inflation** : l’inflation (les prix augmentent en général).
- **to afford** : avoir les moyens de (*I can’t afford a car*).
- **poverty** : la pauvreté (nom) — *the poor* : les pauvres (adjectif nommé).
- **sustainable development** : le développement durable.
- **renewable / solar energy** : énergie renouvelable / solaire.
- **arable land** : les terres arables (cultivables).
- **raw materials** : les matières premières.
- **to export / to import** : exporter / importer.
- **a breakthrough** : une percée, une avancée décisive.
