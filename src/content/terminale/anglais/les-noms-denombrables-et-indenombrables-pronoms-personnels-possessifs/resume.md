## L’essentiel du chapitre

:::formule Dénombrable ou indénombrable ?
| | Dénombrable | Indénombrable |
| --- | --- | --- |
| Quantité | **many, few, a few, several** | **much, little, a little** |
| Question | **How many…?** | **How much…?** |
| Pluriel | oui (*books*) | jamais (*informations* ✗) |
| Article | *a/an* possible | jamais de *a/an* |
| Unités | — | *a piece of, a kilo of, a glass of* |
| Exemple | *How many **books**?* | *How **much** money?* |
:::

:::formule Les indénombrables à connaître
*advice, information, news, furniture, luggage, equipment, work, homework, money, rice, water, bread, sugar, weather, progress, research, knowledge, traffic, music*

→ ~~an advice~~ → ***a piece of advice*** ; ~~informations~~ → ***some information***.
:::

:::formule Les possessifs
| Type | Formes | Place | Exemple |
| --- | --- | --- | --- |
| Adjectif possessif | *my, your, his, her, its, our, their* | **devant le nom** | ***my** book* |
| Pronom possessif | *mine, yours, his, hers, ours, theirs* | remplace un nom | *The book is **mine*** |
| Génitif | *’s* / *of* | personne/temps → *’s* ; chose → *of* | *the **teacher’s** bag / the roof **of the house*** |
:::

:::formule Pronoms personnels
| | Sujet | COD | COI |
| --- | --- | --- | --- |
| 1e | *I* | *me* | *me* |
| 3e m. | *he* | *him* | *him* |
| 3e f. | *she* | *her* | *her* |
| 3e p. | *they* | *them* | *them* |
| 1e p. | *we* | *us* | *us* |

Sujet **devant** le verbe, COD/COI **après** le verbe ou une préposition : *She gave **him** the book. — It’s for **us**.*
:::

## Méthode express

1. Nom **comptable** ? → *many/few*, pluriel, *a/an* possible.
2. Nom **non comptable** ? → *much/little*, jamais de pluriel, mots-compteur.
3. Le pronom : **sujet** (devant le verbe) ou **COD/COI** (après le verbe ou une préposition).
4. Possessif devant un nom → adjectif (*my*); à la place d’un nom → pronom (*mine*).
5. Possession d’une personne ou du temps → *’s* ; d’une chose → *of*.

:::erreur Les erreurs qui coûtent des points
1. ~~I have many money~~ → ***much / a lot of** money*.
2. ~~advices, informations, furnitures~~ → singulier indénombrable.
3. ~~Give it to I~~ → *Give it to **me***.
4. ~~This book is my~~ → *is **mine***.
5. ~~the my bag~~ → ***my** bag*.
6. *whose* (possession) confondu avec *who’s* (who is).
:::

## Vocabulaire

- **Nom dénombrable** : se compte (*a book, two books*).
- **Nom indénombrable** : ne se compte pas (*water, advice*).
- **Mots-compteur** : *a piece of, a kilo of, a glass of*.
- **Possessif adjectif** : *my, your, his…* (devant le nom).
- **Possessif pronom** : *mine, yours, his…* (remplace le nom).
- **Génitif** : possession avec *’s* ou *of*.
- **Pronom COD/COI** : *me, him, her, us, them*.
