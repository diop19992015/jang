## Dénombrables et indénombrables

:::formule Tableau de référence
| | Dénombrable | Indénombrable |
| --- | --- | --- |
| Quantité affirmée | *a lot of / many / several* | *a lot of / much / a great deal of* |
| Quantité négative/interrogative | *many / few* | *much / little* |
| Question | *How **many**…?* | *How **much**…?* |
| Exemple | *How many **students**?* | *How much **rice**?* |
| Unité | — | *a **piece of** advice* |
| Pluriel | *books, cars* | ✗ ~~advices, informations~~ |
:::

:::formule Les mots-compteur
| Nom | Forme correcte |
| --- | --- |
| advice | *a piece of advice / some advice* |
| information | *a piece of information* |
| news | *a piece of news* |
| furniture | *a piece of furniture* |
| luggage | *a piece of luggage / a bag* |
| bread | *a loaf / a slice of bread* |
| water | *a glass / a bottle of water* |
| tea / coffee | *a cup of tea / a cup of coffee* |
| rice | *a kilo of rice* |
| sugar / salt | *a spoonful of sugar* |
:::

## Pronoms personnels

| Fonction | Formes |
| --- | --- |
| Sujet | *I, you, he, she, it, we, they* |
| COD | *me, you, him, her, it, us, them* |
| COI (après préposition) | *me, you, him, her, it, us, them* |
| Après un verbe d’état | *It’s **me*** (soutenu : *It is I*) |

:::formule Position
$$
\text{Sujet} + \text{verbe} + \text{COD/COI}
$$

*She gave **him** the book.* — *This letter is for **them**.* — ***He** is my friend.*
:::

## Les possessifs

| Type | Formes | Règle | Exemple |
| --- | --- | --- | --- |
| Adjectif | *my, your, his, her, its, our, their* | devant le nom | ***my** father* |
| Pronom | *mine, yours, his, hers, ours, theirs* | remplace un nom | *It’s **mine*** |
| Génitif *’s* | *’s* | personnes, animaux, temps | *the **students’** bags, **last year’s** results* |
| Génitif *of* | *of* | choses, organisations | *the roof **of the house*** |

:::remarque Dont, whose et who’s
- *La fille **dont** j’admire le style* → *the girl **whose** style I admire.*
- ***Who’s** coming?* = *Who is coming?* (contraction) — jamais pour la possession.
:::

## Les erreurs les plus fréquentes

:::erreur Les corrections à connaître
| Faux | Correct |
| --- | --- |
| *I have many money.* | *I have **much / a lot of** money.* |
| *He gave me an advice.* | *He gave me **a piece of advice** / **some advice**.* |
| *There are many furnitures.* | *There is **a lot of furniture**.* |
| *The book is my.* | *The book is **mine**.* |
| *Give it to I.* | *Give it to **me**.* |
| *Him is a doctor.* | ***He** is a doctor.* |
| *These are informations.* | *This is **some information**.* |
:::
