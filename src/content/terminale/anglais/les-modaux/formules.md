## Les modaux essentiels

:::formule Tableau de référence
| Modal | Idée principale | Exemple | Traduction |
| --- | --- | --- | --- |
| **must** | obligation, certitude | *You **must** revise.* | Tu dois réviser. |
| **have to** | obligation extérieure | *I **have to** go.* | Je dois y aller. |
| **mustn’t** | interdiction | *You **mustn’t** smoke here.* | Tu n’as pas le droit de fumer ici. |
| **don’t have to** | pas d’obligation | *You **don’t have to** pay.* | Vous n’avez pas à payer. |
| **can** | permission, capacité | *She **can** swim.* | Elle sait nager. |
| **could** | capacité passée, permission polie | *Could I ask a question?* | Puis-je poser une question ? |
| **may** | permission formelle, possibilité | *It **may** rain.* | Il se peut qu’il pleuve. |
| **might** | possibilité faible | *He **might** come.* | Il viendra peut-être. |
| **should / ought to** | conseil | *You **should** sleep early.* | Tu devrais dormir tôt. |
| **would** | politesse, conditionnel | ***Would** you help me?* | M’aideriez-vous ? |
| **had better** | conseil urgent | *You**’d better** hurry.* | Vaut mieux te presser. |
| **can’t** | impossibilité | *It **can’t** be true.* | Ce n’est pas possible. |
:::

## Les combinaisons à connaître

:::formule Passé et déduction
- Obligation passée : **had to** → *I **had to** wait.* (J’ai dû attendre.)
- Capacité passée ponctuelle : **was/were able to** → *We **were able to** finish.*
- Déduction certaine passée : **must have + V3** → *She **must have left**.* (Elle a dû partir.)
- Déduction négative passée : **can’t have + V3** → *He **can’t have forgotten**.* (Il n’a pas pu oublier.)
- Futur de la capacité : **will be able to** → *I **will be able to** help.*
:::

## La règle de formation

:::formule Règle unique
$$
\text{modal} + \text{base verbale}
$$

- Pas de *to* : *must **go*** (✗ *must to go*)
- Pas de *-s* : *he **can*** (✗ *he cans*)
- Pas de *do* : ***Can** he…?* (✗ *Does he can…?*)
- Négation : *modal + not* → *can’t, mustn’t, shouldn’t, couldn’t, wouldn’t*
:::

## Le degré de certitude

| Certitude | Exemple | Sens |
| --- | --- | --- |
| 100 % positif | *He **must be** there.* | c’est certain |
| ~75 % | *He **should be** there.* | c’est probable |
| ~50 % | *He **may / might** be there.* | c’est possible |
| ~0 % | *He **can’t** be there.* | ce n’est pas possible |

:::remarque Le test des trois phrases
Un sujet de BAC demande souvent de distinguer : *must* (certitude), *may/might* (possibilité), *can’t* (impossibilité). Relis la phrase et demande-toi : « Suis-je certain, ou non ? » Le contexte (indice visible ou non) donne la réponse.
:::
