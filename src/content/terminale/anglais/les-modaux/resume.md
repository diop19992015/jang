## L’essentiel du chapitre

:::formule La structure du modal
**Modal + base verbale** (sans *to*, sans *-s*, sans *do*) → *She **must revise**. / **Can** you help? / He **can’t be** late.*

Négation : *mustn’t, can’t, shouldn’t* — Question : *modal + sujet + base verbale ?*
:::

:::formule Obligation et interdiction
| Idée | Forme | Exemple |
| --- | --- | --- |
| Obligation intérieure | **must** | *You **must** respect the rules.* |
| Obligation extérieure | **have to** | *You **have to** wear the uniform.* |
| Interdiction | **mustn’t** | *You **mustn’t** cheat in the exam.* |
| Pas d’obligation | **don’t have to** | *You **don’t have to** come on Sunday.* |
| Passé | **had to** | *I **had to** take the bus.* |
:::

:::formule Permission et capacité
- Permission : ***Can / Could / May** I…?* → *Yes, you **can**.*
- Capacité présent : ***can*** — passé : ***could*** — futur/infinitif : ***be able to*** (✗ *will can*).
:::

:::formule Possibilité et probabilité
| Probabilité | Modal | Exemple |
| --- | --- | --- |
| Certain | **must** | *He **must be** at school.* |
| Probable | **should** | *The bus **should come** soon.* |
| Possible | **may / might / could** | *She **may be** in the library.* |
| Impossible | **can’t** | *It **can’t be** true.* |
| Déduction passée | **must / can’t + have + V3** | *He **must have missed** the bus.* |
:::

## Méthode express

1. Repérer l’**idée** : obligation, interdiction, permission, capacité, possibilité, conseil.
2. Choisir le modal dans les tableaux ci-dessus.
3. Le suivre de la **base verbale** : *must go, can swim, should revise*.
4. Former la négation (*modal + not*) et l’interrogation (*modal + sujet*).
5. Vérifier le temps : passé → *had to / could / must have* ; futur → *will be able to / will have to*.

:::erreur Les erreurs qui coûtent des points
1. ~~He musts~~ / ~~He doesn’t must~~ → *He **mustn’t*** (pas de *-s*, pas de *do*).
2. ~~You must to revise~~ → *You **must revise*** (jamais de *to* après un modal).
3. ~~I will can do it~~ → *I **will be able to** do it*.
4. Confondre *mustn’t* (interdiction) et *don’t have to* (pas d’obligation).
5. ~~Coulded~~ : forme inexistante → *could* (passé) ou *was able to* (fait précis).
:::

## Vocabulaire

- **Modal (auxiliaire modal)** : *must, can, could, may, might, should, would, will*.
- **Obligation** : devoir, exigé (*must, have to*).
- **Interdiction** : *mustn’t* (no entry, no smoking).
- **Permission** : autorisation (*may, could*).
- **Capacité** : savoir-faire (*can, could, be able to*).
- **Probabilité** : degré de certitude (*must, should, may, can’t*).
- **Déduction** : conclure à partir d’un indice (*must have + V3*).
- **Conseil** : *should, ought to, had better*.
