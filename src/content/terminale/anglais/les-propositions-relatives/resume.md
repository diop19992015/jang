## L’essentiel du chapitre

:::formule Les relatifs essentiels
| Relatif | Antécédent | Exemple |
| --- | --- | --- |
| **who** | personne | *the pupil **who won*** |
| **whom** | personne (COD, soutenu) | *the teacher **whom we met*** |
| **whose** | possession | *the boy **whose father** is a doctor* |
| **which** | chose | *the book **which I read*** |
| **that** | personne ou chose | *the film **that we saw*** |
| **where** | lieu | *the school **where I study*** |
| **when** | temps | *the day **when we met*** |
| **why** | raison | *the reason **why I left*** |
:::

:::formule La préposition avec le relatif
- Soutenu : *The man **to whom I spoke**… / The house **in which I live**…*
- Courant : *The man **(who) I spoke to**… / The house **(that) I live in**…*
- Toujours avec la préposition : ~~I’m interested the book~~ → *I’m interested **in** the book.*
:::

:::formule What = pas d’antécédent
*What* = *the thing that* (ce que) : *I know **what you want**.* (Je sais ce que tu veux.) Jamais après un nom : ~~the book what~~ → *the book **that**.*

Relatifs indéfinis : ***whoever** (quiconque), **whatever** (quoi que), **wherever** (où que)*.
:::

:::formule Définissante ou explicative ?
- Sans virgules (identifie) : *The pupils **who revise hard** will pass.* — *that* possible.
- Avec virgules (ajoute une info) : *My brother, **who lives in Dakar**, is a doctor.* — jamais *that*.
:::

## Méthode express

1. Repérer l’**antécédent** : personne, chose, lieu, temps, raison ?
2. Regarder la **fonction** dans la relative : sujet, COD, possession ?
3. Vérifier la **préposition** : devant le relatif (*in which*) ou en fin (*that I live in*).
4. Choisir : *who / which / that / whose / where / when / why / what*.
5. Vérifier les **virgules** : explicative → jamais *that*, jamais de *who* de trop.

:::erreur Les erreurs qui coûtent des points
1. ~~The book what I read~~ → *The book **that** I read*.
2. ~~the school I study~~ → *the school **I study at*** (préposition obligatoire).
3. ~~My brother, that lives in Dakar~~ → ***who*** (après une virgule).
4. *whose* (possession) ≠ *who’s* (who is).
5. ~~The pupil who he wins~~ → *The pupil **who wins*** (un seul sujet).
:::

## Vocabulaire

- **Antécédent** : le nom que la relative complète.
- **Pronom relatif** : *who, whom, whose, which, that, where, when, why*.
- **Relative définissante** : identifie (sans virgules).
- **Relative explicative** : information ajoutée (virgules).
- **Préposition finale** : *the book I’m interested **in***.
- **What** : relatif sans antécédent (*the thing that*).
- **Superlatif** : *the best, the worst* (suivi de *that*).
