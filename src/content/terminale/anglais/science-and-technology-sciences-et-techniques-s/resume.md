## L’essentiel du chapitre

:::formule Les trois sous-thèmes, les mots-clés
| Sous-thème | Vocabulaire à maîtriser |
| --- | --- |
| Inventions et découvertes | *to invent, to discover, a breakthrough, an experiment, to prove, a vaccine* |
| Technologies de l’information | *IT, a smartphone, an app, social media, e-learning, mobile money, AI* |
| Information et éthique | *reliable, fake news, to check a source, plagiarism, privacy, the right to information* |
:::

:::formule Le present perfect (grammaire du chapitre)
$$
\text{have / has + participe passé (V3)}
$$

- *Electricity **has changed** everyday life everywhere.* (L’électricité a changé la vie quotidienne partout.)
- *The Internet **has existed** since the 1990s.* (Internet existe depuis les années 1990.)
- Date close → past simple : *Bell **invented** the telephone in 1876.*
:::

:::formule La voix passive des textes techniques
| Temps | Structure | Exemple |
| --- | --- | --- |
| Présent | *am / is / are + V3* | *Data **are stolen** by hackers.* |
| Passé | *was / were + V3* | *Penicillin **was discovered** in 1928.* |
| Present perfect | *has / have been + V3* | *New apps **have been created**.* |
| Modal | *modal + be + V3* | *Sources **must be checked**.* |
:::

:::formule Les modaux de l’éthique
- *Users **must protect** their passwords.* (obligation)
- *You **should not share** your personal data.* (conseil / interdiction conseillée)
- *Teenagers **may use** the Internet, but they **must respect** the law.* (permission + obligation)
:::

## Méthode express

1. Lire le repère de temps : *in 1876* → past simple ; *since, for, already, up to now* → present perfect.
2. Choisir la voix : si l’inventeur est connu et utile → actif ; sinon → **passif** (*was invented*).
3. Raconter une découverte récente avec le **present perfect** (*has discovered*).
4. Exprimer l’obligation éthique avec *must*, le conseil avec *should*, l’interdiction avec *must not*.
5. Construire la rédaction : avantages → inconvénients → solutions au conditionnel → conclusion.
6. Vérifier les pièges : *information* indénombrable, *more easier* interdit, *must + base verbale*.

:::erreur Les erreurs qui coûtent des points
1. ~~He has invented it in 1876~~ → *He **invented** it in 1876*.
2. ~~The informations are reliable~~ → ***The information is** reliable*.
3. ~~a news~~ → ***a piece of news*** / *a rumour*.
4. ~~The telephone was invented **in** Bell~~ → ***by** Bell*.
5. ~~must to protect~~ → ***must protect***.
:::

## Vocabulaire

- **an invention / a discovery** : une invention / une découverte ; **a breakthrough** : une percée.
- **an experiment / a theory / to prove** : une expérience / une théorie / prouver.
- **a laboratory / a vaccine / to cure** : un laboratoire / un vaccin / soigner.
- **information technology (IT)** : les technologies de l’information.
- **an application (an app) / to download** : une application / télécharger.
- **social media / to post a message** : les réseaux sociaux / publier un message.
- **e-learning / an online course** : l’apprentissage en ligne / un cours en ligne.
- **reliable information / fake news** : information fiable / fausse information.
- **plagiarism / privacy / a hacker** : plagiat / vie privée / pirate informatique.
- **the right to information / freedom of speech** : le droit à l’information / la liberté d’expression.
