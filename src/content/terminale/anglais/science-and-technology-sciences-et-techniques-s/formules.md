## Les temps des inventions

:::formule Choisir le bon temps
| Situation | Temps | Exemple |
| --- | --- | --- |
| Invention datée et achevée | past simple | *Bell **invented** the telephone in 1876.* |
| Découverte récente, conséquence présente | present perfect | *Scientists **have discovered** a new species.* |
| Début + durée jusqu’au présent | present perfect + *since / for* | *The Internet **has existed** since the 1990s.* |
| Invention vue comme un processus | present perfect + passif | *Vaccines **have been developed** quickly.* |
| Prochaine invention | future + passif | *New jobs **will be created**.* |
:::

:::formule Tableau du present perfect
| Affirmatif | Négatif | Interrogatif |
| --- | --- | --- |
| *I / you / we / have + V3* | *haven’t + V3* | *Have I / you… + V3 ?* |
| *he / she / it / has + V3* | *hasn’t + V3* | *Has he / she… + V3 ?* |
:::

## La voix passive : tableaux de référence

:::formule Les temps rencontrés dans les textes techniques
| Temps | Structure | Exemple + traduction |
| --- | --- | --- |
| Présent simple | *am / is / are + V3* | *The device **is used** everywhere.* (L’appareil est utilisé partout.) |
| Passé simple | *was / were + V3* | *Penicillin **was discovered** in 1928.* (La pénicilline fut découverte en 1928.) |
| Present perfect | *has / have been + V3* | *New apps **have been created**.* (De nouvelles applications ont été créées.) |
| Futur | *will be + V3* | *More tasks **will be automated**.* (Plus de tâches seront automatisées.) |
| Modal | *modal + be + V3* | *Sources **must be checked**.* (Les sources doivent être vérifiées.) |
:::

:::formule Passif ↔ actif
*The telephone **was invented** by Bell.* ⇔ *Bell **invented** the telephone.*

- Agent utile → *by + agent* : *by Alexander Graham Bell*.
- Agent inconnu ou sans intérêt → on l’omet : *The vaccine **was discovered** in 1928.*
:::

## Les modaux de l’éthique numérique

:::formule Obligation, conseil, permission, interdiction
| Idée | Structure | Exemple |
| --- | --- | --- |
| Obligation | *must + base* | *Users **must protect** their passwords.* |
| Conseil | *should + base* | *You **should check** the source.* |
| Interdiction | *must not + base* | *You **must not steal** data.* |
| Permission | *may / can + base* | *Students **may use** the school computer.* |
| Déduction passée | *must have + V3* | *He **must have downloaded** it last night.* |
| Impossibilité passée | *can’t have + V3* | *She **can’t have written** that alone.* |
:::

:::remarque Pourquoi ces modaux au BAC ?
Les textes sur l’éthique posent presque toujours la question « que faut-il faire ? ». La réponse attend *must* (règle), *should* (conseil) ou *must not* (interdiction) : trois modaux qui, bien employés, valent des points en grammaire comme en expression écrite.
:::
