## L’essentiel du chapitre

:::formule La structure générale
$$
\text{Sujet} + \text{verbe de report} + \text{that / if / wh + phrase (ordre sujet + verbe)}
$$

- Déclaration : *She said **(that) she was** tired.*
- Question Oui/Non : *He asked **if I was** ready.*
- Question mot interrogatif : *He asked **where I lived**.*
- Ordre : *He **told me to sit** down.* — Négatif : *told me **not to** talk.*
:::

:::formule Le recul des temps
| Direct | Indirect |
| --- | --- |
| present simple | past simple |
| present continuous | past continuous |
| present perfect | past perfect |
| past simple | past perfect |
| will | would |
| can | could |
| may | might |
| must | had to |
:::

:::formule Ce qui change aussi
- Pronoms : *I → he/she, my → his/her*.
- Temps : *now → then, today → that day, yesterday → the day before, tomorrow → the next day*.
- Lieu : *here → there, this → that*.
- **Exception** : les vérités générales gardent leur temps : *He said the earth is round.*
:::

:::formule Say ou tell ?
- ***say*** (sans personne) : *He **said** that he was late.*
- ***tell*** (+ personne) : *He **told me** that he was late.*
- ✗ *said me* / ✗ *told that*
:::

## Méthode express

1. Repérer le verbe de report et le type de phrase (déclaration, question, ordre).
2. Choisir la structure : *that* / *if-whether* / mot interrogatif / *to + infinitif*.
3. Appliquer le **recul des temps** (sauf vérité générale).
4. Changer les **pronoms**, les **marques de temps** et de **lieu**.
5. Pour les questions : **sujet + verbe** (aucune inversion).
6. Vérifier *say* / *tell* et la place de *not* (*not to*).

:::erreur Les erreurs qui coûtent des points
1. ~~where was I going~~ → *where **I was going***.
2. ~~he said he works in Dakar~~ → *he said **he worked** in Dakar*.
3. ~~she told that~~ → ***she said** that* ; ~~he said me~~ → ***he told me***.
4. ~~suggested to leave~~ → *suggested **leaving***.
5. Oublier *would* : ~~he said he will come~~ → *he said **he would come***.
:::

## Vocabulaire

- **Discours direct** : paroles entre guillemets, telles quelles.
- **Discours indirect (reported speech)** : paroles rapportées dans une subordonnée.
- **Verbe de report** : *say, tell, ask, order, advise, suggest, promise, warn*.
- **Recul des temps (backshift)** : décalage des temps vers le passé.
- **Complétive** : subordonnée introduite par *that*.
- **Mot interrogatif** : *what, where, when, why, who, how*.
- **Infinitif de report** : *told me **to** go / asked me **not to** be late.*
