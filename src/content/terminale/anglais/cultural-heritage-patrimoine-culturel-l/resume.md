## L’essentiel du chapitre

:::formule Les trois sous-thèmes, les mots-clés
| Sous-thème | Vocabulaire à maîtriser |
| --- | --- |
| Religions et fêtes | *a religion, to pray, a holy book, a religious festival, Tabaski, Korité, a pilgrimage* |

:::formule Les propositions relatives (grammaire du chapitre)
| Relatif | Fonction | Exemple |
| --- | --- | --- |
| **who** | sujet, personnes | *The man **who sells** fish is my uncle.* |
| **which / that** | sujet ou COD, choses | *The custom **that we protect** is old.* |
| **whose** | possession | *The griot **whose** father died kept the story.* |
| **where** | lieu | *The village **where** I was born still practises the rite.* |
| **when** | temps | *That was the year **when** the festival began.* |
:::

:::formule Les modaux de valeur
- *We **must** respect the law.* (obligation forte)
- *You **should** / **ought to** help the elderly.* (conseil, devoir moral)
- *You **must not** mock other religions.* (interdiction)
- *You **may** pray anywhere peaceful.* (permission)
:::

:::formule Une phrase modèle du thème
*Cultural heritage **is** the legacy **that** our ancestors **hand down** to us, and every citizen **should** preserve it.* (Le patrimoine culturel est l’héritage que nos ancêtres nous transmettent, et chaque citoyen devrait le préserver.)
:::

## Méthode express

1. Repérer le sous-thème : religion, coutume ou valeur → activer le vocabulaire correspondant.
2. Pour décrire une tradition, utiliser une **relative** : *a festival **that** we celebrate every year*.
3. Pour parler de possession, choisir **whose** (jamais *who’s*).
4. Pour prescrire, choisir le modal : *must* (obligation), *should / ought to* (conseil), *must not* (interdiction).
5. Argumenter : valeur → justification avec relative → devoir avec modal → hypothèse avec conditionnel.
6. Vérifier : le relatif **sujet** ne s’ommet jamais ; pas de *to* après un modal.

:::erreur Les erreurs qui coûtent des points
1. ~~The man sells fish is my uncle~~ → *The man **who** sells fish is my uncle.*
2. ~~a festival who we celebrate~~ → *a festival **that/which** we celebrate.*
3. ~~who’s meanings~~ → ***whose** meanings*.
4. ~~We should to respect~~ → *We **should respect***.
5. ~~We must not to pray~~ → ***must not pray***.
:::

## Vocabulaire

- **a religious festival** : une fête religieuse ; *Tabaski, Korité* se gardent en anglais.
- **a pilgrimage / fasting** : un pèlerinage / le jeûne.
- **a custom / a tradition** : une coutume / une tradition ; **to hand down** : transmettre.
- **the griots** : les griots (on garde le mot sénégalais).
- **to preserve a heritage** : préserver un patrimoine ; **a sacred place** : un lieu sacré.
- **tolerance / solidarity** : tolérance / solidarité ; **mutual help** : l’entraide.
- **harmony** : l’harmonie (vivre ensemble) ; **to live together** : vivre ensemble.
- **a moral value** : une valeur morale ; **to respect** : respecter.
