## Les temps du récit : structures à mémoriser

:::formule Tableau général
| Temps | Structure | Emploi | Exemple |
| --- | --- | --- | --- |
| Past simple | *V2 / V + -ed* | fait achevé, daté | *Senegal **became** independent in 1960.* |
| Past continuous | *was / were + V-ing* | action en cours dans le passé | *They **were celebrating** when he arrived.* |
| Past perfect | *had + V3* | avant un autre fait passé | *The treaty **had been signed** before the war.* |
| Present perfect | *have / has + V3* | passé → présent | *Africa **has changed** since 2000.* |
| Future simple | *will + base* | événement futur | *The summit **will be held** next year.* |
:::

:::formule Les irréguliers les plus utiles du thème
| Base | Past simple | Participe passé | Français |
| --- | --- | --- | --- |
| *become* | became | become | devenir |
| *gain* | gained | gained | gagner |
| *found* | founded | founded | fonder |
| *sign* | signed | signed | signer |
| *win* | won | won | gagner |
| *lead* | led | led | conduire, mener |
| *build* | built | built | construire |
| *begin* | began | begun | commencer |
:::

:::remarque Deux verbes à ne pas confondre
- ***found*** = trouver (*I found my pen*) ; ***found*** (écrit de la même façon, verbe régulier *to found*) = fonder (*The UN was founded in 1945*). Le contexte tranche.
- ***gain independence*** = gagner l’indépendance ; ***become independent*** = devenir indépendant.
:::

## Le passif dans les textes d’actualité

:::formule Passif : les temps rencontrés dans les textes
| Temps | Passif | Exemple |
| --- | --- | --- |
| Présent | *am / is / are + V3* | *English **is spoken** worldwide.* |
| Passé | *was / were + V3* | *The country **was colonised** for decades.* |
| Present perfect | *has / have been + V3* | *Several agreements **have been signed**.* |
| Futur | *will be + V3* | *A new school **will be built** in Thiès.* |
| Modal | *modal + be + V3* | *The dispute **must be solved** peacefully.* |
:::

## Les connecteurs de chronologie

:::formule Parler de la suite des événements
| Fonction | Expressions |
| --- | --- |
| Avant | *before, earlier, previously, until then* |
| En même temps | *meanwhile, at the same time, while* |
| Ensuite | *then, after that, soon afterwards* |
| Plus tard | *later, eventually, finally* |
| Déclencheur | *when, as soon as, in 1960, that year* |
| Résultat | *as a result, therefore, consequently* |
:::

:::remarque Chronologie et temps
Les connecteurs de chronologie sont les signaux du temps : *in 1960* impose le past simple, *since 1960* impose le present perfect, *before* laisse le choix entre *past simple* (deuxième fait) et *past perfect* (fait le plus ancien).
:::
