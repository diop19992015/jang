## Formation des temps

:::formule Le présent
- **Present simple** : base verbale + **-s** à la 3e personne → *he works, she studies*.
- **Present continuous** : **am / is / are + verbe en -ing** → *I am working*.
- Questions et négations du présent simple : **do / does + base verbale**.
:::

:::formule Le passé
- **Past simple** : régulier = base + **-ed** (*clean → cleaned*) ; irrégulier : forme à apprendre (*go → went*).
- **Past continuous** : **was / were + verbe en -ing**.
- **used to + infinitif** : habitude passée disparue ; négation **didn’t use to**.
:::

:::formule Les parfaits
$$
\text{Present perfect} = \text{have / has} + \text{participe passé (V3)}
$$

$$
\text{Past perfect} = \text{had} + \text{participe passé (V3)}
$$

Toutes les personnes du past perfect prennent **had**.
:::

:::formule Le futur
| Formation | Usage | Exemple |
| --- | --- | --- |
| *will + base verbale* | décision, promesse, prédiction | *I **will help** you.* |
| *am/is/are going to + infinitif* | intention, prédiction avec indice | *It **is going to** rain.* |
| *am/is/are + -ing* | arrangement fixé | *I **am meeting** him tomorrow.* |
| présent simple | horaire, programme | *The bus **leaves** at six.* |
:::

## Les marqueurs temporels

| Marqueur | Temps |
| --- | --- |
| *every day, usually, often, never, on Sundays* | Present simple |
| *now, at the moment, Look!, Listen!* | Present continuous |
| *yesterday, last week, two days ago, in 2019* | Past simple |
| *when, while, at that moment* | Past continuous |
| *ever, never, already, yet, just* | Present perfect |
| *since 2015, for ten years, so far* | Present perfect |
| *before, after, by the time* (antériorité) | Past perfect |
| *tomorrow, next year, soon, in 2030* | Futur |

:::remarque L’astuce du marqueur
Quand un marqueur est présent, il impose presque toujours son temps : *yesterday* ne tolère pas le present perfect, *since* ne tolère pas le past simple. Sans marqueur, c’est le sens de la phrase qui tranche.
:::

## Correspondances utiles

| Français | Anglais |
| --- | --- |
| Je l’ai vu hier (date finie) | *I **saw** him yesterday.* |
| Je l’ai déjà vu (expérience) | *I **have already seen** him.* |
| Il n’était pas encore arrivé | *He **hadn’t arrived** yet.* |
| Quand j’aurai fini… | *When I **finish**…* (jamais *will finish*) |
| Avant, j’habitais à Saint-Louis | *I **used to** live in Saint-Louis.* |
| Je vais le faire (décision) | *I**’m going to** do it.* |
| Je le ferai (sur le moment) | *I**’ll** do it.* |

## Choisir le temps en 5 étapes

1. Repérer les marqueurs temporels.
2. Situation datée et terminée → past simple ; lien avec le présent → present perfect.
3. Deux actions passées → la plus ancienne au past perfect.
4. Action longue + action brève → past continuous + past simple.
5. Futur : décision (*will*), intention (*going to*), arrangement (présent continu), horaire (présent simple).

:::remarque La subordonnée de temps
Après *when, as soon as, before, after, until* exprimant le futur, on utilise le **présent** : *I will call you as soon as I **arrive**.* (Je t’appellerai dès que j’arriverai.)
:::
