:::formule Le discours indirect (grammaire du chapitre)
| Discours direct | Discours indirect |
| --- | --- |
| *He said, “I am tired.”* | *He said **(that)** he **was** tired.* |
| *She asked, “Where do you live ?”* | *She asked **where I lived**.* |
| *The minister said, “We will help.”* | *The minister said **(that) they would** help.* |
:::

:::formule Le backshift (décalage des temps)
| Direct | Indirect |
| --- | --- |
| présent simple → **past simple** | *is → was* |
| past simple → **past perfect** | *left → had left* |
| present perfect → **past perfect** | *has gone → had gone* |
| *will → would*, *can → could*, *must → had to* | |
:::

:::formule Les repères à ajuster
*now → then · today → that day · tomorrow → the next day · yesterday → the day before · here → there · this → that*
:::

## Méthode express

1. Repérer le sous-thème : médias, rumeur, publicité ou droit → activer le vocabulaire.
2. Pour rapporter une phrase : **verbe introducteur au passé + temps décalés + repères ajustés**.
3. *say* sans complément de personne, *tell* + personne : *He said that… / He told me that…*.
4. Dans les questions indirectes : ordre normal **sans inversion** : *She asked where I lived*.
5. Citer une source avec *according to, sources say, as reported by* ; nuancer avec *however, allegedly*.
6. Vérifier : *news* et *information* restent **indénombrables** (*the news is*).

:::erreur Les erreurs qui coûtent des points
1. ~~He said me that~~ → *He **told** me that* / *He **said** that*.
2. ~~He said that he is tired~~ → *…he **was** tired*.
3. ~~She asked me where do I live~~ → *She asked me where **I lived***.
4. ~~The news are false~~ → ***The news is** false* / *a piece of news*.
5. ~~informations~~ → ***information***.
:::

## Vocabulaire

- **the press / a journalist / an article** : la presse / un journaliste / un article.
- **a headline / to publish** : un titre / publier ; **to broadcast, live** : diffuser, en direct.
- **a rumour / to spread** : une rumeur / se répandre ; **a viral message** : un message viral.
- **reliable / to verify** : fiable / vérifier ; **fake news / misleading** : fausse information / trompeur.
- **an advertisement / a slogan** : une publicité / un slogan ; **to exaggerate** : exagérer.
- **freedom of the press** : la liberté de la presse ; **censorship** : la censure.
- **bias** : un biais, une partialité ; **objective** : objectif ; **public interest** : l’intérêt général.
- **the right to information** : le droit à l’information ; **to inform the public** : informer le public.
