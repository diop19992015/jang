# Formules et tableaux de référence — L’évolution du monde négro-africain

## Les royaumes et empires

:::formule Chronologie des grands empires
| Date | Événement |
| --- | --- |
| VIIe - XIIe s. | **Empire du Ghana** (Soninkés) : Koumbi Saleh, or et sel |
| 1235 | **Soundiata Keïta** fonde l’Empire du **Mali** (bataille de Kirina) |
| 1312-1337 | Règne de **Moussa** : pèlerinage à La Mecque (**1324**), apogée du Mali |
| 1464-1492 | **Sunni Ali Ber** : expansion du **Songhaï** |
| 1493-1528 | **Askia Mohammed** : réformes, armée, université de Tombouctou |
| 1591 | Bataille de **Tondibi** : le Maroc détruit le Songhaï |
| XVIIIe-XIXe s. | **Empire ashanti** (or, *kente*) ; royaumes wolofs (Cayor, Baol, Sine, Saloum) |
:::

:::remarque Le commerce, moteur des empires
| Vers le nord (Maghreb) | Vers le sud (forêt) |
| --- | --- |
| **Or**, esclaves, plumes | **Sel**, tissus, chevaux, marmites |
:::

## L’influence de l’islam

:::formule Dates-clés de l’islamisation
| Date | Événement |
| --- | --- |
| VIIe s. | Conquêtes arabes (Égypte en 642) ; diffusion **marchande** au Soudan occidental |
| 859 | Université **Qarawiyyin** (Fès) |
| 970 | Mosquée **Al-Azhar** (Le Caire) |
| XIe s. | **Almoravides** (Ibn Yasin) : poussée saharienne |
| 1324 | Pèlerinage du **mansa Moussa** : l’or du Mali défile à La Mecque |
| XVe - XVIe s. | Université de **Sankore** (Tombouctou) ; **Ahmed Baba** (1556-1632) |
| 1852 | Voyage d’**Oumar Tall** en terre tijanienne |
| 1853-1927 | **Cheikh Ahmadou Bamba** : fondation du **mouridisme** (Touba) |
| XXe s. | Tijanisme (Ibrahim Niasse), khadrisme, layènes : confréries du Sénégal |
:::

:::formule Les effets de l’islam
| Domaine | Effet |
| --- | --- |
| Écriture | Adoption de l’**alphabet arabe**, alphabets locaux inspirés |
| Savoir | Écoles coraniques, universités, médecine, mathématiques, astronomie |
| Droit | **Charia**, cadis, notaires |
| Politique | Légitimation religieuse des rois (Askia « gardien de la foi ») |
| Langue | L’**arabe** = langue du Coran et du savoir ; langues africaines écrites en arabe |
| Société | Confréries, marabouts, fêtes religieuses (maouloud, magal) |
:::

## L’influence du christianisme

:::formule Repères
| Date | Événement |
| --- | --- |
| IVe s. | Le royaume d’**Aksum** (Éthiopie) adopte le christianisme |
| 1491 | Conversion du roi du **Kongo** ; missionnaires portugais |
| XIXe s. | Évangélisation par les missions catholiques et protestants |
| 1921 | **Kimbanguisme** (Congo) : première Église africaine indépendante |
| XXe s. | Églises africaines, évêques autochtones ; liberté de culte après l’indépendance |
| XXe s. | Au Sénégal : minorité chrétienne (~4 %), archevêques sénégalais (Théodore-Adrien Sarr) |
:::

:::remarque Apports et limites
Écoles et **hôpitaux** d’un côté ; **acculturation**, critique des rites d’initiation et de la polygamie de l’autre : les missions sont à la fois un apport social et un instrument de la domination coloniale.
:::

## La décolonisation

:::formule L’indépendance et ses organisations
| Date | Événement |
| --- | --- |
| 1957 | **Ghana** (Nkrumah) : premier État indépendant d’Afrique noire |
| 1958 | **Guinée** (Sékou Touré) : refus de la Communauté française |
| **1960** | « **Année de l’Afrique** » : 17 indépendances — **Sénégal (4 juin)**, **Mali (22 sept.)**, Côte d’Ivoire, Cameroun… |
| 1963 | **OUA** à Addis-Abeba : unité, solidarité, médiation |
| 1975 | **CEDEAO** (communauté ouest-africaine) |
| 2002 | **Union africaine** (héritière de l’OUA) |
| 1884-1885 | **Conférence de Berlin** : partage de l’Afrique, origine des frontières actuelles |
:::

:::remarque Les quatre effets à citer
1. **État-nation** dans les frontières de Berlin (États multilingues et multiethniques).
2. **Économie** dépendante des anciennes métropoles (matières premières).
3. **Culture** : négritude (Senghor, Césaire, Damas), langues africaines, débat sur la laïcité.
4. **Religion** : Églises africaines, confréries influentes, liberté de conscience garantie.
:::
