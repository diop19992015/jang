  - Pour chaque énoncé, demande : l’objet est-il abstrait, matériel ou humain ?
  - Le résultat est-il nécessaire (démontré) ou probable (vérifié) ?
  - Associe la méthode : démonstration, expérience, interprétation.

## Énoncé

Classez les sciences suivantes dans les trois familles (formelles, de la nature, de l’homme), puis donnez pour chacune : l’**objet**, la **méthode** et le **type de vérité** attendu.

1. La géométrie.
2. La physiologie.
3. L’anthropologie.
4. La logique.
5. La chimie.

## Solution

**1. Géométrie → science formelle.** Objet : les formes et les espaces **abstraits** ; méthode : **démonstration** (axiomes → théorèmes) ; vérité : **nécessaire** — le théorème de Pythagore est vrai une fois pour toutes dans son système, indépendamment de toute mesure.

**2. Physiologie → science de la nature.** Objet : le fonctionnement **matériel** des êtres vivants ; méthode : **expérience contrôlée** (observation, dissection, mesure) ; vérité : **hypothétique** — une loi biologique reste révisable (Popper : falsifiable).

**3. Anthropologie → science humaine.** Objet : les comportements, les cultures et les significations humaines ; méthode : **documentation, interprétation, comparaison** (Weber : expliquer et comprendre) ; vérité : **contextuelle** — située dans un milieu et une époque.

**4. Logique → science formelle.** Objet : les règles de la **pensée valide** (implications, raisonnements) ; méthode : **démonstration** ; vérité : **nécessaire** — un syllogisme valide l’est quel que soit son contenu.

**5. Chimie → science de la nature.** Objet : les **matières** et leurs transformations ; méthode : **expérience** et mathématisation ; vérité : **hypothétique** — les modèles atomiques ont évolué et continueront de progresser.

:::remarque Le test en une phrase
Si le résultat peut être **démontré sans expérience** → formel ; s’il vient de la **mesure du réel** → naturel ; s’il porte sur des **actes qui ont un sens** → humain.
:::
