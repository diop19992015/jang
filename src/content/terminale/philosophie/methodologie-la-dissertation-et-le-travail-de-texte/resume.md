## L’essentiel du chapitre

:::formule Retrouver la question du sujet
1. **Souligner** les termes-clés. 2. **Définir** chaque terme (deux sens possibles). 3. **Repérer le verbe** (est-ce que / faut-il / peut-on). 4. **Formuler la question** en une phrase. 5. **Vérifier** qu’elle est discutable — sinon, relire.
:::

:::formule Le plan type (dialectique)
**I. Thèse** (ce qui semble vrai) → **II. Antithèse** (ce qui le conteste) → **III. Dépassement** (la synthèse qui résout).
Chaque partie : idée directrice → argument → **citation expliquée** → exemple → **transition**.
:::

:::formule L’introduction en quatre mouvements
**Accroche** (un auteur, un fait, une question) → **définition des termes** → **problématique** (la question en une phrase) → **annonce du plan** (« Nous verrons d’abord… puis… enfin… »).
:::

:::formule La conclusion en trois mouvements
**Réponse explicite** à la question (« Oui, à condition que… ») → **bilan rapide** (une phrase par partie) → **ouverture** (une nouvelle question : numérique, africaine, contemporaine).
:::

:::formule L’anatomie de l’argument
Idée → « parce que » → **citation** (auteur + guillemets) → **explication** → **exemple précis** → transition.
Citation modèle : « L’homme est condamné à être libre » (Sartre) → expliquer « condamné » (sans recours) → lien avec le sujet.
:::

## Méthode express

1. **Analyser le sujet** (5 min) : termes, verbe, question, définitions.
2. **Bâtir le plan** (10 min) : thèse / antithèse / dépassement — remplir trois colonnes : arguments, auteurs, exemples.
3. **Rédiger** : introduction, puis une partie par paragraphe argumenté avec citation et exemple, avec transitions.
4. **Conclure** : réponse + ouverture.
5. **Relire** : orthographe, guillemets, noms d’auteurs, réponse à la question.

:::erreur Les erreurs qui coûtent des points
1. Répondre **à côté** de la question (mal analysée).
2. Introduction **sans problématique** ni annonce.
3. Citations **non expliquées** (« comme le dit Kant… » et rien d’autre).
4. Conclusion qui **répète** au lieu de **répondre** — et **ouverture oubliée**.
:::

## Vocabulaire

- **Sujet** : énoncé qui pose une question philosophique.
- **Question (problématique)** : la difficulté exacte à résoudre.
- **Thèse / antithèse / dépassement** : les trois temps du plan dialectique.
- **Argument** : raison avancée pour soutenir une thèse.
- **Preuve** : argument vérifiable ; **exemple** : cas illustratif.
- **Citation** : phrase d’un auteur, citée et expliquée.
- **Transition** : phrase qui conclut une partie et annonce la suivante.
- **Accroche** : ouverture de l’introduction qui attire l’attention.
- **Conclusion** : réponse explicite + bilan + ouverture.
- **Analyse de texte** : expliquer le sens d’un extrait (travail de texte).
- **Paraphrase** : reformuler le texte avant de le commenter.
- **Polyphonie** : les voix (auteur, personnage) d’un texte.
- **Références africaines** : Senghor, Cabral, Mbiti, Nkrumah — indispensables en série L.
