## L’essentiel du chapitre

:::formule Le Japon en un coup d’œil
- **4e économie mondiale** : PIB ≈ 4 200 milliards $, PIB/habitant ≈ 34 000 $.
- Population : environ **125 millions**, 75 % du territoire en **montagne**.
- **Très peu de ressources naturelles** : pétrole, gaz, minerais importés.
- Archipel (Honshu, Hokkaidō, Kyushu, Shikoku), soumis aux **séismes et tsunamis**.
:::

:::formule Le modèle « import-transformer-export »
$$
\text{importer matières premières et énergie} \rightarrow \text{transformer} \rightarrow \text{exporter produits finis}
$$

Exemple : pétrole du Golfe + minerai d’Australie + acier → **voitures Toyota** vendues dans le monde entier.
:::

:::formule Les six piliers du modèle
| Pilier | Détail |
| --- | --- |
| Ressources humaines | éducation, discipline, qualification, forte épargne |
| Keiretsu | groupes d’entreprises liées (Mitsubishi, Toyota, Sony) |
| Exportations | voitures, électronique, navires, robots |
| Zones littorales | usines sur les côtes, près des ports |
| Recherche | forte R&D, qualité, innovation |
| État orienteur | ministère du Commerce qui guide les industries |
:::

:::formule Les problèmes
| Problème | Repère |
| --- | --- |
| Vieillissement | 30 % de plus de 65 ans, 1,2 enfant par femme |
| Dépendance énergétique | pétrole et gaz importés à plus de 90 % |
| Croissance faible | dette publique > 250 % du PIB |
| Concurrence chinoise | usines délocalisées |
| Catastrophes | séismes, tsunamis (Fukushima 2011) |
:::

:::formule Japon / Sénégal : deux leçons opposées
| | Japon | Sénégal |
| --- | --- | --- |
| Levier | les **hommes** (éducation, qualification) | la **jeunesse** (dividende démographique) |
| Faiblesse | vieillissement | chômage des jeunes |
| Leçon | sans nature, la connaissance fait la richesse | sans emploi, la jeunesse devient un poids |
:::

## Méthode express

1. **Partir du handicap** : peu de ressources, peu de terres, montagnes, risques naturels.
2. **Montrer la réponse** : les hommes, l’éducation, l’organisation (keiretsu), la qualité.
3. **Décrire la chaîne** : import → transformer → export (zone littorale).
4. **Poser les problèmes** : vieillissement, énergie, dette, Chine, séismes.
5. **Comparer et nuancer** : 4e économie mondiale malgré tout ; leçon pour les pays en développement.

:::erreur Les erreurs qui coûtent des points
1. Oublier que le Japon **importe presque tout** : c’est la caractéristique n° 1 du chapitre.
2. Confondre **keiretsu** et multinationale : le keiretsu est un groupe d’entreprises japonaises liées par des participations croisées.
3. Présenter le Japon comme **en déclin total** : il reste la 4e puissance économique.
4. Citer le vieillissement **sans conséquence** sur l’économie.
:::

## Vocabulaire

- **Keiretsu** : réseau d’entreprises japonaises liées (banques, industrie, commerce).
- **Import-transformer-export** : modèle japonais de création de valeur.
- **Zone industrielle littorale** : usines installées près des ports.
- **MITI** : ministère japonais du Commerce et de l’Industrie (orientation).
- **Décennie perdue** : années 1990 de croissance quasi nulle après la bulle financière.
- **Zonage** : planification de l’usage du sol.
- **Tsunami** : raz-de-marée sismique.
- **Dividende démographique** : richesse possible d’une population jeune (Sénégal).
- **Dépendance énergétique** : part de l’énergie importée.
- **Valeur ajoutée** : différence entre la valeur du produit et celle des matières premières employées.
