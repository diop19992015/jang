## L’essentiel du chapitre

:::formule Les ressources en eau
| Ressource | Rôle |
| --- | --- |
| Fleuve Sénégal | irrigation, électricité (Manantali), navigation, pêche |
| Fleuve Gambie | riziculture, pêche |
| Fleuve Casamance | riz, bolongs, pêche |
| Delta du Saloum | pêche, mangroves, parc national |
| Lac de Guiers | **eau potable de Dakar**, riziculture |
| Nappes phréatiques | villages, petits irrigations |
| Pluies (mousson) | agriculture pluviale, 100-1 500 mm |
:::

:::formule Les ouvrages hydrauliques
- **Manantali** (barrage sur le fleuve Sénégal, au Mali) : électricité + régularisation du débit pour l’irrigation.
- **Diama** (en embouchure) : bloque l’intrusion d’eau de mer → protège l’irrigation.
- **Conduite du Lac de Guiers** (≈ 180 km) : eau potable de Dakar.
- **Usines de dessalement** : complètent l’alimentation de Dakar.
:::

:::formule Eau et production alimentaire
| Branche | Eau utilisée | Produits |
| --- | --- | --- |
| Agriculture pluviale | mousson (juil.-oct.) | mil, sorgho, arachide, niébé |
| Irrigation | fleuves, Lac de Guiers, nappes | riz (Richard-Toll), maraîchage (Niayes), canne à sucre |
| Élevage | points d’eau, pâturages | bovins, ovins, caprins |
| Pêche | fleuves, lac, océan | thon, sardines, crevettes |
:::

:::formule Les bassins de production
**Bassin arachidier** (centre : arachide, mil) · **Vallée du fleuve Sénégal** (riz, canne à sucre) · **Niayes** (maraîchage irrigué) · **Casamance** (riz, agrumes) · **Côte** (pêche maritime).
:::

:::formule Les problèmes de l’eau
| Problème | Exemple |
| --- | --- |
| Sécheresses récurrentes | 1970-1990, 2020-2023 → récoltes en baisse |
| Irrégularité des pluies | mousson variable |
| Stress hydrique urbain | Dakar : rationnement, dessalement |
| Salinisation | eau de mer dans les nappes (Diama la freine) |
| Pollution | déchets et rejets urbains |
| Dépendance alimentaire | riz et blé importés |
:::

:::formule Les solutions
**Stockage** (Manantali) · **irrigation** (vallée, Niayes) · **dessalement** · **économie d’eau** (goutte-à-goutte) · **assainissement** · **reboisement** · **coopération** (OMVS : Sénégal-Mali-Mauritanie ; CILSS).
:::

## Méthode express

1. **Lister les ressources** : fleuves, Lac de Guiers, nappes, pluies.
2. **Relier chaque ressource à un usage** : irrigation, potable, élevage, pêche.
3. **Citer les ouvrages** avec leur rôle : Manantali (électricité/irrigation), Diama (anti-salinisation), dessalement.
4. **Poser les défis** : sécheresses, salinisation, stress urbain, dépendance alimentaire.
5. **Conclure** : l’eau est nécessaire mais insuffisante sans gestion, industrialisation et revenus.

:::erreur Les erreurs qui coûtent des points
1. Confondre **eau potable** (Lac de Guiers, dessalement) et **eau d’irrigation** (fleuves, nappes).
2. Citer un barrage **sans son rôle**.
3. Dire que le Sénégal « manque d’eau » partout : c’est une question de **répartition et de gestion**.
4. Traiter l’eau **sans la relier à l’alimentation** (le titre lie les deux).
:::

## Vocabulaire

- **Ressource hydrique** : quantité d’eau disponible (fleuves, lacs, nappes, pluies).
- **Barrage** : ouvrage qui stocke et régule l’eau (Manantali).
- **Salinisation** : intrusion d’eau de mer dans les sols et les nappes.
- **Dessalement** : traitement de l’eau de mer pour la rendre potable.
- **Irrigation** : apport d’eau artificielle aux cultures.
- **Goutte-à-goutte** : irrigation économique qui économise l’eau.
- **Sécurité alimentaire** : accès permanent à une nourriture suffisante.
- **Sécheresse** : longue période sans pluie.
- **Mousson** : vents d’ouest de la saison humide.
- **OMVS** : organisation de gestion du fleuve Sénégal (Sénégal, Mali, Mauritanie).
- **ONEA** : Office national de l’eau et de l’assainissement.
