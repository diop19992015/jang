## Question

Pour la courbe paramétrée $x = t^2$, $y = t + 1$, quelle est l'équation cartésienne ?

- [ ] $y = x^2 + 1$
- [x] $y = \sqrt{x} + 1$ avec $x \geq 0$
- [ ] $x = (y-1)^2$ avec $y \geq 1$
- [ ] $y = x + 1$

> De $y = t + 1$ on tire $t = y - 1$, donc $x = (y-1)^2$. Comme $x = t^2 \geq 0$, la courbe n'existe que pour $x \geq 0$ (ou $y \geq 1$ si on écrit $y = \sqrt{x} + 1$, en ne retenant que la branche $t \geq 0$). Les restrictions de domaine sont essentielles.

## Question

Que signifie $\vec{v}(t) = \vec{0}$ pour une courbe paramétrée ?

- [ ] La courbe a une tangente verticale
- [x] Le point est un point singulier (la vitesse s'annule)
- [ ] La courbe est un cercle
- [ ] L'accélération est maximale

> $\vec{v}(t) = (f'(t)\,;\,g'(t)) = \vec{0}$ signifie que les **deux** composantes sont nulles simultanément : le point est momentanément immobile — c'est un point singulier (par exemple les pointes de la cycloïde).

## Question

Quelle est l'excentricité d'une ellipse d'équation $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$ ?

- [ ] $\dfrac{5}{4}$
- [x] $\dfrac{4}{5}$
- [ ] $\dfrac{3}{5}$
- [ ] $\dfrac{5}{3}$

> $a^2 = 25$ donc $a = 5$, $b^2 = 9$ donc $b = 3$, d'où $c = \sqrt{25 - 9} = 4$ et $e = \dfrac{c}{a} = \dfrac{4}{5} < 1$ ✓.

## Question

Quelle propriété caractérise la parabole de foyer $F$ et de directrice $\Delta$ ?

- [ ] $MF + MF' = 2a$
- [x] $MF = d(M\,;\,\Delta)$
- [ ] $|MF - MF'| = 2a$
- [ ] $MF \times d(M\,;\,\Delta) = e$

> La parabole est le cas $e = 1$ : la distance au foyer **égale** la distance à la directrice. La somme constante caractérise l'ellipse et la différence constante l'hyperbole.
