## Question

$(u_n)$ est arithmétique avec $u_0 = 4$ et raison $q = 3$. Que vaut $u_{10}$ ?

- [ ] $30$
- [x] $34$
- [ ] $40$
- [ ] $13$

> Terme général : $u_n = u_0 + n\,q$, donc $u_{10} = 4 + 10 \times 3 = 34$.

## Question

Une suite géométrique a pour raison $q = \dfrac{1}{2}$ et $u_0 = 8$. Que vaut $u_5$ ?

- [ ] $4$
- [x] $\dfrac{1}{4}$
- [ ] $\dfrac{1}{2}$
- [ ] $1{,}6$

> $u_n = u_0 \times q^n$, donc $u_5 = 8 \times \left(\dfrac{1}{2}\right)^5 = 8 \times \dfrac{1}{32} = \dfrac{8}{32} = \dfrac{1}{4}$.

## Question

$(u_n)$ est géométrique de raison $q = -\dfrac{3}{4}$. Que peut-on dire ?

- [ ] Elle diverge car $q$ est négatif.
- [x] Elle converge vers $0$, car $|q| = 0{,}75 < 1$.
- [ ] Elle diverge vers $+\infty$.
- [ ] Elle est constante.

> Le critère porte sur $|q|$ : $\left|-\dfrac{3}{4}\right| = \dfrac{3}{4} < 1$, donc $u_n = u_0\left(-\dfrac{3}{4}\right)^n \to 0$. Les signes alternent (oscillation), mais la suite converge bien vers $0$.

## Question

Soit $(u_n)$ définie par $u_0 = 1$ et $u_{n+1} = u_n + \dfrac{1}{2}$. Que peut-on affirmer ?

- [ ] Elle est géométrique de raison $\dfrac{1}{2}$.
- [ ] Elle converge vers $0$.
- [x] Elle est arithmétique de raison $\dfrac{1}{2}$ et elle diverge.
- [ ] Elle est constante.

> $u_{n+1} - u_n = \dfrac{1}{2}$ est constant : c'est une suite arithmétique de raison $\dfrac{1}{2}$. Comme la raison est positive, $u_n = 1 + \dfrac{n}{2} \to +\infty$ : elle diverge.
