## L'essentiel du chapitre

:::formule Vocabulaire
- **Gène** : portion d'ADN codant un caractère, à un locus précis.
- **Allèle** : version d'un gène ($A$ ou $a$).
- **Génotype** : paire d'allèles, notée $A//a$.
- **Phénotype** : caractère observable.
- **Homozygote** : deux allèles identiques ; **hétérozygote** : deux allèles différents.
:::

:::formule Loi d'uniformité ($F_1$)
Le croisement de deux lignées pures donne des hybrides $F_1$ tous identiques, exprimant le caractère dominant.
:::

:::formule Loi de ségrégation
Un hétérozygote $A//a$ produit $50\,\%$ de gamètes $A$ et $50\,\%$ de gamètes $a$.

Croisement $A//a \times A//a$ : $3/4$ dominant, $1/4$ récessif.
:::

:::formule Loi du brassage indépendant
Pour deux gènes non liés, le croisement $AaBb \times AaBb$ donne les phénotypes dans les proportions $9:3:3:1$.
:::

:::formule Gènes liés
Si les gènes sont sur le même chromosome, les combinaisons parentales sont majoritaires. La fréquence de recombinaison $r$ donne la distance génétique en centimorgans : $d = r \times 100$ cM.
:::

:::formule Hérédité liée à l'$X$
Un homme $X^d//Y$ est atteint dès qu'il porte l'allèle récessif ; une femme doit être $X^d//X^d$ pour être atteinte. Les maladies récessives liées à l'$X$ touchent donc surtout les hommes.
:::

:::formule Groupes sanguins ABO
| Génotypes | Groupe |
| --- | --- |
| $A//A$, $A//O$ | A |
| $B//B$, $B//O$ | B |
| $A//B$ | AB (codominance) |
| $O//O$ | O |
:::

## Démarche type d'un exercice

1. **Lire les résultats** : effectifs, proportions, générations.
2. **Formuler une hypothèse** : dominance, gènes liés ou indépendants, autosomique ou lié au sexe.
3. **Tester l'hypothèse** : échiquier, proportions attendues, croisement test.
4. **Conclure** : génotypes des parents et des descendants, mode de transmission.

:::erreur Les pièges classiques
1. Confondre allèle dominant et allèle le plus fréquent dans la population.
2. Oublier que les proportions mendéliennes supposent de grands effectifs.
3. Croire qu'un gène lié au sexe est forcément porté par le chromosome $Y$.
4. Conclure « gènes indépendants » alors que les quatre classes ne sont pas équiprobables.
:::
