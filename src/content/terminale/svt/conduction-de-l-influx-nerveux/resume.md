## L’essentiel du chapitre

:::formule Mesure de la vitesse
$$
v = \frac{d}{\Delta t}
$$
$d$ = distance entre deux électrodes, $\Delta t$ = délai mesuré entre les deux passages du signal.
:::

:::formule Les deux types de conduction
- **Non myélinisée** : de proche en proche, $0{,}5$–$2$ m/s.
- **Myélinisée (saltatoire)** : de nœud de Ranvier en nœud, $5$–$120$ m/s.
:::

:::formule Les quatre facteurs de variation
| Facteur | Effet |
| --- | --- |
| Diamètre de l’axone | ↑ diamètre → ↑ vitesse |
| Myéline | présence → conduction saltatoire, ×$10$ à ×$50$ |
| Température | ↑ température → ↑ vitesse (dans les limites physiologiques) |
| Intégrité du nerf | coupe/compression/anesthésie → blocage |
:::

:::formule Comparaison rapide
| | Saltatoire | Continue |
| --- | --- | --- |
| Trajet | nœud → nœud | segment par segment |
| Vitesse | élevée | faible |
| Énergie | faible | élevée |
| Myéline | oui | non |
:::

## Méthode express

1. Calculer $v = d/\Delta t$ en veillant aux unités (cm → m, ms → s).
2. Dire le type de conduction : myélinisée = saltatoire.
3. Citer les facteurs avec leur sens d’effet (↑ ou ↓).
4. Interpréter une pathologie : démyélinisation = ralentissement puis blocage.
5. Relier rapidité et fonction : mouvement volontaire rapide = grosse fibre myélinisée.

:::erreur Les erreurs qui coûtent des points
1. Écrire « l’influx saute » sans citer les **nœuds de Ranvier** et l’isolation par la myéline.
2. Oublier de convertir les unités dans $v = d/\Delta temp$ (cm, ms).
3. Dire que la température n’a aucun effet : elle ralentit ou accélère la conduction.
4. Confondre conduction nerveuse (rapide, $120$ m/s max) et conduction cardiaque (lente, $\sim 1$ m/s).
5. Affirmer que la démyélinisation supprime les influx immédiatement : d’abord ralentissement, puis blocage.
:::

## Vocabulaire

- **Nœud de Ranvier** : intervalle entre deux segments de myéline, riche en canaux $Na^+$.
- **Conduction saltatoire** : propagation par sauts de nœud en nœud.
- **Myéline** : gaine lipidique isolante.
- **Latence** : délai entre stimulation et réponse.
- **Sclérose en plaques** : démyélinisation du SNC.
- **Fibre nerveuse** : axone + ses gaines.
