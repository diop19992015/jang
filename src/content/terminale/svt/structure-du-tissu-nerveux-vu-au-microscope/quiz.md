## Question

Sur une coupe transversale de moelle épinière, où se trouve la substance grise ?

- [x] Au centre, en forme de papillon
- [ ] En périphérie, sous les méninges
- [ ] Sur toute la surface, comme le cortex
- [ ] Elle est absente de la moelle

> Dans la moelle épinière, la **substance grise occupe le centre** (forme de papillon ou de H) et la substance blanche la entoure. C’est l’inverse du cortex cérébral, où la substance grise est en surface.

## Question

Que contiennent les cornes antérieures de la substance grise ?

- [ ] Les corps des neurones sensitifs
- [x] Les corps des neurones moteurs
- [ ] Les cellules gliales uniquement
- [ ] Les axones myélinisés

> Les cornes **antérieures (ventrales)** abritent les corps cellulaires des **neurones moteurs**, dont les axones sortent par les racines antérieures pour aller commander les muscles. Les cornes postérieures reçoivent les fibres sensitives.

## Question

Dans quel ordre l’information circule-t-elle dans un neurone ?

- [ ] Axone → dendrites → corps cellulaire
- [x] Dendrites → corps cellulaire → axone
- [ ] Corps cellulaire → axone → dendrites
- [ ] Axone → corps cellulaire → dendrites

> Les **dendrites** reçoivent l’information, le **corps cellulaire** l’intègre, l’**axone** la transmet vers le neurone suivant ou vers l’effeteur. Le sens est unique : c’est la **loi du monodirectionnel** de l’influx dans le neurone.

## Question

Quelle cellule produit la myéline dans le système nerveux périphérique ?

- [ ] L’oligodendrocyte
- [x] La cellule de Schwann
- [ ] L’astrocyte
- [ ] Le neurone lui-même

> Dans les nerfs (SNP), ce sont les **cellules de Schwann** qui entourent l’axone de myéline, segment par segment. Dans le cerveau et la moelle (SNC), ce sont les **oligodendrocytes**.
