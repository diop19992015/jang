## L’essentiel du chapitre

:::formule Localisation
Moelle épinière = prolongement de l’encéphale, logée dans le **canal rachidien**, du trou occipital jusqu’au niveau de **L2**.
:::

:::formule Protections
Vertèbres + méninges + LCR + disques intervertébraux. Au-dessous de L2 : queue de cheval (pas de moelle).
:::

:::formule Anatomie externe
| Repère | Remarque |
| --- | --- |
| Renflement cervical | origine des nerfs des membres supérieurs |
| Renflement lombaire | origine des nerfs des membres inférieurs |
| Conus médullaire | partie inférieure effilée |
| Fil terminal | appendice filiforme terminal |
:::

:::formule Les racines nerveuses
- Racine **postérieure (dorsale)** : sensitive, avec **ganglion** ; sens périphérie → moelle.
- Racine **antérieure (ventrale)** : motrice ; sens moelle → muscle.
- Les deux racines s’unissent pour former le **nerf rachidien** (mixte).
:::

:::formule Double rôle de la moelle
1. **Voie de conduction** : vers le cerveau (ascendant) et depuis le cerveau (descendant).
2. **Centre nerveux** : intégration des réflexes (arc réflexe spinal).
:::

## Méthode express

1. Situer : canal rachidien, de L1 à L2 ; ponction lombaire entre L3 et L5.
2. Citer les protections : vertèbres, méninges, LCR.
3. Décrire la forme : cordon, deux renflements (cervical, lombaire), conus, fil terminal.
4. À chaque question sur une racine : postérieure = sensitive (ganglion), antérieure = motrice.
5. Rappeler le double rôle : conduction + intégration réflexe.

:::erreur Les erreurs qui coûtent des points
1. Inverser les racines : postérieure = sensitive, antérieure = motrice.
2. Oublier le ganglion sur la racine postérieure.
3. Placer le bas de la moelle au niveau du sacrum : elle s’arrête à L2.
4. Confondre moelle (SNC) et nerfs (SNP).
5. Dire que la ponction lombaire prend du liquide dans la moelle : elle le prend dans l’espace sous-arachnoïdien, **sous** le conus.
:::

## Vocabulaire

- **Canal rachidien** : trou formé par les vertèbres.
- **Renflement cervical / lombaire** : épaississements d’où naissent les nerfs des membres.
- **Racine sensitive / motrice** : origine postérieure / antérieure du nerf.
- **Ganglion** : amas de corps de neurones hors du SNC (renflement de la racine postérieure).
- **Conus médullaire** : extrémité inférieure effilée de la moelle.
- **Queue de cheval** : ensemble des racines lombosacrés sous le conus.
- **Paraplégie / tétraplégie** : paralysie des membres inférieurs / des quatre membres.
