## Repères d’organisation

:::formule Le système nerveux central
$$
\text{SNC} = \text{encéphale} + \text{moelle épinière}
$$
Encéphale = cerveau + cervelet + tronc cérébral.
:::

:::formule Schéma légendé — organisation externe (face ventrale)
De l’avant vers l’arrière, on décrit :

1. **Bulbes olfactifs** (avant) : réception de l’odorat.
2. **Hémisphères cérébraux** : grands lobes, commandement.
3. **Chiasma optique** : croisement des nerfs optiques.
4. **Hypophyse** : glande suspendue sous le cerveau.
5. **Pons de Varole** : renflement du tronc cérébral.
6. **Cervelet** : deux hémisphères + vermis médian.
7. **Bulbe rachidien** (arrière) : prolongement en direction de la moelle.
:::

:::remarque Ordre mnémotechnique, de l’arrière vers l’avant
*« Mon Pont De Cerveau »* : **M**oelle → bulbe → **P**ont → cervelet → cerveau. On repère d’abord le bulbe rachidien, plus simple à identifier.
:::

## Les méninges et le LCR

:::formule Schéma légendé — enveloppes de l’encéphale
| Couche (de l’extérieur vers l’intérieur) | Nature |
| --- | --- |
| Os du crâne | osseux |
| Dure-mère | membrane épaisse, adhérente à l’os |
| Espace sous-durale | — |
| Arachnoïde | membrane transparente |
| Espace sous-arachnoïdien → **LCR** | liquide |
| Pie-mère | membrane appliquée sur le tissu nerveux |
| Encéphale | tissu nerveux |
:::

:::formule Rôles du LCR
- **Amortir** les chocs mécaniques (coussin liquide).
- **Nourrir** le tissu nerveux.
- **Assurer l’évacuation** des déchets.
:::

:::remarque Ponction lombaire
Le LCR circule aussi dans la moelle : on peut le prélever par une ponction lombaire (espace entre les vertèbres lombaires) pour diagnostiquer une **méningite** (recherche de microbes) sans risquer de toucher l’encéphale.
:::

## Substance grise et substance blanche

:::formule Comparaison
| | Substance grise | Substance blanche |
| --- | --- | --- |
| Contient | corps cellulaires des neurones | axones myélinisés |
| Rôle | intégration, traitement | conduction de l’influx |
| Cerveau | en **surface** (cortex) | en **profondeur** |
| Moelle épinière | au **centre** (forme de H) | en **périphérie** |
:::

## Principaux repères d’une coupe médiane

:::formule Structures et rôles
| Structure | Rôle |
| --- | --- |
| Cortex cérébral | perceptions, mouvements volontaires, mémoire, langage |
| Corps calleux | communication entre les deux hémisphères |
| Thalamus | relais de toutes les informations sensibles (sauf l’odorat) |
| Hypothalamus | homéostasie, lien nerveux avec l’hypophyse |
| Hypophyse | sécrétion d’hormones, commandement des autres glandes |
| Ventricules | cavités où circule le LCR |
| Arbre de vie du cervelet | substance blanche du cervelet |
:::

## Méthodes d’étude

:::formule Comparaison stimulation / ablation
| Expérience | On observe | On conclut |
| --- | --- | --- |
| Stimulation d’une zone | un mouvement ou une sensation apparaît | la zone est **suffisante** pour la fonction |
| Ablation d’une zone | un trouble apparaît | la zone est **nécessaire** pour la fonction |
:::

:::remarque Techniques d’exploration humaine
- **IRM** : images détaillées des tissus mous, sans irradiation.
- **Scanner** : coupe radiologique rapide.
- **EEG** : enregistrement de l’activité électrique du cortex.
- **Angiographie** : visualisation des vaisseaux cérébraux.
:::

## Vocabulaire

- **Encéphale** : cerveau + cervelet + tronc cérébral.
- **Méninges** : dure-mère, arachnoïde, pie-mère.
- **LCR** : liquide céphalo-rachidien.
- **Cortex** : substance grise périphérique du cerveau.
- **Commissure** : faisceau reliant deux régions symétriques (corps calleux).
- **Noyau gris** : amas de substance grise à l’intérieur de la substance blanche.
