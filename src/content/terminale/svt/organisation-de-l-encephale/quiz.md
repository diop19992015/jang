## Question

Quelles sont les trois grandes régions de l’encéphale ?

- [ ] La moelle épinière, les nerfs et les méninges
- [x] Le cerveau, le cervelet et le tronc cérébral
- [ ] Le cortex, le thalamus et l’hypophyse
- [ ] Les hémisphères, les méninges et le LCR

> L’encéphale, logé dans la cavité crânienne, comprend le **cerveau**, le **cervelet** et le **tronc cérébral**. La moelle épinière, elle, appartient au système nerveux central mais reste dans la colonne vertébrale.

## Question

Quelle est la position de la substance grise dans le cortex cérébral ?

- [ ] Elle est au centre, entourée de substance blanche
- [x] Elle est en surface, sous les méninges
- [ ] Elle est absente du cerveau
- [ ] Elle est confondue avec le liquide céphalo-rachidien

> Dans le cerveau, la **substance grise** (corps des neurones) forme une couche périphérique, le **cortex**, tandis que la substance blanche (axones) occupe la profondeur. C’est l’inverse dans la moelle épinière.

## Question

Quel liquide amortit les chocs mécaniques de l’encéphale ?

- [ ] Le sang artériel
- [x] Le liquide céphalo-rachidien
- [ ] La lymphe
- [ ] Le liquide synovial

> Le **liquide céphalo-rachidien (LCR)** circule entre les méninges et dans les ventricules : il forme un coussin liquide qui protège le tissu nerveux des chocs.

## Question

Un sujet dont on détruit le bulbe rachidien présente un arrêt respiratoire. Que conclure ?

- [ ] Le bulbe contrôle la vision
- [x] Le bulbe est nécessaire aux fonctions vitales comme la respiration
- [ ] Le bulbe commande les mouvements volontaires
- [ ] Le bulbe sert uniquement à l’équilibre

> L’expérience d’**ablation** montre qu’une fonction disparaît quand la zone est détruite : le bulbe rachidien est donc **nécessaire** à la régulation automatique de la respiration et du rythme cardiaque.
